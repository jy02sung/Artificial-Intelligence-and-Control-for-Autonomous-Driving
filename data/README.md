# 데이터 보관 정책

GitHub에는 코드·도로 입력·재현 설정·요약 표·선택한 그림만 저장합니다. 모델 체크포인트, TensorBoard 로그, 개별 실험 결과와 수집 데이터는 로컬 파일로 보존합니다.

| 위치 | 정책 |
|---|---|
| results/ | 실행별 모델·로그·원시 추적, Git 제외 |
| data/ | 데이터셋, Git 제외. 이 README만 추적 |
| docs/experiments/*plan*.json | 소형 실행 설계/설정, Git 추적 |
| docs/experiments/의 기타 JSON | 기존 실험 사례 export, 로컬만 보관 |
| docs/*.md, docs/archive/*.md | 최신 요약과 과거 기록, Git 추적 |
| maps/ | 재현에 필요한 도로 소스·네트워크·소형 검증 자료 유지 |

이미 추적되던 data/dataset.npz와 결과 JSON 7개는 git rm --cached로 추적만 해제했습니다. 로컬 파일과 내용 해시는 보존했습니다. 기존 커밋에는 과거 파일이 남으며 Git 이력은 재작성하지 않았습니다. 따라서 현재 파일 목록과 향후 증가량을 줄이는 조치이지 clone 전체 이력 크기를 즉시 줄이는 작업은 아닙니다.

다른 팀원은 이 변경을 pull하기 전에 해당 위치에 필요한 로컬 데이터가 있으면 별도 백업하세요. Git에서 제거된 파일은 다른 clone에도 제거가 반영될 수 있습니다. 새로 clone한 팀원에게는 데이터·모델을 별도 전달해야 합니다.

로컬 보관은 백업을 대신하지 않습니다. 실험 재현용 요약에는 run 경로, seed, 설정/맵/모델 해시를 남깁니다. Git 이력 정리는 팀 협의 후 별도 작업으로 합니다.
