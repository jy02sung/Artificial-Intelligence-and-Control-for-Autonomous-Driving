# 기존 mcw2 가중치에서 DAgger 추가 없이 PPO만 학습

개발 400회에서 선정한 모델 merge_12의 별도 1,600회(경로당 100회) 결과는 완주 1,537/1,600 (96.06%), 충돌 50/1,600 (3.125%), 시간초과 13회다. 충돌률의 참고용 95% Wilson 구간은 2.38–4.10%다.

saved와 direct의 출발점은 안건 2의 DAgger 직후 체크포인트 f2126af64a90이다. latest는 이미 DAgger와 가중치 혼합, 가림 적응 PPO를 거친 팀 브랜치 최신 체크포인트 4dab15658aa3에서 바로 시작했다. 세 계열 모두 이 로컬 실험에서 DAgger나 교사 라벨을 추가하지 않았다.

saved는 브랜치의 기본 PPO를 사용했다. direct와 latest는 가감속과 공통층을 고정하고 차선 선택 출력층·가치 추정층을 PPO로 업데이트했다. 훈련 시 좁은 간격의 차선 변경과 충돌을 감점하고, 안전하게 실제 이동해 경로 연결성이 개선될 때 가점을 줬다. 5개 어려운 경로의 훈련 비중도 높였다. 평가에는 원래 mcw2의 관측과 네트워크만 사용했다. 여기에는 경로를 따라 차선이 120m 안에서 얼마나 이어지는지가 포함된다.

## 같은 개발 시드 400회

| 출발점 / 학습 | PPO 스텝 | 완주 | 충돌 | 시간초과 |
|---|---:|---:|---:|---:|
| DAgger 직후 기준선 | 0 | 344 | 25 | 31 |
| 브랜치 최신 기준선 | 0 | 376 | 24 | 0 |
| [saved_6](saved_6_dev.json) | 12,288 | 363 | 37 | 0 |
| [direct_16](direct_16_dev.json) | 32,768 | 359 | 41 | 0 |
| [latest_16](latest_16_dev.json) | 32,768 | 375 | 25 | 0 |
| [gap_4](gap_4_dev.json) | 8,192 | 363 | 33 | 4 |
| [gaplatest_20](gaplatest_20_dev.json) | 40,960 | 379 | 21 | 0 |
| [merge_12](merge_12_dev.json) | 32,768 | 391 | 6 | 3 |

gap은 같은 저장 DAgger 원본에서, gaplatest는 팀 최신 체크포인트에서 시작해 PPO의 차선 선택뿐 아니라 공통층도 학습했다. 정책이 직접 샘플링한 행동에 대해 즉시 위험 감점과 장기 주행 결과의 이득(advantage)을 따로 계산한 뒤 PPO의 클립 목적함수를 적용했다. 초기 정책에서 가감속과 차선 선택 확률이 급격히 달라지는 것을 제한했다. [해당 PPO 구현](../../experiments/mcw2/local_driver_gap_ppo.py)

merge는 같은 DAgger에서 시작한 gap의 8,192스텝 체크포인트를 이어서, 분기 전 연결성이 줄어든 상태에서 안전하게 진로를 확보하는 보상을 높였다. 즉시 보상의 차선별 PPO 목적함수를 세 행동의 기존 확률로 평균해 드문 행동의 학습 신호를 보강했다. 이 보상 계산은 훈련에만 사용한다.
