# 실험 X · 취약 경로를 더 자주 경험시킨 PPO 미세조정

**판정은 중단이다.** 고교통 16개 경로에서 각 25회씩, 두 모델을 같은 개발 시드로 비교했다. 기존 모델은 371/400회 완주(92.75%), 29/400회 충돌(7.25%)이었다. X는 350회 완주(87.50%), 50회 충돌(12.50%)이었다. 시간초과는 두 모델 모두 0건이었다. 사전 기준은 완주 380회 이상·충돌 19건 이하였고 최종 검증용 1,600회는 사용하지 않았다.

## 무엇을 바꿨나

- mcw2 커밋 `ac2f9bc`의 기존 best_model.pt에서 시작했다. 기존 정책은 모방학습 이력이 있고 이번 미세조정은 환경 상호작용과 PPO만 사용했다.
- 32에피소드 블록마다 16경로를 한 번씩, 02·05·13·14를 추가로 4번씩 배정하고 순서를 섞었다. 학습은 새 시드에서 시작한 에피소드 82개에 걸쳐 32,768스텝(16회 업데이트), 학습률 0.000025로 수행했다. 시작된 82개 중 53개가 네 집중 경로였다. 마지막 에피소드는 전체 스텝 예산에서 잘릴 수 있다. 실제 학습 시간은 약 3분 15초다.
- 기존 mcw2의 학습 설정, 관측과 보상, 교통 유입 설정을 사용했다. 두 모델은 CPU·libsumo, 결정론적 정책, 센서 가림 및 노이즈를 적용하고 안전 필터를 끈 상태에서 평가했다. 시드 목록의 기존 1,600회·X 학습·개발·최종 세트 사이에 중복이 없는지 확인했다.

## 해석

기존 충돌이 X에서 완주로 바뀐 시드는 14개, 기존 완주가 X에서 충돌로 바뀐 시드는 35개였다. 336개는 양쪽 모두 완주했고 15개는 양쪽 모두 충돌했다. 네 집중 경로 합계도 충돌이 24/100에서 37/100으로 늘었다.

사전 진단 지표는 지정한 차선의 끝 0.1m 이내에서 0.1m/s 미만일 때 다음 도로로 연결되는 옆 차선으로 변경을 요청한 주행 수였다. 02에서 14→16회, 13에서 13→0회, 14에서 18→0회로 합계는 45→16회였다. 13·14만 보면 이 행동은 31→0회였지만 충돌은 15→21건이었다. 이 지표로는 X가 안전한 간격을 선택했는지 또는 달라진 충돌이 어디서 발생했는지를 알 수 없다. 이 단일 학습 시드·예산 조합은 후보에서 제외한다.
