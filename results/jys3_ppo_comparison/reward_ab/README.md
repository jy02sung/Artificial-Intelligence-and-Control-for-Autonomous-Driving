# jys3 완주·분기 보상 비교

학습 시드 11. 같은 BC+DAgger에서 시작했다. 고교통 16개 경로에서 출발 차로와 교통 시드를 맞춘 64회 고정 평가다. 기존 조건은 완주 +5, 분기 +0.25, A는 +10과 +0.25, B는 +10과 +1이다. 충돌 −15와 시간초과·정지 −5는 동일하다.
