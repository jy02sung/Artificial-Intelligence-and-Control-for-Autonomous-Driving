# 완주·충돌 보상 비율의 60만 스텝 검증

충돌을 피하려다 정지하거나 시간초과하는 사례가 많아 완주 보상과 충돌 벌점을 각각 바꿨다. 전진 +2, 분기 +0.25, 시간초과·정지 −5, 고교통, 1,000스텝 상한은 공통이다. 각 조건은 무작위 초기 순수 PPO이며 학습 시드는 11·22·33이다.

12개 모두 65,536스텝의 참조 가중치를 재현했다. 중간 평가 144개와 별도 교통 시드의 최종 평가 30개를 주행별 원자료에서 다시 집계했다. 각 평가에 동일한 64개 출발과 교통 조건을 사용했다. 5만 간격 중간 평가에서 세 시드 합산 완주가 가장 많고 동률이면 충돌이 적은 시점, 다시 동률이면 이른 시점을 선정했다.
