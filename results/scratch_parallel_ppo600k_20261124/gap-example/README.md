# PPO가 차로를 유지하며 감속한 뒤 옆 차 뒤로 들어간 사례

[2번 경로 영상](ppo-gap-opening.mp4)은 고교통 15만 스텝 PPO, 시드 200493722의 결정론적 재생이다. 하늘색은 AV, 주황색은 추적한 동일 HV다. 영상은 0.5배속이다. 표시한 범퍼 여유는 SUMO 차로 종방향 좌표와 차량 길이에서 계산한 분석값이며 정책에 추가한 입력은 아니다.

- 2번 경로의 844484877에서 0번 차로 단절 전에 1번 차로로 옮겼다. 변경 2.0초 전부터 10스텝 연속 차로 유지와 감속을 명령했다. 이 구간 같은 차로의 감지 앞차는 없었다. 속도는 48.9→44.5km/h, 상대 뒤로 들어갈 여유는 −8.53→+9.00m였다. 변경 후 관찰한 2.4초 동안 1번 차로를 유지했고 최종 완주했다.
- 대조 재생은 같은 상태에서 2초 동안 같은 차로를 유지하되 AV 가감속만 0으로 고정했다. 같은 시점의 여유는 +7.67m였다. 상대가 원래 빨랐고 감속은 추가 1.33m에 기여했다. DAgger2도 같은 평가 시드에서 완주했다.
- [11번 경로 영상](strong-example.mp4)은 시드 200763654다. 6초간 AV가 93.8→58.1km/h로 감속하는 사이, 선택한 상대 차량 뒤쪽 여유는 −7.91→+11.28m로 바뀌었다. 같은 시간 차로를 유지하고 등속으로 재생하면 상대 뒤쪽 값은 −26.26m, 앞쪽은 +15.96m로 AV가 상대를 앞서게 된다. 실제 PPO는 상대 뒤로 들어갔으나 이후 0.2초 만에 되돌아오는 등 반복 변경했다. 안정적으로 합류 차로를 유지한 사례는 2번이다.

가감속의 물리적 기여를 확인한 사례 분석이다. 모델의 의도나 PPO 학습의 단독 인과 효과를 추정하지 않는다.
