# 차로변경 전후가 보이는 PPO 고교통 재생

하늘색 차량은 AV, 주황색 차량은 변경 전에 같은 ID로 추적한 목표 차로의 차량이다. 영상의 0초는 변경 명령을 낸 시점이다. 범퍼 여유는 실제 SUMO 좌표와 두 차의 길이에서 계산한 값이다. 실제 정책 입력은 별도로 JSON의 obs에 기록했다. 동일 상태에서 목표 차로의 앞뒤 거리·상대속도 4개만 미감지 값으로 대체해 행동이 얼마나 달라지는지도 확인했다. 이 비교로 특정 차량에 대한 의식적인 판단까지 판별할 수는 없다.

- [25만 모델, 8번 경로](250000.mp4) · 시드 200263277. 0번 차로가 끝나기 전 1번 차로로 이동해 완주했다. 변경 2.4초 전 AV 56.7km/h, 상대 차량 82.3km/h였고, 변경 순간 AV 52.6km/h, 상대 뒤 범퍼 여유 9.43m였다. 변경 2.4초 전 실제 가감속 명령은 −0.059, 왼쪽 차로 앞뒤 차량 관측을 미감지로 대체하면 +0.203이었다.

- [20만 모델, 10번 경로](200000-alt.mp4) · 시드 200585694. 도로 86198708의 0번 차로는 다음 도로와 연결되지 않는다. 차로변경 4.4초 전부터 AV가 감속해 55.1→37.5km/h가 됐다. 상대 차량이 앞으로 지나가고, 뒤로 들어갈 범퍼 여유가 26.1m일 때 1번 차로로 진입했다. 변경 시 도로 경계까지 88.1m 남았으며 최종 완주했다. 변경 4.4초 전 같은 상태에서 실제 가감속 명령은 −0.196, 왼쪽 차로의 앞뒤 관측만 미감지로 치환한 명령은 +0.045였다. 실제 주행 13초 전~11초 후를 담았다.

## 8번 경로의 재가속

25만 모델, 시드 200263277을 재생해 446스텝 완주를 다시 확인했다. 차로변경 명령은 399스텝이다. 427스텝에는 앞차 flow_route_02.5가 자기 경로의 마지막 도로 844484877#1에 있었고 간격은 57.6m였다. 428스텝에 이 차량이 SUMO 도착 목록에 들어가며 앞차 관측은 미감지 (1, 1)로 바뀌었다. AV는 두 스텝 모두 도로 844484877의 1번 차로에 있었고 제한속도는 100km/h였다.

| 시점 | 실제 가감속 명령 | 현재 차로 앞차 거리·상대속도만 반대 시점 값으로 교체 |
|---|---:|---:|
| 변경 후 5.6초 | −0.057 | +0.491 |
| 변경 후 5.8초 | +0.516 | −0.030 |

이후 변경 후 7.0초에는 AV가 내부 연결도로에 진입하면서 명령이 +0.373에서 +0.685로 더 커졌다. 이때 앞차는 계속 미감지였고, 차로 연결성·밀도 등 다른 입력이 함께 바뀌었다.
