# HV 높은 트래픽: 15,000대/시간

퇴계원IC HV 전용 **높은 트래픽 운영 프로필**. `run.sumocfg`를 SUMO-GUI에서 열면 된다. 0–3600초에 총15,000대가 생성되며 모두 빠져나갈 때까지 실행한다. AV는 없다.

## 기본 조건과 차이

- 기준 `../hv_stable`은10,200대/h. 원본과 기준 시나리오는 보존한다.
- 이 프로필은 **본선 직진06번에3,600대/h,16번에1,200대/h를 추가**한다. 나머지14개 경로 수요는 동일하다.
- 따라서 남쪽 본선6,000대/h,북쪽 본선4,200대/h,기타입구4,800대/h. 모든16경로를 사용한다.
- 전 경로를 같은 비율로 늘린 조건이 아니며 실제 관측 OD도 아니다. 좁은 진출로와 일반도로까지 일괄 증량하는 대신 고속도로 본선에 높은 부하를 주는 시나리오다.
- 맵 파일은 기준과 SHA256까지 동일하다. 차로수·연결·안전거리·차선변경 권한을 완화하지 않았다.
- 지퍼 우선권과 운용속도, 버스5%, 승용차 중 비협조2%,4개 추종모델 혼합 유지. 출발 best/max 유지.
- teleport 비활성화,교차로 내부 충돌 검사 활성화. 충돌 차량을 성공 도착으로 계산하지 않는다.

## 재현

```powershell
python -X utf8 -m utils.hv_high_traffic --modes mainline_high --seeds 7201 7202 7203 --output results/my_high15000_validation
python -X utf8 -m utils.hv_high_traffic --modes mainline_high --seeds 7301 7302 7303 --duration 7200 --horizon 10800 --output results/my_high15000_long
```

최종 요약·전체 seed별 결과는 [검증 문서](../../docs/experiments/ic-hv-high15000-20261113.md) 참조.
각 파일은 검증한1시간입력과 동일하다. 2시간시험은 같은유량을2시간유지하고30,000대를생성한다.
**기존 AV 실행기에는 자동 적용하지 않았으며 AV 학습은 중단 상태다.** 이후 AV 비교에는 모든모델에 동일한이프로필을사용해야한다.
