로컬 원본 결과는 휴지통으로 이동했습니다. Git 과거 커밋에는 이전 파일이 남아 있으며 이력을 강제로 재작성하지 않았습니다. 수업 원본 data/dataset.npz는 이번 삭제 대상이 아닙니다.

현재 작업은 [ego 없는 교통 안정화](TRAFFIC.md)입니다. 기존 수집 코드는 재사용 참고용으로 남아 있지만 구형 도로를 참조하므로 새 도로용 수집기로 간주하면 안 됩니다. 도로 검증 후 입력·행동 정의를 재검토하고 새 데이터 버전을 수집해야 합니다.
