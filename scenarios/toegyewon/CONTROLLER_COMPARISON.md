# 제어기별 BC 시범 데이터 비교

ego의 종방향 제어기만 Krauss / IDM / EIDM / ACC로 바꿔 데이터를 수집합니다. **BC·PPO 자체를 학습한 결과는 아닙니다.** 기존 baseline_v1과 rules_v2는 보존합니다.

- [2026-10-31 측정 결과 및 데이터](datasets/controller_comparison_20261031_175454/COMPARISON.md)
- 재현: `python scenarios/toegyewon/collect_comparison.py --seed 1000`
- 재분석: `python scenarios/toegyewon/compare_controllers.py <원본 results 폴더>`

## 동일하게 맞춘 조건

| 항목 | 설정 |
|---|---|
| 도로 | 퇴계원IC rules_v2, 부분 검증된 차선 표시 포함 |
| ego 경로 | nw_to_east / south_to_west |
| 교통 수요 | 1,752 / 2,920 / 4,088대/시간 |
| 반복 | 조건마다 5회, 제어기당 30회, 총 120회 |
| 시드 | 1000~1029, 제어기 사이 동일한 짝 |
| ego 출발 / 관찰 제한 | 출발 요청 90초 / 삽입 후 최대 300초 |
| 시간 간격 | 0.2초 |
| ego 크기 | 길이 5m / 폭 1.8m |
| 가속 / 감속 / 긴급 감속 | 2.6 / 4.5 / 9m/s² |
| tau / minGap | 1.2초 / 2.5m |
| 목표 속도 배율 | ego와 배경 모두 1, 분산 0 |
| 차선 변경 | LC2013, 공통 파라미터 |
| 도로 규칙 | 일반 차량 실선 변경 제한, 해시로 지정한 비버스 차량 약 5% 위반 허용, ego 공통 긴급 회피 규칙 |
| 배경 제어기 분포 | Krauss 35%, IDM 승용차 25%, EIDM 20%, ACC 15%, IDM 버스 5% |

차량별 ID·종류·경로·출발 요청 시간을 명시적으로 생성하고 SHA-256으로 동일성을 확인합니다. 실제 삽입 지연과 이후 궤적은 상호작용 때문에 달라질 수 있습니다. 같은 SUMO 시드라도 제어기별 난수 소비가 달라 모든 난수 표본까지 동일한 것은 아닙니다.

공통 파라미터를 같게 지정해도 모델마다 사용 여부와 해석이 다릅니다. 예를 들어 sigma는 모든 제어기에 동일한 노이즈를 넣는 공통 스위치가 아닙니다. 모델 고유 파라미터는 SUMO 1.27.1 기본값을 사용했습니다. 이는 각 모델을 최적으로 튜닝한 비교가 아니라 **같은 물리 조건에서 기본 모델을 교체한 비교**입니다. 실제 적용된 공통 차량 파라미터도 TraCI로 읽어 대조합니다.

## 저장과 향후 학습

각 제어기 폴더에는 dataset.npz, manifest.json, quality_report.json, episode_metrics.json, splits.json을 저장합니다. 원본 전체 차량 상태 JSONL, 에피소드별 수요 파일·경고·규칙 이벤트·실행 코드 사본은 로컬 results에 유지합니다. 팀 공유용 배열과 보고서는 datasets에 둡니다.

분할은 각 경로·교통량에서 첫 3개 시드를 train, 네 번째를 validation, 다섯 번째를 test로 지정합니다. 네 제어기 모두 동일한 시드가 동일한 분할에 들어갑니다. 실패한 회차도 저장하며, 초기 BC 후보만 별도로 표시합니다. 단순 성공 필터는 정체 상황의 비중을 줄이는 편향이 있으므로 원본을 삭제하지 않습니다.

54차원 관측과 4차원 rule_context를 결합할 수 있습니다. 행동은 명령값이 아닌 실제 가속도·차선 변화입니다. 기존 수업 31차원 학습 코드에 곧바로 넣을 수 없으므로 학습 전에 입력·행동 어댑터와 유효성 마스크 처리가 필요합니다. 특히 도로 연결부에서 차선 번호가 바뀐 기록과 도착 후 없는 상태를 정상 행동으로 학습하지 않아야 합니다.

BC 비교에서는 데이터 수·조건별 구성·업데이트 수를 맞추고, PPO에서는 추가 환경 상호작용 수와 보상을 맞춥니다. 이미 보고서에 사용한 시험 시드 외에 최종 평가용 새 시드를 확보하는 것이 좋습니다.

## 해석 범위

IDM을 기준으로 상대 개선율을 계산하고, 완주율 같은 비율은 %p 차이를 씁니다. 기준값이 0이면 상대 개선율을 계산하지 않습니다. 조건별 표와 짝지은 재표집 구간도 함께 봅니다. 승차감·급제동이 좋더라도 느리게 움직이거나 정체에 갇힌 결과일 수 있습니다. 제한된 도로·시드에서 얻은 시범 제어기의 결과이며 BC+PPO의 성능 순위를 미리 확정하지 않습니다.

이번 수집에서는 네 제어기 모두 낮은 교통량의 10회만 완주했고, 나머지 20회는 시간 제한에 도달했습니다. 따라서 성공 시범만 선택하면 중간·높은 교통량의 성공적인 합류 시범은 없습니다. 이 데이터만으로 혼잡 상황까지 충분히 학습할 수 있다고 보지 말고, 후속 환경 검증과 추가 성공 시범 수집 필요성을 함께 판단해야 합니다.
