# 퇴계원IC 북쪽 남행 진입부 +400m

북쪽에서 남쪽으로 내려오는 본선의 시작 구간만400m연장한실험용맵이다. 원본은 `../toegyewon_only`에 그대로 보존했다.

| 항목 | 기존 | 변경 |
|---|---:|---:|
| 첫 분기까지 주행 거리 | 183.44m | 583.44m |
| 차로 수 | 5 | 5 |
| 변경 edge | 86198728 | 동일 ID |
| 해당 경로 | 13/14/15/16 | 동일, 길이만+400m |

- 첫 분기 노드498837378과그이후의모든도로/차로연결/우선권은보존했다.
- 기존진입부접선방향으로5개차로를평행연장했다. 새분기/차로감소/접속교차로를만들지않았다.
- lane.length만각각400m증가하고기존shape의모든점은그대로남겼다. 차로변경권한/차폭/제한속도는불변.
- 꾸민맵(`landscaped.net.xml`)에도같은XY연장을반영했다. 추가구간높이는기존입구높이8m를유지한가정이며실측고도가아니다. 기존고가구간높이는보존했다.
- 실선/점선에관한기존구간설정과장식은보존했다. 새진입준비구간의추가400m는기본차로경계표시를사용한다.
- `review.sumocfg`: 기본맵 보기. `landscape.sumocfg`: 고가/주변장식 보기.
- **HV15,000대/h주행은** `../../scenarios/hv_high15000_north400/run.sumocfg`를사용한다. review의routes파일은기존구성으로유지했으며고교통검증입력과같지않다.
- AV학습은재개하지않았다. 차로변경가능거리를늘린것이지AV완주문제를해결했다고확정한것은아니다.

재생성: `python -X utf8 -m utils.extend_north_entry` (목적폴더가없을때만실행;기존결과덮어쓰기방지).
변경전후해시와차로길이: `north-extension.json`.
전체경로는기존16개동일하다. 기존검사보고서중해시가달라지는것은복사본에서제외했다.
