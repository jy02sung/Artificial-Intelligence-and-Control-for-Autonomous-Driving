# 시원님 MCW 기반: 안전게이트·차로 지정 없는 PPO

최종 모델: `road-balanced-27`. 개발 평가 후 가중치를 고정하고 새로운 교통 시드로 80회 독립 평가했다. **완주 77/80 (96.25%), AV 충돌 1/80 (1.25%), 시간초과 2/80**. 기존 MCW 목표인 **전체 완주율 ≥95%, 전체 충돌률 <5%**를 이번 평가에서 충족했다. 모든 교통 상황에서의 안전을 보장하는 결과는 아니다.

도로 중심 위치는 해당 도로의 **모든 차로 시작점 평균**이다. 특정 차로를 고르거나 차로 정답을 계산하지 않는다. 도로 ID를 포함하므로 이 결과의 적용 범위는 현재 고정 지도와 16개 경로이며, 처음 보는 지도에 대한 일반화 결과가 아니다.

251차원은 센서가 251개라는 뜻이 아니다. 도로 ID의 one-hot 표현과 기존 주변 차량 정보의 정규화 표현, 사용하지 않는 0값 슬롯도 포함한다. 관측 인덱스는 `manifest.json`의 `observation_schema_half_open`에 저장했다. 기존 차로 안내 입력 31~33·37~46은 0이고 대응 입력 가중치도 0임을 검사했다.

초기 가중치는 과거에 게이트·차로 안내가 있는 환경에서 학습된 모델이다. **이번 추가 학습과 평가는 그 기능을 제거했다.** 처음부터 도움 없이 학습한 모델이라고 표현하면 안 된다. 새 교사 행동·모방학습·수동 차로 정답·실패 시 강제 복구는 사용하지 않았다.

## 최종 보상

위험한 행동에는 학습 중 감점을 주지만, 실행 중 해당 행동을 취소하거나 다른 행동으로 바꾸지 않는다.

| 보상 항목 | 최종 설정 |
|---|---|
| 실제 주행 속도 | 스텝당 `+0.035 × 속도/vmax` |
| 실제 다음 도로 진입 | 진행 도로당 `+0.6` |
| 다음 도로 입구에 가까워짐 | 거리 감소량 × `0.015`; 거리 200m에서 제한 |
| 그다음 도로 입구에 가까워짐 | 거리 감소량 × `0.005`; 거리 300m에서 제한 |
| 완주 / 충돌 / 시간초과·기타 실패 | `+20 / -30 / -20` |
| 전방 간격 부족 | 연속적인 간격 부족 정도 × `-0.08` |
| 전방 간격 부족 상태에서 양의 가속 | 행동 전 간격 부족 정도 × 양의 가속 출력 × `-0.1` |
| 인접 앞뒤 간격이 부족한 방향으로 변경 명령 | 해당 방향의 최대 간격 부족 정도 × `-0.3` |
| 물리적으로 실행할 수 없는 변경 명령 | `-0.2` |
| 실제 차로 변경 / 2초 이내 반대 방향 재변경 | `-0.01 / 추가 -0.2` |
| 앞이 비어 있는데 저속·정지 | 앞차가 없거나 25m 초과, 속도 3m/s 미만이면 최대 `-0.08/스텝` |
| 시간 비용 | `-0.002/스텝` |

도로 목표가 바뀌는 스텝에는 거리 감소 보상을 주지 않는다. 위험값은 거리·속도에서 계산한 연속적인 특징이며 통계적으로 보정된 충돌 확률이 아니다. 정지 벌점이나 불가능한 명령 벌점도 가감속·변경을 강제하지 않는다.

## PPO 학습과 평가 조건

PPO의 기본 목적함수는 유지했다. 최종 단계의 정책/가치 학습률은 각각 `0.00002/0.0002`, gamma `0.995`, GAE lambda `0.95`, clip `0.15`, rollout `2048`, epoch `5`, minibatch `256`, 은닉층 `256×256`, 가치 손실 계수 `0.05`, 차로 엔트로피 계수 `0.001`이다. 가속은 연속 출력이고 차로 행동은 좌/유지/우 범주형 출력이다.

가치평가 손실은 공유 운전 특징으로 역전파하지 않게 분리했고, 운전 정책은 PPO 정책 손실로 학습한다. 제한시간 실패에서도 GAE를 끊어 다음 에피소드의 가치가 이전 에피소드에 섞이지 않게 했다. 최종 단계는 16개 경로를 고르게 학습하고, 에피소드마다 15% 확률로 무교통 경로 주행을 복습했다. 이는 **학습 전용**이며 최종 평가는 전부 혼잡 교통이다. 최종 단계의 혼잡 교통 학습 종료는 153완주·23충돌, 무교통은 37완주이며, 이 혼합 학습 성적을 평가 성적으로 제시하지 않는다.

선정된 모델 계보의 추가 학습량은 **505,856스텝**이다. 매 단계 optimizer를 새로 시작했다. 탈락한 별도 후보의 스텝은 이 합계에 넣지 않았다.

15,000은 실제 1시간에 무조건 모두 투입됐다는 값이 아니라 수요 설정이다. 진입 정체에 따라 실제 투입은 지연될 수 있다. 지도/교통을 쉽게 바꾸거나 감지 범위를 넓혀 목표를 맞추지 않았다. 100~200m 관측·거리별 노이즈는 이번 작업에 포함하지 않았다.

`speedMode=0`, `laneChangeMode=0`을 확인한다. 기존 실선·존재하지 않는 차로·교차로 내부 변경 제한과 물리적 속도 범위는 유지한다. 이것을 SUMO의 모든 물리·교통 규칙 제거라고 표현하지 않는다. 충돌 검사 활성화, 충돌 시 remove, 순간이동 비활성화 상태이다.

게이트만 제거한 기존 모델 실험은 39회에서 중단됐다(27완주·11충돌·1시간초과). 첫 16경로는 12완주·3충돌·1시간초과다. 이를 완료된 80회 실험으로 표시하지 않는다. 시원님 11월16일 보고서의 78/80·2충돌과 이번 원본 재현 79/80·0충돌도 구분한다. 이번에는 11월18일 합류 관측 수정이 포함된 코드를 사용했다.

## 검증과 실행

배포 파일: [코드·학습 모델·평가 원자료 ZIP (약 8 MB)](../../results/mcw_policy_only/mcw-policy-only-release-20261120.zip). ZIP SHA-256은 `4e99f3b7463eaa851a3bfb4e72ee8fffe57e87333df546f77d12e8c77b346d3e`이며, 압축 내부의 `SHA256SUMS.json`으로 개별 파일을 확인할 수 있다. ZIP 안의 보고서는 배포 링크를 추가하기 전 평가 시점의 문서이다.

검사 4개 통과: 차로 안내 함수 호출 금지, 제거한 관측 슬롯 확인, 관측 캐시 일치, 위험한 고정 명령의 실제 충돌, 선택 가능한 부분 학습 모드의 가중치 제한을 검사했다. 체크포인트 감사에서 **마지막 학습과 평가 가중치 동일, 원본과 시나리오 동일, 런타임 소스 해시 일치, 전체 PPO 정책 가중치 변경, 제거한 차로 안내 가중치 0**을 확인했다. 상세는 `road-balanced27-heldout80/verification.json`이다.

기준 MCW 저장소에서 배포 ZIP을 저장소 루트에 풀고 실행한다. 필요한 Python 패키지는 저장소 `requirements.txt`를 사용하며 같은 결과를 비교하려면 위 버전과 SUMO 1.27.1/libsumo를 맞춘다. 아래 명령은 **최종 모델을 명시**한다. `--resume`을 생략하면 초기 시원님 가중치를 사용한다.

```powershell
python -X utf8 -m utils.mcw_policy_only --stage high_real_ratio --resume results/mcw_policy_only/road-balanced27-heldout80/evaluated_model.pt --out results/mcw_policy_only/replay-final-80 --eval-seed 60001 --episodes 5 --split heldout --trace --future-goal-coef 0.005 --acceleration-risk-penalty 0.1 --invalid-command-penalty 0.2
```

이는 이미 공개된 최종 80조건의 **재현** 명령이며 새로운 독립 증거를 추가하는 것은 아니다. 결과 폴더가 이미 존재하면 다른 `--out`을 사용한다. 이 러너는 headless 평가용이며 `.sumocfg`만 GUI에서 열면 학습된 AV 정책이 자동 실행되지 않는다.

마지막 65,536스텝 학습 재실행:

```powershell
python -X utf8 -m utils.mcw_policy_only --train --stage high_real_ratio --resume results/mcw_policy_only/road-recovery-26/model.pt --out results/mcw_policy_only/retrain-final --steps 65536 --seed 27 --lr 0.00002 --critic-lr-mult 10 --value-coef 0.05 --entropy 0.001 --empty-fraction 0.15 --detach-value --future-goal-coef 0.005 --acceleration-risk-penalty 0.1 --invalid-command-penalty 0.2
```

체크포인트 검증:

```powershell
python -X utf8 -m utils.audit_mcw_policy_only --warmstart results/mcw_policy_only/road-recovery-26/model.pt --trained-checkpoint results/mcw_policy_only/road-balanced-27/model.pt --checkpoint results/mcw_policy_only/road-balanced27-heldout80/evaluated_model.pt --manifest results/mcw_policy_only/road-balanced-27/manifest.json --evaluation-manifest results/mcw_policy_only/road-balanced27-heldout80/manifest.json --baseline-manifest results/mcw_policy_only/original-80/manifest.json --out results/mcw_policy_only/replay-verification.json
```

최종 평가 모델 SHA-256: `05cc46ccd10dcb62af93288f1317370e72b70e1f0e9fe2b62a1409433b807244`.
