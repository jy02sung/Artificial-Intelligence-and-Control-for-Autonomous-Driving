## B0: 동일 행동 제약에서 통과 가능한가?

SUMO best-lane offset의 방향을 차로 변경 명령으로, 현재 차로 제한속도를 속도 목표로 사용하는 진단 제어를 적용했다. 직접 위치 이동·차로 강제 설정을 추가하지 않고 기존 env.step을 통과했다. 실선 금지, 차로 변경·속도 적용, 도로 연결은 기존과 같다. PPO 학습 결과가 아니다.

| 경로 | 도착 | 충돌 | 소요시간 | 차로 변경 요청 / 거절 |
|---|---|---|---|---|
| south_through | 성공 | 없음 | 31.6초 | 0 / 0 |
| south_to_east | 성공 | 없음 | 124.8초 | 2 / 0 |
| north_to_west | 성공 | 없음 | 94.8초 | 2 / 0 |

세 경로의 기본 시작 조건에서는 기존 행동 제약으로 통과가 가능하다. 모든 시작 차로·교통량에서 통과 가능하다는 뜻은 아니다. 도로를 쉽게 바꾸기보다 정책의 경로 선택과 관측·학습을 점검할 근거다.

## C0: 관측·행동에서 확인한 사항

- seed11 south_through는 처음에 연결 가능한 sb_in 차로3에서 오른쪽 변경 명령을 냈고, 최종 차로0에서 정지했다.
- seed11 south_to_east는 연결 가능한 차로1에서 오른쪽 변경, seed22는 같은 차로에서 왼쪽 변경 명령을 냈다. 최종 차로0/4는 south_exit 연결 차로1과 다르다.
- seed33 south_to_east는 weave 차로3에서 best-lane offset=-1을 받았지만, 관측한 진입 시점에는 차로 유지 명령을 냈다. east_ramp 연결 차로는 0·1·2다.
- best-lane 방향 관측은 존재한다. 따라서 경로 정보가 전혀 없다고 말할 수 없다. 다만 context의 분기 거리 계산은 목표 차로가 정확히 {0}인 경우만 다루어, 위 사례의 거리 입력은 -1(미검출)이었다. 목표 차로 방향과 분기 거리 안내가 일관되지 않는다.
- 보상 크기만이 원인이라고 확정할 근거는 없다. 이번 결과는 기존 정책의 무교통 경로 선택 실패와 제한된 거리 관측을 확인한 것이다.
