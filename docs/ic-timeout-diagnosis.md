# 900초 시간 초과 재현

기본 PPO 모델 `R0-11-200000/policy-200000.pt`의 평가에서 시간 초과가 발생한 7개 경로 중 평가 순서상 처음 3개를 선택했다. 교통량 base, SUMO seed 1001, 결정적 행동 선택을 유지하고 에피소드 제한만 4,500스텝에서 9,000스텝으로 변경했다(0.2초/스텝). 체크포인트 평가와 별도 실행했다.

|경로|정지한 차로와 위치|경로에 필요한 다음 도로|현재 차로가 연결된 도로|
|---|---|---|---|
|south_through|sb_in_1, 83.97m|sb_bridge|south_exit|
|south_to_east|weave_3, 32.81m|east_ramp|flyover|
|south_to_local|weave_3, 32.81m|east_ramp|flyover|

세 사례 모두 300, 600, 899.8, 1200, 1799.8초에 위치가 같았고 속도는 0m/s였다. 가속 명령은 양수였다. 지도에서 각 위치는 차로 끝이며 지정 경로로 이어지는 인접 차로가 있다. 세 사례에서 제한 시간 연장은 완주율을 개선하지 못했다. 다른 시드와 경로의 시간 초과 원인은 별도로 확인해야 한다.

기본 모델의 110회 평가에서 완주 55회(중앙값 84.8초, 최대 760.2초), 충돌 35회(그중 9회는 출발 후 1초 이내), 시간 초과 20회였다. 후속 독립 실험에서는 분기 직전 경로에 연결되는 차로 확보와 출발 직후 충돌을 구분해 검증한다.

원본 측정 파일은 팀 저장소 기준 `results/ic_campaign_v2/timeout_replay_r0.json`이다.

## 전체 실패 사례 재현

기본 모델의 시간 초과 20건(7개 경로)을 동일 교통 시드로 모두 재실행했다. 1,800초에도 20건 모두 미완주였다. 마지막 측정에서 속도와 차로 끝까지 남은 거리가 모두 0이었고, 앞차가 없으며 현재 차로는 지정된 다음 도로로 이어지지 않았다.

|정지 차로|건수|
|---|---:|
|sb_in_1|3|
|weave_3|4|
|weave_2|2|
|east_in_0|6|
|sano_wb_exit_lane_0|5|

기본 모델의 출발 1초 이내 충돌 9건을 같은 경로·시드로 재현했다. SUMO 판정은 9건 모두 측면 충돌이다. 같은 모델로 첫 1초간 차로 변경만 억제하자 9건 모두 첫 1초를 통과했다. 전체 경로 안전성은 별도로 평가한다. 원본 기록은 results/ic_campaign_v2/baseline_failure_audit.json 및 early_contact_audit.json에 있다.

후속 비교는 python -m utils.ic_failure_trials로 실행한다. 기준 모델과 출발 1초 차로 유지 설정은 동일 가중치로 110회씩 비교한다. ROUTE100은 기본 PPO에 보상 한 항목만 추가하고 동일 seed 11로 처음부터 20만 스텝 학습한다. 분기 차로 끝에서 100m 이내에 처음 관측한 시점에 다음 도로와 연결된 차로면 +0.1, 아니면 −0.1을 1회 적용한다. 짧은 구간은 진입 시점부터 평가한다. 평가용 교통 시드는 1001~1005다.
