# 14번 경로: 기존 관측·N1·N2 비교

2026-11-08: 사전 검증 및 시험 학습 완료. 본 학습은 아래 순서로 자동 실행한다. [완료 결과 자동 집계](ic-navigation-route14-results.md) · [공통 설계](ic-navigation-learning-plan.md).

## 고정 조건

04번과 동일하게 N0(기존 관측), N1(정적 경로 안내), N2(N1+경로별 차로 연결성)을 비교한다. 맵·보상·PPO 구조·행동 제약은 그대로 두고 경로만 route_14로 바꾼다. 목적지 차로로 명령을 덮어쓰는 강제 보정은 사용하지 않는다.

- 학습 seed: 11, 22, 33. 각 seed에서 N0 → N1 → N2 순서.
- 각각 새 초기화, 200,000스텝. 총 9회·1,800,000스텝.
- 학습률 0.0003, gamma 0.99. 나머지도 04번 설정 유지.
- 무교통, 학습 출발은 best 차로/max 속도.
- 각 모델 평가: 차로 0~3 × 속도 0/5/10/15/20m/s, 총 20조건. 평가 seed 20001~20020.
- **14번 입구의 차로 4는 이번 비교 평가에서 제외한다.** 04번과 평가 조건을 맞춘 것이며 모든 출발 차로 검증으로 해석하지 않는다.
- 최종 holdout 및 HV 평가는 별도다. 이번 결과만으로 최종 완주율 95% 달성을 주장하지 않는다.

## 자동 실행과 기록

`python -m utils.train_navigation_route14 train`이 학습 후 평가를 실행하고 즉시 다음 조건으로 넘어간다. `python -m utils.publish_navigation_route14`는 완료된 결과를 검증해 결과 문서만 별도 커밋·push한다. 학습 간 대기 주기는 없다.
