- 모든 접속부의 외곽과 실제 차로 중심선·내부 연결선을 8개 도면으로 펼쳐 점검했다. 사용자 지적 분기부는 SUMO 확대 화면에서도 다시 확인했다.

- 북쪽 차로 감소 위치는 다음 합류 **50m 전**, 북쪽 합류 후 **5차로**, 지도 경계 축소를 유지한다.

## 검증 근거

`maps/toegyewon_osm/geometry-review.json`에 맵 SHA256, 접속부별 입력·출력 도로와 차로 연결부 방향 차이를 기록한다. 외부 차로 선분의 최대 방향 변화 및 내부 연결선의 입·출구 접선 차이가 10도를 넘으면 검사가 실패한다. 이 기준은 이번 맵의 급격한 꺾임 재발을 찾는 검사이며 도로 설계 기준을 의미하지 않는다.

`python -m utils.audit_osm_geometry`로 68곳의 검사와 도면을 재생성할 수 있다. 도면은 `maps/toegyewon_osm/geometry-review/`에 저장된다. `layout-adjustments.json`의 `whole_map_alignment_review`에 수정한 지점을 기록했다.

차로 연결 끝점 간 5cm 초과 공백은 없었다. 현재 외부 차로 선분의 최대 방향 변화는 약 5.83도, 연결부 입·출구의 최대 접선 차이는 약 5.93도다.

무교통 기본 SUMO 운전자 시험은 기존 23건과 외부 연결별 출발 차로·도착 도로 조합 195건을 합쳐 **218건**으로 확장했다. 모두 도착했고 충돌·텔레포트가 없었다. 여러 도착 차로로 갈 수 있는 연결에서는 실제 도착 차로를 강제로 지정한 시험은 아니며, 차로별 연결 자체는 정적 검사·도면으로 별도 확인한다.

아주 짧은 도로에 5m/s로 차량을 직접 넣으면 출발 자체가 거부되는 사례가 있어, 연결별 시험은 정지 출발로 통일했다. 대표 경로 23건의 조건은 유지했다.

## 범위의 한계

이번 결과는 맵의 기하 형상과 통과 가능성 확인이다. 위성사진 대비 모든 차로 수·실선·점선의 현장 정확성, 혼잡 시 교통 용량, AV 학습 성능을 입증하지 않는다. 기존 미확인 표식과 OSM 기본 차로 정보는 import-audit.json에 그대로 표시한다. 학습·데이터 수집은 재개하지 않았다.

## 서쪽 3차로 분기 위치 추가 수정

사용자 확인에 따라 1808903388 분기점을 진행 방향으로 약 44m 이동했다. 기존 위치에서 바로 1+2차로로 분리하던 구성을 바꿔 169929488#0의 3차로를 실제 갈라지는 구간까지 연장했다. 주행 방향 오른쪽 차로(0)는 169728799로, 나머지 두 차로는 169929488#1로 이어진다. 세 도로의 곡선과 접선을 함께 조정했으며 전체 연결 관계와 차로 수는 보존했다. 위치는 사용자 화면에 맞춘 모델링 보정으로 실측 좌표는 아니다.

SUMO 확대 화면 확인, 전체 기하 검사와 정적 차로 연결 검사를 수행했다. 분기 좌표와 접근 3차로에 회귀 검사를 추가했다. 무교통 기본 운전자 218건도 전부 도착했으며 충돌·텔레포트가 없었다. 학습과 데이터 수집은 중단 상태를 유지한다.
