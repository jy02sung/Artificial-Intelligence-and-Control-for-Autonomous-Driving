## 관측 검토와 다음 단계

기존 IC 관측의 분기거리/방향은 목표 차로가 단 하나이며 그 차로가0일 때만 만들어진다. 따라서 170059994→1063527748(목표0·1·2), 1063527748→797789364(목표2), 차로감소5→4는 이 명시적 분기 안내가 빠진다. SUMO best-lane offset은 여전히 별도 입력으로 제공되므로 정보가 완전히 없다는 뜻은 아니다. 또한 동일 관측이라도 새 OSM 기하·경로는 기존 정책의 학습 분포와 다르다. 이 둘 중 어느 것이 성능 저하의 원인인지 아직 독립 실험으로 분리하지 않았다.

다음은 실패가 모인 route_04/route_14의 시작 조건 검증과 실제 관측 추적, 이후 관측만 바꾼 최소 재학습 비교다. 지금 결과는 경로별95%완주 목표에 미달하므로 혼잡 교통·보상 조합 학습·대량 수집으로 넘어가지 않는다. HV 단독 통과는 버스/위반차 혼합 교통량 시험을 대체하지 않는다.

기존 기록을 덮어쓰지 않았고 추가 학습은 하지 않았다. 원시1초 추적은 `results/toegyewon_only_v1/traces`, 사례는 `hv`, `av`, `b` 폴더에 있다.

## 재현

```powershell
python -m utils.build_toegyewon_only
python -m utils.check_toegyewon_only hv
python -m utils.check_toegyewon_only av
python -m utils.check_toegyewon_only b
```

기존 사례 파일이 있으면 중복 실행하지 않는다. 맵/코드를 변경한 후 새 비교를 할 때는 별도 결과 디렉터리 버전을 사용해야 한다.
