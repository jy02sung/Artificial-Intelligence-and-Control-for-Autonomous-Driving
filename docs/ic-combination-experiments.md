# 차로 준비·지퍼 합류·과속 벌점 조합 실험

사용자 요청에 따라 단독 성능과 관계없이 세 보상을 함께 검증한다. 차로 준비는 목적지와 연결된 차로를 평가하는 ROUTE100을 사용한다. 기본 PPO와 동일한 20만 스텝, 학습 seed 11·22·33, 교통 seed 1001~1005 및 22개 경로를 사용한다.

|조건|추가 보상|
|---|---|
|R0|기본 보상|
|COMBO|ROUTE100 + ZIP + RAMP|
|COMBO025|세 추가 보상을 각각 0.25배|

ROUTE100은 현재 분기 도로의 끝에서 100m 이내에 처음 관측한 시점에 경로 연결 차로면 +0.1, 아니면 −0.1을 한 번 준다. 100m보다 짧은 도로는 진입 직후 평가하므로 이전 도로에서 준비해야 하는 상황을 충분히 설명하는지 결과 해석에 포함한다. ZIP은 양쪽 접근 차량과 이전 합류 순서가 관측된 경우 교대 진입에 +0.1, 연속 진입에 −0.1이다. RAMP는 현재 램프 제한속도 초과 비율에 −0.1 × 시간간격/0.5를 곱한다. 종결 스텝은 기존 충돌·도착 보상을 적용한다.

먼저 seed 11에서 두 조합을 비교한다. 기본보다 완주율이 낮거나 충돌률이 높은 조합은 같은 크기에서 추가 항목을 하나씩 제외한 세 조건을 학습한다. 이후 두 조합을 seed 22·33으로 반복한다. 비교 판단에는 최종 20만 스텝 정책을 사용한다. 중간 체크포인트는 저장한다.

각 평가 에피소드에 기본 보상과 차로 준비·지퍼·과속 항목별 누적값 및 비영(0이 아닌) 발생 스텝 수를 저장한다. 경로별 완주·충돌·시간 초과, 차로 준비 관측 횟수와 성공 횟수, 지퍼 기회와 준수, 램프 과속 시간을 함께 비교한다.

작은 보상 조합의 회복은 크기의 영향에 대한 근거로 해석한다. 특정 항목을 제외했을 때 개선되면 그 항목의 현재 정의 또는 다른 항목과의 상호작용을 분석한다. 두 크기에서 악화됐다는 결과만으로 보상 개념 자체가 잘못됐다고 결론 내리지 않는다. 관측 정보, 발생 빈도, 짧은 구간의 보상 시점, 학습량도 원인이 될 수 있다. 최종 판단은 반복 seed의 편차와 함께 기록한다.

실행 명령은 `python -m utils.ic_combination_trials`이다. 진행 파일은 `results/ic_campaign_v2/combination-trials/status.json`, 결과는 같은 폴더의 `results.json` 및 각 `runs/COMBO*` 폴더에 저장된다. 기존 R0 반복 실험이 실행 중이므로 조합 실행기는 해당 조건을 중복 실행하지 않는다.
