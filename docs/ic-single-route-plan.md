# south_to_east 관측 비교 실행 계획

사용자 승인 범위: 시작 조건 검증 후 기존/수정 관측 각각 학습 및 비교, 단계별 커밋.

- [ ] 시작 조건: 위치 0m 유지. 차로 0~5 × 속도 5/15/25m/s =18개와 best 차로의 0/max 속도 2개, 총20개를 학습 전에 고정. 같은 행동 제약 진단 제어로 모두 검증하며 실패를 숨기지 않는다.
- [ ] 학습: 무교통 south_to_east 단일 경로, 기본 보상/PPO/네트워크/200,000스텝 유지. seed11의 기존·수정 관측을 처음부터 각각 학습하는 1차 대응 비교. seed1개 결과를 일반적인 우월성으로 확정하지 않는다.
- [ ] 학습 시작 조건은 차로0~5 × 속도7/17/27m/s를 균등 순환. 평가 시작 조건과 속도를 분리. 학습/평가 위치는 모두 기존0m이며 위치 일반화는 검증하지 않는다.
- [ ] 수정 관측은 기존37차원을 유지하고 추가6값 중 분기 거리와 목표 차로 방향만 일반화한다. 목표가 차로0 하나인 경우뿐 아니라 모든 경로 분기에 적용한다. 네트워크 파일·행동·보상·best-lane 방향은 유지한다.
- [ ] 동일20개 시작 조건으로 결정적 평가, 완주/충돌/시간초과/실패차로를 보고한다. 19/20 완주 및 충돌1/20이하를 초기 경험적 목표로 사용하며 실제성공확률95%의 보장은 아니다. 기본best/max도 통과해야 한다.
- [ ] 진단 실패 조건이 있으면 학습 전에 원인을 기록하고 조건을 임의로 제외하지 않는다. 코드 검증→시작 검증 결과→학습별 결과를 별도 커밋한다.

구현: utils/ic_single_route.py에 전용 환경/시작 조건/진단/학습/평가를 둔다. 기존 환경 코드는 수정하지 않는다. 결과 results/ic_single_route_v1, 문서 docs/ic-single-route-results.md. 기존 캠페인 자동 재개 금지.
