# 퇴계원IC 도로 환경 구현 계획

**목표:** 사용자 지도에 표시된 퇴계원IC와 바깥 진출입 구간을 jys 브랜치에 구현한다.
**설계:** OSM 도로 좌표·일방통행·교량 연결을 사용한다. 독립된 scenarios/toegyewon 폴더에 원자료, 재생성 스크립트, 설정, 실행기를 둔다. 기존 고속도로 학습 코드는 유지한다.
**범위:** 도로, 일반 교통류, 빨간 ego 1대, 실행·검증용 궤적 수집. PPO 학습과 기존 31차원 관측의 IC 적응은 후속 단계다.
**근거:** 사용자의 첨부 지도와 2026-10-28 회의록. 자동 회의록 지명 오류보다 사용자 지정 퇴계원IC를 우선한다.

- [x] 실제 좌표 및 위상 기반 네트워크 생성. 고가 교차에 가짜 교차로가 없는지 확인.
- [x] 엇갈림 구간을 공유하는 두 경로와 본선 양방향 등 유효한 경로 생성.
- [x] 일반 차량과 단일 ego 실행, 궤적 기록 및 여러 시드 검증.
- [x] SUMO 화면 확인, 실행 방법·가정·남은 작업 기록. 자동 GUI 캡처는 해당 PC에서 대기 문제로 제외하고 데이터 기반 구성도 제공.
- [x] jys 브랜치에 공유할 파일 검토 및 검증 결과 정리.

검증은 정적 경로 연결, 단일 ego, 핵심 루프 보존, 시뮬레이션 충돌·텔레포트·완주 여부를 확인한다. 속도·교통량·상대고도 추정값은 실측값처럼 설명하지 않는다.
