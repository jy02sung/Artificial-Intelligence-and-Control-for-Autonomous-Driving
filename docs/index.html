PROJECT OBJECTIVE

도로에서 평가까지, 하나의 흐름으로

국내 실제 도로를 바탕으로 SUMO 환경을 구축하고, 일반 차량과 함께 주행하는 자율주행 정책을 학습·평가합니다. 코드와 데이터, 실험 조건을 함께 정리해 팀원이 결과를 재현할 수 있도록 합니다.

현재 공개된 코드는 수업의 기본 고속도로 환경입니다. 특정 도로 구현이나 최종 모델 성능을 완료한 상태는 아닙니다.
