## 재현 및 결과

팀 저장소 루트에서 Python 3.10, SUMO 1.27.1, libsumo 1.27.1을 사용한다. GUI에는 기존 TraCI를 사용한다.

- 실행: `python -m utils.ic_campaign`. 동일 캠페인은 한 프로세스만 실행한다.
- 캠페인 상태: `results/ic_campaign_v2/status.json`. 실행별로 `manifest.json`, 설정 스냅샷, 단계별 모델, CSV 및 TensorBoard 로그를 저장한다. 체크포인트별 평가 원값은 `eval-스텝.json`에 저장한다.
- 결과표 생성: `python -m utils.report_ic`. 완료 표시가 있는 조건만 포함한다. 체크포인트 평가와 다른 학습 조건은 파일 단위로 구분한다.
- 저장 위치: `results/ic_campaign_v2/pilot`, `runs`, 최종 검증 통과 시 `final-data`. GitHub에는 실행 코드·설정·검증표를 기록한다.
- 예산: 핵심 R0/BLOCK/GAP/PREP/ZIP/RAMP를 1만 스텝 점검 후 각각 20만 스텝으로 비교한다. 기준·선정 조건에서 시드 11/22/33, 학습률·감마를 각각 비교한다. 채택한 정책의 최종 평가는 22경로 × 3부하 × 미사용 시드 10개다.
- 최종 수집은 **충돌률 <5%**와 팀 제안 **완주율 ≥90%**를 충족한 경우에만 진행한다. 미달 시 실패 사례 분석 단계로 전환한다. 1천만 개는 고유 transition 기준의 팀 계획이며 수업에서 집계 단위를 확인해야 한다.

## 판정과 가정

- 준비 거리는 출구로 이어지는 0번 차로, 100m 지점 통과 시 준비 여부와 진출 차로 변경 당시 거리를 기록한다. 단일 외측 차로로 빠지는 분기에만 적용한다.
- 지퍼 판정은 두 접근로의 45m 안에 차량이 모두 있을 때 직전 진입 방향과 AV의 실제 진입 방향을 비교하는 모델상의 지표다. 실제 운전자 귀책 여부에 대한 판정은 영상과 별도로 점검한다.
- 램프 속도는 모델에 지정된 램프와 차로 제한속도를 사용한다. 현장 표지 확인 전까지 지도상 가정으로 표기한다.
- R0도 동일한 경로 입력과 동일한 시간 정규화 보상을 사용한다. 지퍼·100m 보상은 사건당 ±0.1 또는 +0.1, 램프 벌점은 초과 비율을 반영한다. 가중치는 실험 후보이며 실도로 안전 기준을 뜻하지 않는다.
- 반복 실행 시 유효한 완료 표시를 기준으로 이어서 진행한다. 중단된 학습 구간은 처음부터 다시 훈련할 수 있다. 동일한 run의 설정·모델·데이터를 임의로 섞지 않는다.
