# 2차 실험: 무교통 AV 사전 검증

## 목적과 전환 기록

1차 실험은 목표 성능을 확보하지 못한 실험으로 보존한다. 완료된 결과는 유효한 비교 기록이며, H-LR seed33은 평가 도중 사용자 요청으로 중단, 감마 비교는 미실행이다. 미완료/미실행을 성능 실패 수치로 채우지 않는다. 기존 데이터·정책을 삭제하지 않는다.

목표는 경로별 완주율 95% 이상, 충돌률 5% 이하다. 무교통 통과는 실제 교통 속 목표 달성과 다르다.

## A0: 기본 시작 조건에서 재학습 없는 기능 검증

기존 R0 학습 seed11·22·33의 최종 20만 스텝 정책을 그대로 사용한다. 경로는 south_through(고속도로 직진), south_to_east(남향 출구와 루프·엇갈림), north_to_west(엇갈림 차로 선택과 서쪽 진출)이다. 이 경로들은 퇴계원 핵심 구간을 포함하며 지도/경로를 잘라서 바꾸지 않는다.

원래 평가용 base 맵·차량 타입·GUI 파일을 별도 디렉터리에 복사하고 route XML의 flow/vehicle/trip만 제거한다. 네트워크 파일 SHA256은 원본과 동일해야 한다. AV는 기존 삽입 조건 best/max, seed1001, 제한시간900초, 시간간격0.2초, 기존 보상·관측·행동 제약 유지. 매 스텝 AV 이외 차량이 없음을 확인한다.

3개 경로 × 3개 저장 정책 = 9회. 이는 기본 기능 점검이며 9회 성공률을 95% 통계 검증이라고 표현하지 않는다. 결과는 도착·충돌·시간초과·잘못된 출구 및 마지막 60초 원인 분류로 기록한다. 1초마다 경로 문맥/관측과 정책 명령을 저장한다.

## B/C: 실패 원인 검증

A0 실패 시 같은 맵과 행동 제약에서 경로를 아는 진단 제어로 통과 가능성을 확인한다. 실선·물리 제약을 우회하지 않으며 진단 제어의 성능을 PPO 성능으로 보고하지 않는다. 실패 구간의 연결 차로, 실제 관측, 거리, 차선 변경 요청과 적용 여부를 비교한다. 원인 미확인은 별도로 유지한다.

## A1: 시작 조건 강건성 평가

B/C에서 통과 가능한 시작 조건을 먼저 검증한 후 경로당20개 시작 차로·속도·위치 조건을 고정한다. seed만 바꿔 동일 무교통 주행을 복제하지 않는다. 정책3개 × 경로3개 × 조건20개 =180회. 각 정책·경로별 19/20 이상 정상 완주, 충돌1/20 이하를 요구하고 기본 시작 조건은 모두 완주해야 한다. 무교통 충돌은 기준 이내라도 원인을 조사한다. 20개 조건은 초기 평가이며 실제 성공확률95%의 통계적 보장은 아니다.

## D: 최소 조건 재학습 및 확장

환경/관측 검증 후 대표 경로 하나, 무교통, 기본 보상으로 먼저 학습한다. 관측 수정과 보상 수정은 별도 실험으로 분리한다. 각 단계 목표 통과 후 퇴계원 경로 확대 → 낮은 교통량 → 기본 교통량 → 사노IC 경로 혼합으로 확장한다. 학습에 쓰지 않은 평가 시작 조건을 별도로 유지한다.
