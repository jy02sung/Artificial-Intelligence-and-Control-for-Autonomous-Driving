# 프로젝트 최종 목적 및 완료 체크리스트

작성일: 2026-10-27

상태: 팀 논의용 초안. **실제 도로, 세부 주행 과제, 역할 분담 및 일정은 미정**입니다.

## 최종 목적

대한민국에 실제로 존재하는 도로의 특징을 SUMO에 구현하고, 일반 차량과 상호작용하는 자율주행 차량이 목표 경로를 안전하게 주행하도록 학습한다. 도로 구현부터 데이터 수집·모델 학습·성능 평가까지 연결하고, 팀원과 평가자가 같은 결과를 재현할 수 있도록 코드·데이터·결과를 정리한다.

핵심은 복잡한 도로나 새로운 알고리즘 자체가 아니라 **의미 있는 차량 상호작용, 안정적인 시뮬레이션, 검증된 주행 성능**이다.

## 사용 방법과 기준

- `[수업]`은 아래 수업 자료에서 확인한 목표·평가 항목을 정리한 것입니다. 최신 제출 공지가 나오면 그 공지를 우선합니다.
- `[권장]`은 팀의 구현·검증을 위한 제안입니다. 수업의 추가 의무로 해석하지 않습니다.
- 체크는 결과 파일·커밋·영상 등 근거를 확인한 뒤 표시합니다. 기존 고속도로 실행 성공을 최종 도로 완성으로 간주하지 않습니다.
- 담당자와 마감일은 팀에서 정하며, 아직 하지 않은 작업은 체크하지 않습니다.

## 5. 최종 성능 평가

수업 자료의 기본 성능 목표는 **충돌률 5% 이하**이며, 프로젝트 준비 자료는 **100에피소드 이상 최종 평가**를 권장합니다. 충돌률만 낮추기 위해 정지해 있는 정책을 성공으로 보지 않도록 완주와 시간 초과를 함께 확인합니다.

- [ ] [수업] 최종 모델의 충돌률을 계산하고 기본 목표 5% 이하 달성 여부를 보고한다.
- [ ] [수업 자료 권장] 최종 평가를 100에피소드 이상 수행한다.
- [ ] [권장] 학습·튜닝에 사용하지 않은 평가 시드와 교통 조건을 정한다.
- [ ] [권장] 완주율·시간 초과율·통과 시간을 충돌률과 함께 보고한다.
- [ ] [권장] 동일한 평가 조건에서 기준 정책과 학습 정책을 비교한다.
- [ ] [권장] 성공 사례와 실패 사례를 각각 분석하고 한계를 설명한다.

| 지표 | 목표 또는 결정 사항 | 실제 결과 / 근거 |
| --- | --- | --- |
| 충돌률 | 수업 기본 목표 ≤ 5% | 미측정 |
| 최종 평가 횟수 | 수업 자료 권장 ≥ 100에피소드 | 미실시 |
| 완주율 | 팀 목표 미정 | 미측정 |
| 시간 초과율 | 팀 목표 미정 | 미측정 |
| 통과 시간 | 비교 방식·목표 미정 | 미측정 |

충돌률 = 충돌이 발생한 평가 에피소드 수 / 전체 평가 에피소드 수 × 100%. 충돌 대상이 ego인지 전체 차량인지 명시하고, 원시 횟수도 함께 기록합니다. 실패한 평가를 임의로 제외하지 않습니다.
