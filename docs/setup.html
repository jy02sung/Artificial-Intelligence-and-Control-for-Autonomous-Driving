13번 경로 실행 방법

  1. 코드와 재생 파일 받기

    실행 코드 ZIP을 풀고, 재생 파일을 requirements.txt와 같은 폴더에 넣으세요. ZIP은 주행 시뮬레이션 코드와 dagger5.pt 가중치를 포함합니다.

    실행 코드 ZIP 받기재생 파일 받기 (replay_r5.py)

  2. Python과 SUMO 준비하기

    64비트 Python 3.12가 필요합니다. Windows에서는 위 폴더를 열고 탐색기 주소창에 cmd를 입력한 뒤, 아래 명령을 차례로 실행하세요. 설치는 처음 한 번만 하면 됩니다.

    py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt eclipse-sumo==1.27.1 sumo-data==1.27.1
    macOS · Linux에서 설치하기

    같은 폴더에서 터미널을 열고 실행하세요. Mac에서는 Apple Silicon 칩과 macOS 14 이상이 필요합니다.

    python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt eclipse-sumo==1.27.1 sumo-data==1.27.1

  3. 최종 모델로 주행 재생하기

    같은 창에서 아래 명령을 실행하세요. SUMO가 열리면 화면이 빨간 자율주행 차량을 따라갑니다. 주변 차량도 차체 모양으로 표시되며, 주행이 끝나면 터미널에서 결과를 확인할 수 있습니다.

    python replay_r5.py

    검증 기록에서 이 주행은 route_13 | arrival | 507 steps로 끝났습니다. arrival은 목적지에 도착했다는 뜻입니다.

    화면 없이 결과만 확인하기 
    python replay_r5.py --headless

    두 방식 모두 13번 경로의 맨 오른쪽 5차로에서 출발하며 교통 조건도 같습니다(시드 104320013).
