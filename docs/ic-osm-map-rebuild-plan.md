# 첨부 OSM 기반 맵 재구성 계획

- 사용자 요청: main의 단순화된 퇴계원IC 형상/연결을 2026-11-07 첨부 map.osm 기준으로 수정. PPO·데이터수집·보상실험 중단 유지.
- 기존 수작업 중심선/Bezier/장식 상판을 덧대지 않고 OSM을 SUMO에 직접 변환한다. 퇴계원IC 및 다운로드 범위의 사노IC/연결도로를 포함한다. 좌표를 임의로 이동하거나 차로를 임의로 추가하지 않는다.
- maps/toegyewon_osm/source.osm 원본, 재생성 스크립트, 변환 명령/경고, 도로별 lane태그와 기본값 출처를 보존한다. OSM에도 없는 차로/속도/신호주기/표선정보는 실측값으로 주장하지 않는다.
- 직접연결은 OSM 공유노드·방향·제한에 따르고, lane-to-lane 연결은 SUMO 생성 추정임을 명시한다. 정밀 높이는 제공되지 않아 layer를 임의 높이로 변환하여 경사도320% 같은 오류를 만들지 않는다. 입체교차는 공유노드가 없는 연결로 보존한다.
- 기본 view_road.py는 새 OSM 맵을 보여준다. --legacy로 기존 main 맵 재현 가능. 기존 ROAD 기반 학습환경은 새 edge ID로 마이그레이션 전 사용하지 않는다. 기존 실험폴더/정책을 덮어쓰지 않는다.
- 검증: 재생성, 주요 차로태그 일치, 잘못된 남향→외곽램프 연결 제거, 외곽램프→본선합류 존재, 경로연결 정적검사, SUMO 빈장면 로드, 실제GUI 확인. 학습/수집은 재개하지 않는다.
