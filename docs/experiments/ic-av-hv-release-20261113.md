## 확인된 실패 양상

기존 조건 충돌15회 중10회가 정책 제어 시작1초 이내, 상한 조건은14회 중3회가1초 이내였다. 같은 입구의 경로들이 같은 초기 교통 상태를 공유하므로 서로 독립된29종의 원인으로 해석하지 않는다.

- 기존03~06:0.4초에 충돌. 직전 속도24.98m/s, 차선변경 명령+1. 03의 가속 명령+0.690. 마지막 앞차 ID와 실제 충돌 상대 ID가 달라 단순 앞차 추돌로 분류할 수 없다. 출발 직후 횡방향 명령·주변 차량 간격 검증이 우선이다.
- 기존09:6초에 충돌. 직전 앞차 간격0.96m, AV27.78m/s, 앞차17.20m/s인데 가속 명령+0.963. 실제 충돌 상대가 그 앞차임을 확인했다.
- 기존10·11:24.2초에 충돌. 간격1.81m, AV27.78m/s, 앞차18.23m/s, 가속 명령+0.973. 역시 해당 앞차와 충돌했다.

따라서 이번 정책은 HV가 최종적으로 모두 빠져나가는 환경에서도 안전한 상호작용을 보장하지 않는다. 기다릴 시간을 늘리는 것만으로 위 충돌이 해결되지 않는다. 입력 관측의 의미·정규화, 초기 차선변경 안전 판정, 정책의 제동 행동을 분리 확인해야 하며 무조건 학습량 부족으로 결론내리지 않는다.

팀에는 맵/HV 환경과 이번 실패 기록은 공유할 수 있지만, AV가 검증된 완주 정책이라는 설명은 붙이지 않는다. 원시 추적·최종 상태·해시는 로컬 `results/av_hv_release_20261113`에 보존한다. 실행: `python -X utf8 -m utils.av_hv_release_check`. 실행 기준 커밋 `dbe0675`에 새 평가 스크립트를 추가한 작업 상태이며, 평가 스크립트는 이 보고서와 함께 커밋한다.
