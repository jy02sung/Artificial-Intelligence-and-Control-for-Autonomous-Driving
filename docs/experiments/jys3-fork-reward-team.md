# 팀원 담당 · 분기 통과 보상 독립 실험

**질문**　목적 경로의 올바른 다음 도로에 진입했을 때 지급하는 보상을 +0.25에서 +1로 올리면, 13번 진출과 16번 본선 복귀, 전체 완주율이 개선되는가?

| 담당 | 비교 조건 | 규모 |
|---|---|---|
| 기존 실행 PC | 분기 +0.25 고정, 완주·충돌 (+5,−15) / (+10,−15) / (+5,−5) / (+10,−5) | 4조건 × 시드 11·22·33, 12개 |
| 팀원 PC | **완주 +5, 충돌 −5 고정**, 분기 **+0.25 / +1** | 2조건 × 같은 세 시드, 6개 |

공통 기준군인 (+5,−5,+0.25)를 팀원 PC에서도 돌려 같은 환경에서 직접 비교한다. 각 정책은 무작위 초기화한 순수 PPO로 0부터 600,000 환경 스텝까지 학습한다. 경로 전진 보상은 한 주행 최대 +2, 분기 보상은 올바른 다음 도로로 넘어갈 때 분기별 최초 1회다. 일반 시간초과는 1,000스텝(200초), 잘못된 차로 끝 정지는 기존 30초 규칙을 적용한다. 둘 다 −5다. 추가 속도 보상은 0이다. 고교통 high_real_ratio(15,000대/시), 16개 경로, 동일 시드의 경로·교통·출발 차로 편성을 사용한다. 정책 입력 52칸 중 두 번째 분기 안내 2칸은 두 조건 모두 0이다.

## 팀원 PC에서 실행

새 작업 폴더에서 아래 순서로 실행한다. Windows 기준 Python 3.10, Eclipse SUMO 1.27.1을 사용하고 SUMO_HOME과 PATH를 설정한다. 원 실험의 CPU PyTorch는 2.14.0, NumPy는 2.2.6이다.

~~~powershell
git clone --branch jys3 --single-branch https://github.com/jy02sung/Artificial-Intelligence-and-Control-for-Autonomous-Driving.git jys3-fork
cd jys3-fork
python -m pip install -r requirements.txt
python -m pip install libsumo==1.27.1
python -m utils.jys3_fork_reward_team --check
python -m utils.jys3_fork_reward_team
~~~

점검 명령은 별도 프로세스에서 두 조건의 실제 보상 상수, 시드 11 초기 정책의 일치, 6개 단기 참조 파일, SUMO 초기화·관측·정책 행동 1스텝을 확인한다. 본 실행은 학습 워커 6개, 중간 평가 워커 4개를 사용한다. 가중치 파일은 65,536스텝 **재현 확인용**이다. 각 실행 폴더의 verified.json에 저장된 matched 값으로 원 모델과 가중치가 정확히 같은지 확인한다. 버전 차이로 불일치하면 보고서에 환경과 함께 기록한다.

## 중간 평가와 결과 제출

결과 폴더는 `results/jys3_ppo_comparison/pure_f/terminal_ratio/fork_reward_team_600k/`이다. 이 폴더가 이미 있으면 기존 결과를 보호하기 위해 새 실행이 중단된다.

- 50,000스텝 간격으로 600,000까지 평가한다. 50,000에서는 당시 주행을 생성한 정책을 저장해 기존 2,048스텝 PPO 업데이트 순서를 보존한다. 각 체크포인트는 학습 시드마다 고교통 64회(16경로 × 출발 조건·교통 조합 4회)다.
- screen.json에 중간 결과를 누적한다. 조건마다 3개 학습 시드 합산 완주가 가장 많은 체크포인트를 선정하고, 동률이면 충돌이 적은 쪽, 다시 동률이면 이른 시점을 선택한다.
- final.json은 학습 및 선정용과 분리한 교통 시드에서 65,536스텝·선정 모델·600,000스텝을 비교한다. 같은 시드·경로·출발 조건으로 두 보상을 대조한다. 원시 eval 파일에 주행별 종료 결과, 통과한 분기, 16번 첫 왼쪽 명령 거리, 시간초과 시 남은 거리와 최근 30초 이동이 있다.
- 팀에 전달할 때는 **각 조건의 완주·충돌·일반 시간초과·차로 끝 정지 건수와 비율**, 13번 마지막 진출, 16번 0차로 출발의 왼쪽 명령→실제 이동→본선 통과, 학습 시드별 차이를 포함한다. 13번과 16번은 각 경로 번호를 더한 교통 시드를 쓰므로 두 조건 사이의 동일 경로 비교가 짝지어진 평가다.

## 기존 단기 결과

65,536스텝의 새 교통 조건 평가 결과다. 각 행은 학습 시드 3개 × 64회다.

|분기 보상|완주|충돌|일반 시간초과|차로 끝 정지|13번 마지막 진출|16번 0차로 본선 통과|
|---|---:|---:|---:|---:|---:|---:|
|+0.25|55/192|59/192|19/192|59/192|0/12|0/6|
|+1|62/192|25/192|16/192|89/192|0/12|0/6|

+1에서 충돌이 줄고 차로 끝 정지가 늘었다. 장기 평가에서 이 변화가 유지되는지와 실제 분기 성공이 생기는지를 따로 본다.
