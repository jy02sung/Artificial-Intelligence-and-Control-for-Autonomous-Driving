# 수업 기본 BC로 기존·혼잡 시범 재비교

기준 커밋 88eb274. 프로젝트 BC의 희소 행동 재추출과 분류 손실이 수업 기본과 얼마나 다른 결과를 내는지 확인하기 위해 수업 원본 train_bc.py와 algorithms/bc.py를 그대로 사용한다. 시드 0의 무작위 초기값, Adam 0.0003, 배치 256, 50에포크, 256×256 ReLU, 연속 행동 2개의 MSE, 에피소드 단위 20% 검증, 최저 검증 MSE 모델이다. 각 시범 160회에서 128회 학습·32회 검증한다. 경로·출발차로 편성이 두 조건에 일치하도록 에피소드 ID를 부여하고 분할은 수업 코드에 맡긴다. 입력은 프로젝트에서 수집한 50차원이며 학습 분할의 평균과 표준편차를 사용한다. 외부 평가는 이전과 같은 고교통 128회에서 환경에 전달된 raw 행동과 환경의 차로 명령 양자화 판정으로 계산한다.

## 학습 설정 확인

프로젝트 작업 폴더와 수업 원본 폴더의 두 파일 SHA-256이 각각 일치했다. 학습기는 `16f4decdb2092c44a12b0e67abd271e4be43cc0b2af2c9dbec05eda2e7ae311b`, BCPolicy는 `a82bb84e53ea63e64ed1554f9344b42fd2672a1b845d6024b4ef74853ba8b4aa`이다. 입력 파일과 출력 폴더만 지정했으며 CPU에서 독립적으로 실행했다. 학습 원본 160회 안에서 에피소드를 분할한 결과 두 모델의 학습·검증 경로와 출발차로 편성이 동일했다.

| 항목 | 기존 시범 BC | 혼잡 시범 BC |
|---|---:|---:|
| 학습 / 검증 주행 | 128 / 32 | 128 / 32 |
| 학습 / 검증 스텝 | 46,436 / 11,022 | 48,007 / 11,214 |
| 학습분의 차로변경 명령 | 117 | 117 |
| 검증 MSE 최저 에포크 | 49 | 50 |
| 해당 검증 MSE | 0.003221 | 0.005150 |
| 공통 외부 전문가 시범 32회에서 올바른 방향 명령 / 차로변경 정답 | 10/29 | 11/29 |
| 공통 외부 시범에서 전문가 유지 시 발생한 차로변경 명령 | 8 | 8 |

검증 MSE는 각 학습기가 분리한 자체 검증 세트에서 계산했다. 별도 32회(11,555스텝)의 공통 전문가 관측은 모델 선정 이후에 비교했다. 저장된 학습 곡선의 최소 검증 MSE와 선정 모델을 불러와 다시 계산한 MSE가 두 조건 모두 일치했다.

재현 명령은 `python -m utils.jys3_classroom_gap_bc train`, `python -m utils.jys3_classroom_gap_bc audit`, `python -m utils.jys3_classroom_gap_bc evaluate` 순서다. 각 모델의 설정과 에포크별 손실 CSV, 최저 검증 MSE 모델, 평가 원자료는 [결과 폴더](../../results/jys3_classroom_gap_bc)에 있다. TensorBoard 로그와 변환한 입력 NPZ는 같은 로컬 결과 폴더에 있다.
## 수정 분기 환경에서의 고교통 128회

| 조건 | 완주 | 충돌 | 실제 경로 이탈 | 끝 정지 | 일반 시간초과 |
|---|---:|---:|---:|---:|---:|
| 수업 BC · 기존 시범 | 75 (58.6%) | 4 (3.1%) | 33 (25.8%) | 12 (9.4%) | 4 (3.1%) |
| 수업 BC · 혼잡 시범 | 78 (60.9%) | 5 (3.9%) | 34 (26.6%) | 10 (7.8%) | 1 (0.8%) |

두 모델 모두 이전 비교의 128개 출발 상태·시드·첫 관측 해시와 일치했다. 초기 학습 시드는 0 한 개이며 수업 기본 분할 때문에 각 시범의 80%를 실제 학습에 사용했다. 이전 프로젝트 BC와는 배치·모델·손실·분할·학습률·학습량 등이 함께 다르다.

| 합류 시점 평가 | 기존 시범 | 혼잡 시범 |
|---|---:|---:|
| 같은 전문가 관측 49개에서 대기 후 첫 허용 기회 즉시 올바른 명령 | 3/49 (6.1%) | 3/49 (6.1%) |
| 같은 49개에서 차로 유지 / 반대 방향 | 46 / 0 | 46 / 0 |
| 학생 자기 주행에서 대기 후 열린 구간 중 올바른 명령 | 6/34 | 6/36 |
| 그 6개 응답 구간의 지연 중앙값 / 평균 | 12.3초 / 25.9초 | 3.1초 / 6.2초 |
| 대기 후 틈이 열리고도 유지한 채 해당 구간에서 실패 | 26 | 24 |
| 처음부터 열려 있던 기회까지 포함해 유지한 채 해당 구간에서 실패 | 42 | 37 |

지연은 첫 허용 순간부터 이후 허용 중 명령까지의 경과시간이며 무응답 구간은 응답 수 분모에 남긴다. 끝까지 유지는 해당 도로·차로에서 첫 기회 이후 차로변경 명령 없이 실제 이탈·끝 정지·차로 끝 12m 이내 일반 시간초과로 끝난 사례다. 기존 시범 모델에서 끝까지 유지는 2·8·13·14번 각 6회, 혼잡 시범 모델에서는 5번 6회, 2·13번 각 5회였다. 수업 기준 환경의 차로 양자화 임계값 ±0.5를 사용했다. 동일 전문가 첫 기회에서 이전 프로젝트 BC의 34/49와 32/49에 비해 두 모델의 즉시 명령은 크게 줄었다. 미니배치 크기 단독 효과는 이 설계에서 분리되지 않는다.
