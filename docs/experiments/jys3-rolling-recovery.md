# Rolling Merge 잔여 시간초과의 옆 차와 정지 순서

기준 5023f70. 기존에 시간초과된 5·14번에서 옆 차량 ID·차종·위치·속도와 AV의 실제 움직임을 비교한다. 보조 실험은 50차원 관측과 원래 안전 허용 기준을 유지하고, 목표 차로 차량이 가까이서 느리게 이동하면 더 일찍 속도를 줄이는 세 가지 후보를 두 실패 시드에서 먼저 평가한다. 하나 이상 회복한 최선 후보를 같은 128회에서 비교한다. 시범 재수집과 학습은 별도 단계이다.

## 두 차량이 실제로 멈춘 순서

두 사례 모두 길이 51.07m의 170059994였다. 2차로는 1063527748로 연결되고 3차로는 844484876로 연결된다. AV와 옆 차량은 서로 반대편 연결을 필요로 했다. 종료 때 옆 차량은 앞차가 없고 SUMO 지정 정차 플래그가 0이었으며, 같은 ID로 계속 AV와 나란히 있었다. 좌우 차체가 종방향으로 겹쳐 합류 허용 기준을 충족하지 못했다. 아래 시각은 그 시점부터 종료까지 해당 속도 아래에 머문 첫 관측 시각이다.

| 경로·시드 | 옆 차량 / 길이 | 옆 차 / AV가 각각 1m/s 미만이 된 시각 | 옆 차 / AV가 각각 0.1m/s 미만이 된 시각 | 종료 때 AV 차로 끝 여유 |
|---|---|---|---|---:|
| 5 · 95380405 | flow_route_14.3, 트럭 9.0m | 64.6 / 64.8초 | 70.0 / 67.6초 | 5.29m |
| 14 · 95380614 | flow_route_05.8, 배송차 5.5m | 74.2 / 75.2초 | 78.4 / 78.0초 | 5.39m |

5번은 2→3차로가 필요한 AV와 3차로에서 본선 연결을 필요로 한 트럭이었다. 14번은 3→2차로가 필요한 AV와 2차로에서 출구 연결을 필요로 한 배송차였다. 트럭이나 배송차의 경로 정보는 원인 확인에만 썼다.

## 개선 결과

세 후보 모두 두 시드를 회복했다. 두 사례의 1m/s 미만 최장 합류 대기가 모두 0초인 queue_tail을 128회 검증 대상으로 골랐다. 새 제어는 기존 strict가 기다리는 상태에서 끝까지 70m 이내이고 목표 차로 가까이에 느린 차가 관측될 때만 동작한다. 이때 끝에서 24m를 여유로 둔 감속 상한과 목표 차로 앞차 관측 속도·간격을 함께 써 종방향 위치를 조절한다. 기존 단계와 같은 옆 차로 진입 기준을 사용했다. 5번은 2.1m/s로 차로변경해 109초에, 14번은 9.1m/s로 차로변경해 92초에 완주했다.

| 고교통 128회 | 기존 strict | queue_tail |
|---|---:|---:|
| 완주 | 125 (97.7%) | 127 (99.2%) |
| 충돌 / 실제 이탈 / 끝 정지 / 일반 시간초과 | 1 / 0 / 0 / 2 | 1 / 0 / 0 / 0 |
| 연속 10초 이상 저속 합류 대기 | 2회 | 0회 |
| 연속 5초 이상 저속 합류 대기 | 5회 | 3회 |

기존 완주 125회 전부 유지, 기존 충돌 11번 95380211은 그대로 충돌, 기존 시간초과 2회는 완주다. 시드를 맞춰 선택한 후보를 같은 패널에서 대조한 성적이며, 새 시드 일반화 성능은 별도 검증 대상이다. 기본 전문가와 시범 데이터는 그대로 유지했다.
