# BC+DAgger 가치 예측 워밍업과 원본 정책 KL을 적용한 PPO

기준 커밋 470188a. 수정 환경의 BC+DAgger 원본 SHA-256은 6690df50d70c82c1b61230e2e90d112c6ddb03af61516385e1d8c56f66a83eb3이다. 앞선 시도에서 정책 변화와 주행 악화가 함께 관찰되어 연결 방식과 보상 조합을 함께 시험한다.

정책의 공유층·가감속·차로 출력·표준편차를 고정하고 가치 출력층만 20,000 환경 스텝 학습한다. 워밍업 편성 시드 111, PPO 편성 시드 11. 이후 PPO 학습률 0.00002, 엔트로피 보너스 0, 할인율 0.995, 기존 GAE 0.95, 10에포크다. 제안에서 지정하지 않은 KL 계수는 1.0으로 정했다. 현재 정책에서 동결 원본으로의 해석적 KL(정규 가속 + 범주형 차로)을 PPO 손실에 더한다. 워밍업 시점과 종료 시점의 정책 파라미터 일치를 검사한다.

전진 상한 +6, 분기 +2.5, 도착 +10, 충돌 −10, 이탈 −8, 끝 정지·일반 시간초과 −8이다. 앞차가 없거나 25m 초과이고 속도 2m/s 미만일 때 매 스텝 −0.02와 연속 50회째 −7을 적용한다. 같은 스텝에서 기존 종료가 먼저 성립하면 그 종료를 우선한다. 2m/s는 정지 카운터에도 동일하게 적용하기로 해석했다.

고교통 15,000대/시, 50개 관측, 동일 평가군 128회. PPO 스텝을 별도로 계산하며 8,192마다 평가한다. 기존 32,768 연장 기준을 유지한다. PPO 후보는 두 평가군 합산 완주 수, 낮은 충돌 수, 이른 스텝 순으로 선정한다. 원본·선정 PPO·마지막 PPO를 별도 교통 시드 81260100 계열 64회에서 평가한다. 한 가지 결합 설계의 시험이다.

## 외부 피드백 확인

6,144스텝은 2,048스텝 롤아웃을 세 번째로 업데이트한 시점이다. 종전 KL은 직전 0.00967에서 0.07462로 7.7배, 차로변경 확률은 직전 0.78%에서 10.14%로 13.0배였다. 첫 로그 0.26% 대비 약 39배다. 서로 다른 상태 묶음에서 낸 평균이고, 6,144 당시의 주행 평가는 없다. 모방 체크포인트의 가치 출력층은 같은 시드의 초기값과 완전히 일치하지만 공유층은 지도학습으로 갱신됐다. 기록은 정책 변화의 증거이며 특정 원인의 독립 효과를 측정하지 않는다.

360스텝 뒤 완주 보상만 출발 시점으로 할인하면 기존 +0.134, 제안 +1.646이다. 360스텝은 전문가 160회 평균의 근사이고 종전 패널에서 원본 정책이 실제 완주한 115회는 평균 346.2스텝이었다. 매 스텝 전진과 분기 보상도 수익에 들어간다. 할인 길이는 경계가 아니며 에피소드별 성공 확률과 사건 시점도 중요하다.

PMH의 별도 비교는 시작 245/256 완주에서 KL 적용 243·245회, 미적용 137·174회였다. 원본 보존 근거로 참고했다. [PMH 실험](https://github.com/jy02sung/Artificial-Intelligence-and-Control-for-Autonomous-Driving/blob/2bf7d863c746bf9f25369f2dc6ab0bf6a6067577/docs/experiments/pmh-jys3-ppo-minreward/README.md)
