# BC+DAgger에서 PPO로 이어 학습할 때 충돌 벌점 비교

기준 커밋 4b5bb88. 수정 분기 환경의 BC+DAgger 가중치 `results/jys3_physical_imitation_160/BC_DAgger/dagger1.pt`에서 다시 시작한다. SHA-256은 6690df50d70c82c1b61230e2e90d112c6ddb03af61516385e1d8c56f66a83eb3이다.

충돌 벌점만 −7에서 −5로 낮춘다. 시드 11, 고교통 15,000대/시, 50개 관측, 학습률 0.0001, 전진 최대 +3, 분기 +1, 완주 +5, 이탈 −4, 정지·시간초과 −5, PPO 업데이트와 출발 편성은 같다. 기존 −7 주행을 재사용하고 −5는 8,192스텝마다 동일 128회를 고정 평가한다. 원본 115개 완주의 유지, 충돌, 실제 이탈·정지, 전문가 가속 명령이 +0.1을 넘은 2,076개 상태에서 정책이 −0.1 미만을 선택한 건수를 비교한다. 32,768의 연장 여부는 기존 실행기의 같은 기준을 따른다.

실행 명령은 `python -m utils.jys3_physical_imitation_ppo --collision -5`이다.
