# BC를 100에포크까지 늘린 결과

전문가 시범을 더 반복해서 학습하면 완주율이 오르는지 확인했다. 160회 학습 시범, 32회 검증 시범, ReLU HybridActorCritic, 초기화 시드 11, 옵티마이저와 배치 구성을 고정했다. 첫 50에포크의 에포크별 기록과 당시 최고 모델의 모든 가중치가 기존 BC 실행과 정확히 일치함을 검증한 뒤, 같은 Adam 상태로 100에포크까지 계속 학습했다.

| 비교 대상 | 실제 평가 에포크 | 오프라인 검증 점수 | 가감속 MAE | 완주 | 충돌 | 실제 이탈 | 끝 정지 / 시간초과 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 50에포크 중 검증 최고 | 48 | 0.5101 | 0.0697 | 107/128 | 17 | 4 | 0 / 0 |
| 100에포크 중 검증 최고 | 94 | 0.5276 | 0.0538 | 107/128 | 13 | 8 | 0 / 0 |
| 마지막 100에포크 | 100 | 0.4184 | 0.0539 | 107/128 | 16 | 5 | 0 / 0 |

세 모델을 같은 고교통 128회에서 결정론적으로 평가했다. 48→94에포크에서 기존에 충돌한 7건이 새로 완주했고, 기존 완주 7건은 충돌 5건과 실제 이탈 2건으로 바뀌었다. 완주율은 83.59%로 같았다. 오프라인 모방 성능에는 개선 여지가 있었고, 이 실행에서 100에포크까지 반복한 효과는 완주 건수보다 실패 유형의 변화로 나타났다.

같은 평가 패널에서 BC 후 학생 주행을 추가한 DAgger R5는 125/128 완주, 2회 충돌, 1회 실제 이탈이었다. DAgger 실험에는 학생 상태 추가, 표본 보강, 학습률 조정이 함께 들어갔다.
