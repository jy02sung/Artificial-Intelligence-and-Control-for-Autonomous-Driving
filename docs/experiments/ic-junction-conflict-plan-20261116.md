# 합류 연결부 충돌: 관측·보상 독립 비교

출발 정책은 2차 경로 보상 후보 round-02/route/policy-200000.pt로 고정한다. 기존 관측·경로 보상2배·위험 차선변경 벌점은 보존한다.

근거: 신규seed의 route01 충돌 재현2건에서 SUMO junction 충돌 확인. AV가 이미 감속하는 사례와 다른 합류 차량이 현재 차로 앞차 정보에 나타나기 전 진입하는 사례가 존재했다. route13 측면 충돌은 별도 유형이며 이 실험으로 모두 해결된다고 가정하지 않는다.

|조건|관측 변경|보상 변경|
|---|---|---|
|control|없음|없음|
|observation|국소 교차 위험·AV/상대차의 교차점 도달 예상시간 3개|없음|
|reward|없음|교차 위험과 AV 속도의 곱에 -0.1|
|combined|3개 추가|동일 벌점 추가|

기존 미사용 관측60:63만 사용해 차원63과 네트워크 크기를 유지한다. SUMO getJunctionFoes의 상충 차로 관계·거리와 현재 속도로 등속 도달시간을 계산한다. 상대차는 기존 가시거리50m 안의 실제 위치인 경우만 포함한다. 우선권 응답 플래그나 미래 행동·충돌 여부는 입력하지 않는다. 다만 SUMO가 제공하는 상충 차로 관계를 이용하는 시뮬레이션 관측이라는 가정을 문서화한다. 명령 강제 보정은 없다.

예상시간 차2초 및 양쪽5초 내 접근을 이용한 연속 위험도(0~1). 이 시간과 계수는 새 가설이며 최적값으로 확정하지 않는다. 동일 모델에서20만 스텝 추가, 학습seed11, 평가seed79101~79103, 각 저장모델 무교통16+교통48회. 최대3작업 병렬, 4조건 중 하나는 순차 투입한다. 단독·조합 성능과 위험도 발생·감속·벌점 총량을 비교한다.

실행 전 feature 경계검사와 실제 SUMO smoke, 초기 가중치 일치·강제보정0을 확인한다. 새seed320회 기존 검증은 끝까지 보존한다. 결과는 기존 길찾기 손실 및 충돌률을 함께 판정한다. 이번 평가seed 또한 선택에 사용하면 최종 검증에서 제외한다.
