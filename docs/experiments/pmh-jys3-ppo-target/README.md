# PPO로 목표(완주 ≥ 95%, 충돌 < 5%) 도달 시도 (pmh, 2026-11-26~)

상태: **진행 중**. 1차 학습·선정 평가는 끝났고, 미사용 시험 세트(48010000대 256회) 평가는 아직 하지 않았다. 안전 게이트 없음. 실행 코드 `utils/pmh_jys3_ppo_target.py`, 실행 커밋 `420748a`.

## 1차 조건

- 시작 가중치: `models/pmh/jys3_dagger10_fixed.pt` (BC+DAgger, 최종 256회 245 완주)
- 보상: 완주 +1, 충돌 −1
- 이전 PPO 미세조정(`pmh-jys3-ppo-minreward`)에서 바꾼 것
  - 가치망을 별도 256×256 MLP로 분리했다.
  - 어려운 경로(5·13·14)를 블록마다 2회씩 더 넣었다.
  - KL 고정 β를 0, 0.1, 0.3 세 값으로 비교했다.
- 그대로 둔 것: 가치망 사전학습, 시작 σ 0.22, jys3 PPO 설정(학습률 1e-4 고정)
- 학습: 204,800스텝, 학습 seed 11·12
- 선정 평가: 체크포인트마다 26010000대 64회 + 29010000대 64회 = 128회

- **관찰**: 가치망을 분리해도 KL 고정이 없으면(sep0) 무너졌다. 마지막 체크포인트 충돌이 24~33건이다. 따라서 공유 몸통은 붕괴의 유일한 원인이 아니다.
- **관찰**: β 0.1·0.3은 시작 수준(121~124/128)을 유지했다. 126~127까지 오른 체크포인트도 있지만 128회의 표본 변동과 구분되지 않는다.
- 다음: 미사용 시험 세트 평가는 아직 하지 않았다. 사용자 요청에 따라 M0 arrival 실험을 먼저 진행한다.
