# 저장된 BC와 BC+DAgger의 수정 분기 환경 재평가

기존 분기에서 SUMO가 지정 경로로 갈 수 없는 차로 끝에 차량을 세운 현상이 모방 정책의 기존 성적에 얼마나 영향을 주었는지 측정한다.

- 고교통 시간당 15,000대, 경로 16개 × 기존 교통·출발 조건 4개, 모델별 64회다. 기존 평가와 같은 시드 26010000 + 100 × 출발 조합 + 경로 번호를 사용한다.
- 기존 가중치를 고정하고 결정론적으로 운전한다. 수정 환경에 기존 도로 방향 정의와 차로 연결 관측을 복원하고 정책에는 원래의 50개 입력만 전달한다. 잘못된 외부 도로에 실제 진입하면 종료한다.
- 기존 환경 재생에서 원본 평가의 주행별 종료 사유와 종료 스텝을 확인한다. 기존·수정 환경의 출발 상태와 최초 50개 관측을 비교한다.
- 기준 커밋 33f48fe6cc7d215307ab569cc7b6a63d87ee291d. BC 가중치 SHA-256 627D82AF933AE8E94AB18322EF66F310DEB3FABFA40AFD12C43B943869CC7E03. BC+DAgger 가중치 SHA-256 EF75561D485D3012FC7CEED9534C8F870D834F7505F2AF9EA3F0EA0D878403B5.
- 실행 코드는 [고정 가중치 재평가](../../utils/jys3_imitation_physical.py)다. 주행별 기존·수정 결과는 results/jys3_imitation_physical 아래에 보관한다.
