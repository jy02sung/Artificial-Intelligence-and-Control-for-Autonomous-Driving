## 3. 가장 중요한 수정 — 분기 경계를 넘었을 때 실패를 관측할 수 있게 했다

16번이 타야 하는 본선은 `86198725`다. 진입 도로 `86198728`의 0차로는 출구 `37927508`로 연결되고 1~4차로는 본선으로 연결된다. 기존 SUMO 고정 경로에서는 0차로 끝에서 가속해도 등록된 다음 도로가 본선이어서 차가 멈췄다. 왼쪽을 명령하면 1차로로 옮겨 본선에 진입할 수 있었다. 사용자가 “잘못 나가면 벌점을 주도록 했는데, 실제로 잘못 나갈 수 있는가?”라고 물으면서 실험 기준이 바뀌었다. 수정 환경에서는 실제 차로 연결을 따라 경계를 넘으면 도로 ID를 지정 경로와 대조하고 실제 이탈을 집계한다. 물리적으로 차로가 사라지는 합류부는 여전히 옆 차로로 옮겨야 한다. ## 4. 먼저 전문가가 실제로 어떻게 운전하는지 봤다

1. **왜 학생이 합류를 못 하는가?** GUI에서 전문가는 차로 끝 전에 완전히 멈췄고, 옆 차로의 뒤차와 속도 차가 커져 필요한 간격이 더 벌어졌다. 그대로 기다리는 성공 주행만 복제할 가능성이 있었다. 학생과 같은 50개 관측으로, 옆 차를 먼저 보낼 때는 일찍 감속하고 뒤차만 가까우면 앞쪽 공간에서 속도를 맞추는 전문가를 시험했다. 실제 변경에 필요한 안전 간격을 유지한 채 대기 시간과 변경 순간 속도를 측정했다. [기존 시범 진단](jys3-physical-expert-audit.md) · [전문가 쌍대 비교](jys3-rolling-expert.md)
2. **램프 위 차량 때문에 아래 도로의 시야가 가려지는가?** 지도에서 확인한 고가 교차 20쌍을 가림 판정에 반영했다. 이후 고교통 512회에서 짧은 연결로와 본선 차로 감소부를 따로 봤다. 13번의 한 시드는 완주했어도 1m/s 미만으로 96.2초를 기다렸다. 2·8번의 본선 실패 세 건은 차로 끝에서 합류 공간을 쓰고 난 사례였다. [가림 보정과 문제 주행](jys3-rolling-visibility-validation.md) · [속도·여유 거리 재검증](jys3-rolling-margin-eval.md)
3. **어느 시점에서 전문가 튜닝을 그만둘까?** 동일 512회에서 저속 도로의 후단 여유 거리 24m→12m만 마지막으로 비교했다. 두 전문가 모두 512회 완주, 충돌·이탈·끝 정지·시간초과 0건이었다. 10초 이상 대기가 19→15건, 문제 연결로 다섯 사례 중 네 건의 저속 대기가 0초가 돼 12m 후보를 동결했다. 이후 학습용 시범은 168회 시도해 160회(57,158스텝), 오프라인 검증은 33회 시도해 32회(11,737스텝)를 채택했다. 학생 평가에서는 정지와 실패도 전부 분모에 넣었다. [전문가 선정](jys3-expert-final.md) · [시범 선별 기록](jys3-final-relu-dagger.md)

## 5. 왜 BC 다음에 DAgger를 했고, 왜 R5에서 멈췄나?

**수업 실습과 무엇이 같은가?** 최종 BC는 256×256 ReLU, Adam 학습률 0.0003, 기본 배치 256, 50에포크, 가감속 MSE를 사용했다. 고속도로의 차로 명령은 좌·유지·우 세 범주이므로 분류 손실을 사용하고, 희귀한 차로변경 정답 32개를 기본 배치에 추가했다. DAgger는 학생이 방문한 상태에 전문가가 행동을 붙여 데이터를 누적하는 온라인 모방학습이다. BC는 저장한 시범을 쓰는 오프라인 지도학습이다. 이 두 단계의 목표는 전문가 행동 예측이며 PPO 보상을 최적화하지 않는다. DAgger의 라운드 수와 학습률은 프로젝트에서 정했다. 수업 모방학습 자료 18·20쪽과 실제 변경 항목은 두 보고서에 정리했다. [수업 기본값 대조표](jys3-final-relu-dagger.md) · [강의와 DAgger 절차](jys3-uniform-dagger.md)

| 자주 나왔던 질문 | 선정 근거 |
|---|---|
| BC부터 더 학습하면 되지 않을까? | 같은 데이터를 100에포크까지 학습했다. 검증 최고 에포크는 48→94, 오프라인 점수는 0.5101→0.5276으로 올랐다. 같은 128회에서 7건을 새로 완주하고 기존 완주 7건을 잃어 완주는 107회로 같았다. 학생이 직접 가게 되는 위치에서 정답을 추가하는 실험으로 넘어갔다. [BC 100에포크 대조](jys3-final-relu-bc100.md) |
| 보강형의 효과가 단지 주행 데이터를 더 모은 덕분일까? | 같은 BC에서 기본형과 보강형을 각각 학습했다. 둘 다 144회 × 5라운드, 총 720회다. 기본형은 16경로 균등 수집·균등 배치, 보강형은 매 라운드 취약 4개 경로에 16회를 배분하고 차로변경 정답·실패 직전 3초·현재 오답 상태를 더 자주 학습했다. 경로 배분과 배치 보강을 함께 적용한 효과를 비교했다. [라운드별 대조](jys3-uniform-dagger.md) |
| 왜 발표 모델이 R5인가? | 공통 128회에서 BC·기본 R5·보강형 R5는 완주 107→118→125, 충돌 17→6→2, 이탈 4→3→1이었다. 보강형의 R4도 124회 완주했지만 R5가 한 건 더 완주하고 충돌이 3→2건으로 줄었다. 5라운드 내 연장 기준을 충족해 R8로 연장하지 않았다. [선정 기록](../../results/jys3_final_relu_dagger/selection.json) |
| 최종 발표에서 어느 수치를 보여줄까? | 선정 후 지정 256회에서 기본형→보강형 완주 234→247, 충돌 9→4였다. 추가 256회에서는 완주 246→252, 충돌 5→1이었다. 보강형은 양쪽에서 **완주율 ≥95%, 충돌률 <5%**를 충족했다. 지정 검증에는 8번 차로 끝 정지 2건이 남았고, 추가 검증은 끝 정지·일반 시간초과 모두 0건이었다. 지정 시드 묶음은 과거 프로젝트에서 쓴 적이 있어 선정 후 처음 평가한 추가 묶음도 함께 제시했다.
