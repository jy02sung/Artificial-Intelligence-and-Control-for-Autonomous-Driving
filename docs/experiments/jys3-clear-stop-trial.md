# 수정 분기 환경 · 전 구간 10초 정지 종료 시험

수정 환경에서 S2 시드 11은 60만 가중치의 독립 평가 192회 중 184회가 일반 시간초과였다. 마지막 정지 지점에서 가속을 올리면 완주와 실제 이탈이 모두 생긴 선행 재생 결과를 토대로, 기존 S2와 같은 시작점에서 정지 종료와 보상 두 값을 함께 바꾼다. 기준 커밋은 a4bab31이다.

|항목|기존 S2|새 조건|
|---|---:|---:|
|완주 / 분기 최초 정상 통과|+5 / +1|+5 / +1|
|경로 전진 누적 상한|+2|+3|
|충돌 / 실제 오진입|−7 / −5|−7 / −4|
|차로 끝 정지 / 1,000스텝 일반 시간초과|−5 / −5|−5 / −5|
|전 구간 앞이 빈 저속 정지|스텝당 0|50스텝 연속이면 −5 한 번, 종료|
 
- 정지 조건은 매 0.2초 주행 후 속도 0.5m/s 미만이고 같은 차로 선행차가 없거나 간격이 25m 초과인 경우다. 조건을 벗어나면 연속 횟수를 0으로 돌린다. 앞이 비어도 옆 차로의 차량 때문에 합류를 기다릴 수 있다. 동일 스텝에 기존 종료 사유가 발생하면 그 사유를 우선한다.
- 학습률 0.0001, 할인율 0.99, 고교통 15,000대/시, 16개 경로, 52개 관측, 동일 차로·가속 명령, 무작위 초기 PPO를 사용한다. 저장한 0스텝 가중치 해시는 기존 S2와 같다. 시드 11은 b64044aede93134c764e068419166b8585d400f217f167210f2a082ac8e90bbf, 시드 22는 f6d3db3566e161cf73a16ef1c2e98ec1b7d00a1d0147e6ac95a47c6f10cb2ac0이다.
- 시드 11·22를 30만까지 병렬 학습한다. 5만마다 동일 고교통 128회로 완주·충돌·일반 시간초과·끝 정지·10초 정지·실제 이탈을 따로 집계한다. 정책 손실·가치 손실·엔트로피·근사 KL을 기록한다.
- 기존 S2 30만 가중치도 새 조건에서 동일 128회를 고정 재생한다. 이 결과는 학습 없이 종료 사유만 옮겨가는 효과를 보여준다.
- 제안된 45~55%+에서 하한 45%를 사용한다. 30만 합산 완주율 45% 이상, 일반 시간초과율 5% 미만, 30만 완주율이 20만·25만 평균보다 높으면 승격한다. 시드 11·22는 이어서, 시드 33은 처음부터 60만까지 학습한다. 대표와 최종은 별도 교통 시드군 3개로 검증한다.
- 결과 해석에서 일반 시간초과와 10초 정지 및 끝 정지의 합계도 본다. 비교는 보상·종료 설계 전체에 대한 시험이다.
- 할인된 종료 벌점만 보면 50스텝 뒤 −5는 −3.025, −4는 −2.420이고 1,000스텝 뒤 −5는 −0.000216이다. 완주·충돌 등의 수익 순서는 사건 시점과 중간 전진·분기 보상에 따라 달라진다.

### 기존 S2 초반 학습과 최종 평가의 차이

시드 11의 0~10만 학습 스텝 안에서 끝난 실제 PPO 수집 주행 488회는 충돌 306회(62.7%), 이탈 80회(16.4%), 완주 61회(12.5%), 일반 시간초과 34회(7.0%), 끝 정지 7회(1.4%)였다. 학습은 행동을 확률적으로 뽑고, 독립 평가는 고정 가중치로 결정론적으로 달린다. 60만 모델의 95.8% 시간초과를 초반 학습에 그대로 적용하면 초기 실패의 대부분을 차지했던 충돌을 놓친다.
