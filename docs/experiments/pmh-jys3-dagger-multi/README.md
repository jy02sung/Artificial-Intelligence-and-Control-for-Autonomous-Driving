## 남은 실패 분석 (crash 6라운드, 최종 256회의 실패 17건)

상태: **완료**. 실행 코드 `utils/pmh_jys3_failure_replay.py`. 결과 `failures_crash6.json`(로컬 원본 `results/pmh_jys3_failures/crash6.json`).

### 방법

- 평가와 같은 순서(rep마다 16경로 연속)로 정책 주행을 다시 실행했다. 재생한 192회의 결과가 원래 평가와 모두 같았고, 실패 17건도 모두 재현됐다.
- 실패마다 마지막 10초의 상태를 기록했다.
  - 주행 상태: 도로·차로·위치·도로 끝까지 거리·속도
  - 정책 행동과, 같은 상태에서 전문가가 매긴 행동
  - SUMO 차로 변경 판정(막힘·겹침)
  - 명령 방향 차로의 실제 앞뒤 간격, SUMO 충돌 기록
- 같은 rep 순서를 전문가가 직접 운전하게 해서 비교했다.

- 전문가는 재생한 192회를 모두 완주했다.

### 충돌 11건: 모방 오차

- 11건 모두 정책이 차로를 바꾼 직후에 났고, 같은 순간 전문가의 판단은 "유지"였다.
- 차로를 바꾼 순간 목표 차로 차량과의 간격은 0~1.2m였다(옆에 나란히 있는 차량). SUMO도 모두 위험으로 판정했다.
- 마지막 10초 안에 전문가가 같은 방향으로 바꾸라고 한 적이 한 번도 없다. 정책이 전문가 행동을 잘못 따라 한 것이다.
- 엇갈림 구간 진입 직후 0~3m 지점에 몰려 있다(8건 중 6건). 속도는 8~12m/s였다.

### 정지 6건: 전문가 규칙의 한계

- 정책은 전문가처럼 감속하며 틈을 기다리다가 도로 끝(남은 거리 0~3m)에 멈췄다.
- 이 상태에서 전문가 행동은 계속 "가속 0, 유지"다. 차로 연결 정보로는 다른 차로로 가야 하는 상황이다(예: 844484877_0은 다음 도로와 연결이 없는 차로 소멸, 52873356_1은 0번 차로로만 진출).
- 그런데 전문가의 틈 판단(뒤 간격 > 3 + 0.5×속도 + 접근 속도 여유)은 정지 상태에서 본선 차량이 계속 다가오면 거의 만족되지 않는다.
- 전문가가 직접 운전할 때는 이 상태에 도달하지 않는다. 그래서 DAgger 라벨이 "계속 기다림"으로만 쌓이고, 학생은 도로 끝에서 멈춰 서는 행동을 배운다.

### 개선 방향

1. **충돌(모방 오차)**
   - DAgger에서 정책과 전문가의 차로 명령이 다른 상태(특히 정책은 변경, 전문가는 유지)를 더 무겁게 학습한다.
   - 엇갈림 구간 경로(5·13·14번) 수집 비중을 높인다.
2. **정지(전문가 한계)**
   - 도로 끝 정지 상태 전용 합류 규칙을 전문가에 넣는다. 예를 들어 정지했을 때는 뒤차와의 시간 간격 기준으로 틈을 받아들이고, 조금씩 전진하며 틈을 만든다.
   - 그다음 수정된 전문가로 DAgger 라벨을 다시 매긴다. 전문가의 64회 성적이 떨어지지 않는지 먼저 확인해야 한다.
