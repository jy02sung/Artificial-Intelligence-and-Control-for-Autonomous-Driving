## 해석

- DAgger를 반복하자 충돌이 크게 줄었다. 256회 기준 충돌률이 24.6%에서 4.3%로 떨어져 목표(<5%)를 만족한다. 완주율은 74.6%에서 93.4%로 올랐지만 목표(≥95%)에는 1.6%p 모자란다.
- 효과는 2라운드에서 가장 크다(독립 64회 완주 47 → 58~59). 이후에는 충돌이 조금씩 더 준다. 수집 주행의 충돌은 32 → 2건으로 줄었다.
- 충돌 직전 상태에 가중치를 준 crash가 plain보다 약간 낫다(256회 완주 +4, 충돌 −3). 차이가 작고 학습 seed가 하나라 우위가 확정되지는 않는다.
- 남은 실패는 엇갈림 구간 경로(13·14번)의 충돌과 5·7·8번의 정지·시간초과에 몰려 있다. 라운드가 진행될수록 충돌 대신 정지가 조금 늘었다(plain 6라운드 시간초과·정지 7).
- 전문가 자체의 성적은 jys3 기준 63/64다. 학생이 전문가 수준에 거의 다가갔으므로, 더 개선하려면 전문가의 13·14번 처리나 정지 판단을 함께 보는 것이 효율적이다.
