# 고교통에서 합류를 기다렸다가 성공하는 전문가 시범

기존 전문가 시범 160회 중 옆 차로의 앞뒤 간격 때문에 필요한 차로변경을 바로 할 수 없었던 주행은 63회였다. 이런 장면을 늘리기 위해 전문가의 속도 조절과 시범 선별을 각각 시험했다. 최종 BC용으로는 기존 전문가의 혼잡 선별 데이터를 권장한다. 조기 양보 후보는 기존 시간초과를 일부 회복했지만, 마지막 독립 평가와 수집 과정에서 기존 전문가가 완주한 주행도 잃었다.

## 전문가 제어 비교

기준 커밋 409981f, 실험 시작 커밋 0bcaa9f. 수정 분기 환경, high_real_ratio 시간당 15,000대, 안전게이트 해제, 50개 관측, 기존 도로 단위 안내와 물리적 차로 연결, 배경 차량의 원래 행동을 사용했다. 변경 대상은 필요한 차로변경을 바로 실행할 수 없는 상황의 전문가 가감속이다.

- 기존 전문가는 앞차 간격을 지키면서 차로 끝에 정지 여유를 둔다.
- 조기 양보 후보는 옆 차로 차량의 상대속도에 따라 먼저 보내거나 앞쪽 공간에 맞춰 전진한다. 차로변경 명령은 기존 전문가의 앞뒤 간격·상대속도·차선 조건이 충족될 때 낸다.
- 기존 실패 6회에서 단순 저속 접근은 4회 완주·2회 오진입, 앞뒤 위치 조절은 3회 완주·1회 오진입·1회 끝 정지·1회 시간초과, 조기 양보는 4회 완주·1회 끝 정지·1회 시간초과였다.
- 거의 멈춘 뒤에만 저속 전진하는 추가 후보도 기존 실패 4회를 회복했다. 기존 평가와 추가 평가 384회에서 378회 완주하고 1회 충돌했다. 같은 384회에서 기존 전문가와 조기 양보 후보는 각각 377회 완주했고 충돌과 이탈이 0회였다. 조기 양보 후보를 독립 검증 대상으로 선정했다.

| 고교통 평가 패널 | 전문가 | 완주 | 충돌 | 끝 정지 | 일반 시간초과 | 실제 경로 이탈 |
|---|---|---:|---:|---:|---:|---:|
| 기존 256회 | 기존 | 250 (97.7%) | 0 | 0 | 6 | 0 |
| 기존 256회 | 조기 양보 | 251 (98.0%) | 0 | 4 | 1 | 0 |
| 추가 128회 | 기존 | 127 (99.2%) | 0 | 0 | 1 | 0 |
| 추가 128회 | 조기 양보 | 126 (98.4%) | 0 | 2 | 0 | 0 |
| 최종 독립 128회 | 기존 | 127 (99.2%) | 0 | 0 | 1 | 0 |
| 최종 독립 128회 | 조기 양보 | 124 (96.9%) | 0 | 4 | 0 | 0 |

같은 평가 패널의 두 전문가는 교통 시드와 출발 상태가 같았다. 기존 전문가를 다시 실행했을 때 과거 256회 모두 종료 사유와 소요 스텝이 일치했다.

기존 시간초과 6회 중 5번 1회, 7번 1회, 13번 2회가 조기 양보로 완주했다. 예를 들어 5번 시드 91000805는 속도를 낮춰 옆 차에 양보하는 명령을 77스텝 내고, 대기 후 실제로 차로를 바꿔 568스텝에 완주했다. 반대로 기존 완주 중 2·8·14번 각 1회가 끝 정지로 바뀌었다. 최종 독립 패널에서도 기존 완주 3회를 잃었고, 원래 시간초과하던 1회는 끝 정지가 됐다. 독립 패널에서 새로 완주한 사례는 0회였다.

## 학습·검증 시범 구성

두 전문가를 같은 학습 후보 320회와 별도 검증 후보 64회에서 각각 주행시켰다. 두 데이터셋은 별개이며 동일 시드가 들어 있다. 학습과 검증 사이, 선정 평가와 최종 독립 평가 사이에는 시드 중복이 없다.

각 데이터셋에 16개 경로당 완주 10회, 총 160회를 담았다. 학습 시범은 경로별로 출발 차로 편성을 맞춰 96회를 시드 순서대로 고르고, 나머지 64회는 대기 후 실제 차로변경, 필요한 차로변경을 기다린 스텝, 앞차 15m 이내 노출 순으로 골랐다. 단일 차로 출발은 0차로를 썼다. 검증 시범은 별도 시드에서 경로당 완주 2회씩 담았다. 실패를 포함한 전문가 성능은 위의 전체 주행 패널에서 측정했다.

| 학습 시범 160회 | 전체 스텝 | 옆 차 때문에 합류 대기가 있었던 주행 | 해당 스텝 | 앞차 15m 이내 주행 | 좌 / 우 명령 |
|---|---:|---:|---:|---:|---:|
| 이전에 수집한 기존 데이터 | 57,458 | 63 | 2,250 | 108 | 70 / 75 |
| 이번 후보에서 기존 전문가 완주를 시드 순서대로 선택 | 57,876 | 63 | 2,381 | 95 | 70 / 75 |
| **기존 전문가 · 혼잡 선별 (기본)** | **59,221** | **74** | **3,574** | **106** | **70 / 75** |
| 조기 양보 전문가 · 혼잡 선별 (비교) | 58,626 | 74 | 2,770 | 111 | 70 / 75 |

동일한 기존 전문가·경로·후보 시드에서 선별만 바꿔, 옆 차의 간격 때문에 합류를 기다린 스텝이 2,381→3,574개(+50.1%)가 됐다. 차로변경 명령은 145개로 같았다. 실제로 대기 후 같은 도로에서 차로를 바꾼 장면은 기본 데이터에 81회, 비교 데이터에 83회 들어 있다.

‘옆 차 때문에 합류 대기’는 필요한 방향으로 차로변경이 허용되는 위치에서 옆 차로 앞뒤 간격 또는 접근 속도가 전문가의 진입 기준을 충족하지 못한 스텝이다. 대기 후 차로변경은 같은 도로에서 전문가가 실제로 차로를 바꿨는지 확인했다. 학습용 파일의 주행별 길이, 50개 관측, 가감속·차로 명령 2개, 유한값·범위·파일 해시를 확인했다. 검증 시범은 학습과 별도 폴더에 저장했다.

같은 학습 후보 320회에서 기존 전문가는 309회 완주·11회 시간초과였다. 조기 양보 후보는 이 11회를 모두 완주했다. 5번 3회, 7번 1회, 13번 5회, 14번 2회다. 이 주행의 관측과 행동을 별도의 보강 데이터로 추출했다. 반대 방향으로는 기존 완주 5회가 조기 양보에서 끝 정지가 됐다. 기존 전문가의 검증 후보 64회는 완주 63회·시간초과 1회였다.

조기 양보 후보는 학습 후보 320회 중 315회 완주하고 5회 끝 정지했다. 검증 후보 64회 중 63회 완주하고 10번 경로 시드 94700010에서 1회 충돌했다. 같은 여섯 실패 시드를 기존 전문가로 재생했을 때는 모두 완주했다. 배경 차량 양보를 강제할 근거는 이번 비교에서 나오지 않았다. 학생 모델 학습·성능은 이번 전문가 데이터 실험의 측정 범위 밖이다.
