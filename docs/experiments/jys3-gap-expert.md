# 고교통 분기·합류에서 전문가의 속도 조절 개선

기준 커밋 409981f. 기존 전문가를 보존하고 수정 분기 환경의 동일한 50개 관측과 동일한 이웃 차로 진입 기준을 사용한다. 기존 실패 6건에서 세 가지 속도 조절 후보(앞뒤 위치 정렬, 앞차 양보 강화, 끝까지 저속 접근)를 비교한다. 회복 수, 충돌·오진입, 주행 시간을 기준으로 한 후보를 정해 기존 진단 패널 256회와 별도 128회에서 대조한다. 기존 패널의 충돌·이탈 0건을 보존하는지 확인한다.

수집 시드는 평가와 분리한다. 고교통 320회(16경로 × 20회)에서 경로당 완주 10회를 선정한다. 각 출발차로 편성에서 먼저 완주한 3회와 남은 주행 중 합류 대기 후 실제 차로변경, 대기 스텝, 같은 차로 앞차 15m 이내 노출 순으로 2회를 고른다. 단일차로는 두 편성 모두 0차로다. 어려운 사례는 경로 안에서 상대적으로 선정하며 실제 혼잡 노출을 별도로 보고한다. 실패와 미선정 주행도 전체 목록에 남긴다. 별도 시드 64회에서 경로당 2회씩 32회 검증 시범을 고른다.
