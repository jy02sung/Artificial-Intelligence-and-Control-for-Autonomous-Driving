# 고가 가림 수정 후 전문가의 완주와 합류 대기

11번에서 수정한 시야 가림이 다른 경로에서도 작동하는지, 양보형 전문가가 간격이 열렸을 때 실제로 차로를 바꾸는지 검증했다. 기준 커밋은 `618c529`, 평가 코드 첫 커밋은 `f90738e`다. 수정 분기 환경, 고교통 15,000대/시, 안전게이트 OFF, 정책 관측 50개로 규칙 기반 전문가 `queue_tail`을 실행했다. 새 학습과 실패 시드 교체는 없었다.

| 출발 조건 | 완주 | 충돌 | 실제 이탈 | 차로 끝 정지 | 일반 시간초과 | 10초 이상 저속 대기 주행 |
|---|---:|---:|---:|---:|---:|---:|
| 일반 BC 시범과 같은 조건 | 160/160 | 0 | 0 | 0 | 0 | 4 |
| 혼잡 보강 BC 시범과 같은 조건 | 157/160 | 0 | 0 | 3 | 0 | 13 |
| 기존 비교 패널 | 128/128 | 0 | 0 | 0 | 0 | 0 |
| 새 시드 | 64/64 | 0 | 0 | 0 | 0 | 3 |
| 합계 | 509/512 (99.4%) | 0 | 0 | 3 (0.6%) | 0 | 20 |

저장된 두 BC 시범 묶음은 각각 경로당 10회, 160회 모두 완주였다. 원본 320개 파일의 해시, 관측 수, 행동 수를 확인했다. 표는 같은 출발 차로와 시드에서 현재 전문가를 다시 주행시킨 결과다. 512개 시드가 서로 다르며 경로당 32회씩이다. 2번은 30/32, 8번은 31/32, 나머지는 각각 32/32였다.

## 양보 후 차로변경

차로변경이 필요하고 실선이 아닌 동일 도로·차로·방향에서 간격 부족으로 기다린 구간은 240건이었다. 관측상 앞뒤 간격과 옆 차량 겹침 조건을 처음 만족한 237건 모두 같은 0.2초 스텝에 원하는 방향을 명령했고, 실제 차로 번호도 바뀌었다. 이 중 178건은 1m/s 이상에서 변경했다. 변경 속도 중앙값은 8.0m/s였다. 대기 시간 중앙값은 5.2초였다.

- 11번 95380211은 5.4초간 양보하고 18.2m/s에서 0→1차로로 바꿔 완주했다.
- 13번 68173213은 출구 준비 중 뒤차와의 간격을 확보하면서 10초 사이 9.65→14.89m/s로 속도를 높였다. 뒤쪽 관측 간격이 33.8m인 순간 2→1차로로 바꾸고 완주했다.
- 16번 95380016은 본선으로 가기 위해 차로 끝 398m 전에 0→1차로로 변경했다.

## 긴 대기가 집중된 두 곳

저속 대기는 차로변경이 막혀 속도 1m/s 미만이 연속된 시간이다. 현재 전문가에서 10초 이상이었던 20회를 골라 같은 수정 센서와 같은 교통 시드로 기존 전문가도 주행시켰다. 이 비교는 긴 대기 사례에 한정한다.

| 도로 | 현재 전문가 | 같은 조건의 기존 전문가 |
|---|---|---|
| 제한속도 40km/h, 길이 51m인 분기 연결로 `170059994` | 6회 모두 완주했으나 14.4~96.2초 저속 대기 | 같은 6회 모두 완주, 저속 대기 0~3.6초 |
| 제한속도 100km/h인 본선 `844484877` | 14회 중 11회 완주, 3회 0차로 끝 정지 | 14회 모두 완주 |

가장 큰 차이는 13번 94600413이었다. 기존 전문가는 4.8초 기다린 뒤 2.86m/s로 변경해 총 91.2초에 완주했다. 양보형은 102.8초 기다렸고, 그중 96.2초간 1m/s 미만이었다. 정지 상태에서 차로를 바꾸고 총 191.0초에 완주했다.

본선 실패 3회는 모두 필요한 0→1차로 변경의 허용 간격이 끝까지 열리지 않았다. 2번 94601102와 8번 94601308의 마지막 옆 차로 뒤쪽 관측 간격은 각각 0.53m와 0.66m였다. 2번 94601802는 옆 차량과 차체가 나란히 겹쳤다. 현재 전문가는 차로 끝 2.1~2.8m 전에서 종료됐다. 기존 전문가는 같은 세 시드에서 끝까지 약 7m를 남긴 위치에서 정지 상태로 합류하고 완주했다.

다음 비교는 허용 간격을 유지하고, 두 구간에서 접근 속도와 대기 위치를 바꾸는 것이다. 짧은 연결로에서는 장시간 정지를 줄이고, 본선에서는 합류 전에 공간을 소진하는지를 확인한다.
