# 충돌·위험 변경 보상 강화 실험 계획

Goal: 기존 근접 기준 모델을 보존하고, 경로 보상이 발생하지 않는 위험 행동에도 학습 신호를 주어 완주+충돌 100%, 충돌 5% 미만을 검증한다.
Architecture: 새 환경 하위 클래스와 실행 래퍼만 추가한다. 실행 중인 환경은 수정하지 않는다. 행동·지도·교통·학습 파라미터는 동일하게 유지한다.
Tech stack: PyTorch PPO, libSUMO, Python unittest.

## 고정 조건

round-02 route/policy-200000.pt에서 시작. 추가 200,000스텝, seed11, 기존 학습률·할인율 등 유지. 신규 입력57:63 가중치는 시작할 때만0으로 설정한다. 물리적 감지거리50m, 강제 행동/경로 보정0. 개발 평가16무교통+48교통, 통과 후보는 독립320교통 검증. 성공모델 채택 전 길찾기 퇴화도 확인한다.

## 비교 조건

|조건|관측|보상 변경|
|---|---|---|
|collision20|기준과 동일|AV 충돌 종료 보상을 -5에서 -20으로 변경(추가 -15)|
|lane4|기준과 동일|비종료 단계 위험 차선변경 벌점 -0.1risk를 -0.4risk로 변경(추가 -0.3risk)|
|anticipatory|옆 차로 위험57:60 + 합류 위험60:63, 합류 검색150m/실제 감지50m|위 두 변경 + 비종료 합류위험×속도비에 -0.1계수 적용|

마지막 조건은 조합 탐색이며 한 요소의 인과효과로 해석하지 않는다. 합류 관측만의 효과는 진행 중인50/150m 실험과 비교한다. 보상 증가는 정지 정책을 유도할 수 있어 시간초과를 별도로 판정한다. collision20은 HV끼리의 충돌에는 추가 벌점을 주지 않는다.

## 실행 확인

collision20과 anticipatory 학습을 시작했다. lane4는 대기 중이다. 중간 평가 슬롯1개를 유지하고 CPU 작업 수9개를 넘기지 않는다.

- collision20 추가학습4,096스텝: 충돌 추가 벌점5회, 합계-75. 위험 차선변경·합류 추가 벌점은0으로 독립 조건 유지.
- anticipatory 추가학습2,048스텝: 충돌 추가 벌점1회(-15), 위험 차선변경14회(약-1.719), 합류 위험51회(약-1.582). 실제 발생을 확인했으며 성능 개선 증거는 아직 아니다.
- 런타임 설정 확인: 학습 max_steps4,500×0.2초=900초, 평가54,000×0.2초=10,800초. manifest의 simulation은 학습 설정이다. 평가 시간제한을900초로 혼동하지 않는다. 두 교통 모드 모두 동일 평가 제한이며, 물리 감지거리는50m다.

## 이전 후보 추가 선별

옆 차로 위험 관측100,352모델은 교통38회 중 완주33/충돌5, 사전 안내 입력 보존100,352모델은30회 중 완주27/충돌3으로 부분 평가 보류했다. 사전 안내 입력 보존151,552모델도29회 중 완주23/충돌6으로 보류했다. 전체 평가율로 환산하지 않는다. 기존 보상 억제+위험 관측 조합100,352모델 평가는 계속 진행한다.

후속: 사전 안내 입력 보존 조건이20만스텝 학습을 완료하여 모델 해시·최종 체크포인트·CSV 마지막 행을 검증했다. 확보된 학습 슬롯에서 lane4도 시작했다. 세 안전 조건 모두 학습 중이며, 별도 슬롯에서 사전 안내 입력 보존 최종20만 모델을 평가한다.
