# M5-FT 네 가지 학습 설정과 두 출발점의 보상 비교

출발점은 최종 환경의 순수 PPO M3와 M5-FT다. M1→M2에서 같은 25만 스텝 예산으로 가치망을 분리하자 3시드 평균 완주율이 36.1%에서 50.0%로 올랐다. M2→M3의 30만 스텝 대조에서는 도로 방향 관측 교정 후 이탈률이 30.0%에서 15.4%로 내려갔다. 같은 두 시드의 M3→M5-FT에서는 576회 패널 합계 완주가 877→948건, 충돌이 139→95건이었다. 앞의 두 대조는 각 변경에 대한 근거이고, 마지막 대조는 미세조정 방식 전체의 결과다.

보상은 M0에서 실제 단독 검증한 두 값만 쓴다. 분기 +1→+2.5에서 3시드 완주가 277→464/1,728건이었으나 변경 필요 출발 완주는 0→6/624건이었다. 이 차이가 M3 학습 방식과 이미 분기를 익힌 M5-FT 정책에서도 재현되는지 각각 검증한다. M3와 M5-FT는 모두 기존 분기 보상이 +2.5이므로 각 트랙에서 +1인 대조를 둔다. 두 트랙 간 차이는 초기화 단독 효과로 해석할 수 없다.

## 외부 PC 실행

jys3 브랜치를 새 프로젝트 폴더에 내려받고 팀 SUMO·Python 환경에서 실행한다. 두 PC는 서로 독립적이다. 한 대면 두 명령을 순서대로 실행한다. 네트워크와 시작 체크포인트 및 원본 Q1 평가 자료가 브랜치에 포함돼 있다.

| 배정 | 출발점 | 각 보상 조건의 PPO | 조건 내에서 유지하는 설정 |
|---|---|---:|---|
| PC 1, ft | 선정된 M5-FT 자체. 시드 22는 +75,000, 시드 33은 +125,000 모델 | +75,000, 25,000 간격 평가 | 정책·가치망 가중치 복원, 새 Adam, lr 0.00001 고정, 차로 엔트로피 0.0005, 원래 M3 기준 Self-KL 0.08, 기존 M5 안전 보상. 추가 워밍업 없이 새 주행 시드 구간에서 시작 |
| PC 2, scratch | M3(Q1)와 동일한 시드 22·33 무작위 초기 가중치 | 0~300,000, 50,000 간격 평가 | 원래 Q1 실행 경로, 분리형 가치망·방향 관측 교정, lr 0.0001, 차로 엔트로피 0.002. Q1 대조군은 같은 예산 이내 기존 자료 재사용 |

| 보상 조건 | 올바른 분기 최초 통과 | 지정 경로 전진 누적 상한 |
|---|---:|---:|
| base (기존값) | +2.5 | +6 |
| fork1 (대조값) | +1 | +6 |

ft는 두 조건 × 2시드 × 75,000 = 30만 신규 PPO 스텝이다. scratch는 +2.5의 기존 Q1 자료를 재사용하고 +1만 2시드 × 300,000 = 60만 스텝을 새로 학습한다. 목적은 같은 출발점 안에서 분기 보상 +2.5 − +1의 성능 차이를 측정하는 것이다. 무작위 시작군의 두 정책은 각각 학습 첫 스텝부터 해당 보상을 받고, 이어학습군의 두 정책은 같은 M5-FT 가중치에서 같은 양의 후속 PPO를 받는다. 두 트랙 모두 최종 수정 분기·고가 시야 보정, 고교통 15,000대/시, 50차원 관측, 안전게이트 OFF를 사용한다.

## 로컬 네 항목 대조

모두 같은 시드의 M3 정점(22는 20만, 33은 25만)에서 출발해 M5 보상으로 PPO 15만 스텝을 진행한다. 원본 M5-FT의 워밍업 완료 가중치와 시작 정책 해시, 분리형 가치망, 교통 시드 편성, 새 Adam, 업데이트 경계를 맞춘다.

| 조건 | 원본 대비 한 가지 변경 | 확인할 내용 |
|---|---|---|
| no_warm | 가치망 선행 1만 스텝 → 0. M3 가치망 그대로 시작 | 초반 급락과 최종 완주 |
| higher_lr | 선형 감쇠 전체를 정확히 3배. 0.00003→0.00001 대신 0.00009→0.00003 | 같은 업데이트 수에서 정책 변화 폭 |
| original_entropy | 차로 엔트로피 계수 0.0005 → 0.002 | 시도·실제 변경·컷인·변경 필요 완주 |
| no_kl | Self-KL 계수 0.08 → 0 | 기존 완주 상실·신규 완주 |

```powershell
python -u -m utils.jys3_m5ft_ablation local --workers 4
```

주 비교는 동일한 +15만 체크포인트, 보조 비교는 각 시드별로 128회 선정 패널에서 고른 체크포인트다. 홀드아웃 64+256+256회는 시작 관측 해시까지 짝을 맞춘다. 결과표는 변경 조건 − 원본 M5-FT로 표시하므로, 예를 들어 no_kl의 완주 변화가 −3%p면 다른 세 설정이 같은 조건에서 Self-KL을 유지한 효과가 +3%p라는 뜻이다. 네 효과를 합산하지 않는다. 같은 패널을 반복 사용하므로 새 제출 후보의 일반화는 새 시드에서 다시 살핀다.
