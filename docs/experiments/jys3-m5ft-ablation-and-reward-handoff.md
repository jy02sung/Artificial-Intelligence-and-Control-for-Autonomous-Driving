# M3 무작위 시작 보상 실험과 로컬 M5-FT 학습 설정 대조

## 외부 PC · 처음부터 분기 보상이 학습에 미치는 영향

최종 수정 환경에서 처음부터 학습한 M0~M5의 공통 시드 22·33을 비교했다. 시드당 576회 선정 모델의 평균 완주율은 M0 17.9%, M1 35.3%, M2 52.6%, M3 76.1%, M4 73.0%, M5 54.9%였다. M3는 M4보다 충돌률도 낮았고(12.1% 대 20.1%) 변경 필요 출발 완주율도 높았다(60.3% 대 56.2%). 이 결과에 따라 외부 비교의 기본 학습법을 M3로 정했다.

분기 보상은 M0에서 +1에서 +2.5로 올리자 완주가 277에서 464/1,728건으로 늘었지만 변경 필요 출발의 완주는 0에서 6/624건으로 늘었다. 이번 질문은 방향 관측을 교정한 M3에서 동일한 보상 인상이 첫 분기 통과와 최종 완주에 어떤 영향을 주는가이다.

| 조건 | 초기 가중치 | 분기 최초 정상 통과 | 경로 전진 상한 | 학습·평가 |
|---|---|---:|---:|---|
| 기존 M3(Q1) | 무작위, 시드별 원본 초기화 | +2.5 | +6 | 0부터 실행한 기존 학습에서 30만 이내 자료 재사용 |
| 대조 | 같은 시드·동일한 초기 정책 SHA-256 | +1 | +6 | 0부터 30만 PPO 스텝, 같은 경로·교통 시드 편성 |

양쪽 모두 50차원 관측과 도로 방향 교정, 분리형 가치망, 고교통 15,000대/시, 안전게이트 OFF, lr 0.0001, 차로 엔트로피 0.002를 적용한다. +2.5 대조군의 학습된 모델 파일은 평가에만 쓴다. 각 PC에서 5만 스텝마다 128회 선정 평가를 하고, 정확히 30만인 모델과 각 조건의 선정 모델을 각각 576회에서 검증한다.


## 로컬 네 항목 대조

모두 같은 시드의 M3 정점(22는 20만, 33은 25만)에서 출발해 M5 보상으로 PPO 15만 스텝을 진행한다. 원본 M5-FT의 워밍업 완료 가중치와 시작 정책 해시, 분리형 가치망, 교통 시드 편성, 새 Adam, 업데이트 경계를 맞춘다.

| 조건 | 원본 대비 한 가지 변경 | 확인할 내용 |
|---|---|---|
| no_warm | 가치망 선행 1만 스텝 → 0. M3 가치망 그대로 시작 | 초반 급락과 최종 완주 |
| higher_lr | 선형 감쇠 전체를 정확히 3배. 0.00003→0.00001 대신 0.00009→0.00003 | 같은 업데이트 수에서 정책 변화 폭 |
| original_entropy | 차로 엔트로피 계수 0.0005 → 0.002 | 시도·실제 변경·컷인·변경 필요 완주 |
| no_kl | Self-KL 계수 0.08 → 0 | 기존 완주 상실·신규 완주 |

```powershell
python -u -m utils.jys3_m5ft_ablation local --workers 4
```

주 비교는 동일한 +15만 체크포인트, 보조 비교는 각 시드별로 128회 선정 패널에서 고른 체크포인트다. 홀드아웃 64+256+256회는 시작 관측 해시까지 짝을 맞춘다. 결과표는 변경 조건 − 원본 M5-FT로 표시하므로, 예를 들어 no_kl의 완주 변화가 −3%p면 다른 세 설정이 같은 조건에서 Self-KL을 유지한 효과가 +3%p라는 뜻이다. 네 효과를 합산하지 않는다. 같은 패널을 반복 사용하므로 새 제출 후보의 일반화는 새 시드에서 다시 살핀다.
