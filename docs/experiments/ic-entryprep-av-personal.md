# 퇴계원IC 15,000대/시간에서 새로 학습한 AV

팀의 `main` 커밋 `b10794c`에서 공개한 진입부 연장 맵과 교통 파일을 사용했다. 모든 모델의 출발 차로는 `best`, 출발 속도는 `max`이다. HV를 900초 먼저 운행한 뒤 AV 한 대를 투입했다. 각 경로의 최종 도로에서 SUMO 도착 이벤트가 발생해야 완주로 집계했다. 충돌은 SUMO가 AV를 충돌 차량으로 기록한 경우다.

| 개인 브랜치의 모델 | 완주율 | AV 충돌률 | 시간초과 | 두 목표를 모두 통과한 경로 |
|---|---:|---:|---:|---:|
| 첫 개선 모델 `risk-22` | 98.19% | 0.81% | 16/1,600 | 14/16 |
| 누적 주행거리 모델 `trip-22` | 97.75% | 1.50% | 12/1,600 | 14/16 |
| 합류 차량 관측 모델 `merge-22` | 98.19% | 0.50% | 21/1,600 | 13/16 |
| 끼어들기 후속 모델 `gap-lane-22` | 99.94% | 0.00% | 1/1,600 | 16/16 |

각 모델에 학습과 분리한 교통 시드 100개를 사용해 매 시드 16개 경로를 독립적으로 초기화했다. 네 모델의 평가 시드 집합은 서로 다르다. 같은 조건의 변경 전후 비교는 아래의 160회 대조 실험에 제시했다. `gap-lane-22`는 16개 경로 각각에서 완주율 95% 이상 및 AV 충돌률 5% 미만을 동시에 충족했다. 평가 범위는 15,000대/시간 기본 교통과 모델 학습 시드 22이다.

## 학습 방법

- 기준·risk·trip·merge 모델은 각각 처음부터 학습했다. 생성한 감속·차로 선택 예제 32,768개를 16회 학습한 뒤, 실제 SUMO 교통에서 PPO를 8,192스텝 학습했다. 공통 모델 시드는 22, 학습 교통 시드는 12001~12008이다. 끼어들기 후속 모델은 아래의 추가 학습 절차를 사용했다.
- 새 기준 모델은 기존 경로 안내와 주변 50m 관측을 사용한다. 같은 크기의 신경망으로 비교할 수 있도록 추가 입력은 0으로 채웠다.
- 개선 모델은 앞차를 120m까지 보고 거리가 줄어드는 속도를 구분한다. 옆 차로에서는 방금 투입된 차와 바짝 붙은 차도 관측한다. 경로에 연결되는 차로 방향, 차로의 시작·끝까지의 위치를 제공했다. 보상에 앞차와의 부족한 간격, 차로 변경 시 위험, 경로 연결 차로와의 차이를 반영했다.
- 평가는 학습된 신경망이 가감속과 차로 변경을 결정한다. 시범 정답을 제공한 단계는 초기 학습이다. SUMO 속도 안전 보조 및 자율 차로 변경은 팀 평가 설정인 0으로 고정했다. 실선·차로 존재 여부 등 기존 도로 제약은 적용된다.

팀의 1/16 완주·15/16 충돌은 예전에 학습한 별도 모델의 공개 기록이다. 이번 전후 비교에는 같은 초기화 방식과 학습량으로 만든 새 기준 모델을 함께 사용했다. [팀 배포 기록](ic-av-hv-release-20261113.md)

## 출구 차로에서의 시간초과와 후속 모델

`risk-22`가 05번에서 시간초과한 사례를 재생했다. 출구로 이어지는 3번 차로 바로 옆 2번 차로에서 51.07m 길이의 도로 끝까지 진행한 뒤 정지했다. 원래 입력은 도로 한 구간을 새로 진입할 때마다 출발 지점까지의 거리를 0으로 되돌렸다. 처음 출발한 후 누적 주행거리를 제공하는 `trip-22`를 같은 예제·PPO 학습량·교통 시드로 새로 학습했다. 두 모델 모두 실제 차선 변경과 가감속을 직접 결정한다.

개발 시드 20001~20020에서 300초 주행 제한으로 평가했다. 05번은 첫 모델이 18/20, 후속 모델이 19/20 완주했다. 후속 모델의 14번도 19/20 완주했다. 두 경로 각 1건의 실패는 시간초과였고 충돌은 0건이었다. 추가로 시도한 출구 접근 감속 및 옆 차로 간격 기준 변경은 개발 평가에서 시간초과가 더 잦아 채택하지 않았다. 후속 모델의 별도 검증 시드는 31001~31100이다.

## 합류 차량을 관측하는 모델

`trip-22`의 07번 충돌을 조사했을 때 AV가 차로를 유지하며 이미 감속 중인데도 다른 방향 차량과 만나는 사례가 반복됐다. `merge-22`는 80m 이내의 합류 지점에 접근하는 다른 차량의 현재 위치·속도·차량 길이를 관측한다. 두 차량이 비슷한 시간에 같은 지점에 닿을 것으로 추정하면 그 지점까지의 거리를 앞차 관측에 반영한다. 좌우 차선 변경과 가감속 명령은 이전과 같이 신경망에서 나온다. 이 모델은 같은 학습 시드·예제 수·PPO 스텝 수로 처음부터 학습했다. 별도 검증 범위는 32001~32100이다.

개발 시드 20001~20020에서 02·05·07·11·14번을 각각 20회 평가했다. 주행 제한 300초에서 99/100 완주, AV 충돌 0회, 시간초과 1회였다. 시간초과는 14번과 시드 20015의 조합에서 발생했다. 이 개발 평가를 전체 16개 경로 성적에 합산하지 않았다.

팀 시드 9101에서 처음부터 교통을 생성하면 04번은 122.6초, 09번은 43.6초에 완주했다. 이 조건에서 13번과 14번은 각각 10,800초 시간초과였다. 같은 시드의 900초 상태를 저장·복원한 별도 시험에서는 16개 모두 도착했다. 팀과 직접 비교하는 표에는 처음부터 진행한 결과를 사용했다.

새 시드 32001~32010의 같은 출발 조건 160개에서 기준 모델은 129회 완주·31회 충돌, 합류 차량을 관측하는 모델은 157회 완주·2회 충돌·1회 시간초과였다. 완주율은 80.63%에서 98.13%로, 충돌률은 19.38%에서 1.25%로 바뀌었다. 이 모델의 160회는 시드 32001~32100 평가에 포함된다.

전체 별도 시드 100개에서는 1,600회 중 완주 1,571회(98.19%), AV 충돌 8회(0.50%), 시간초과 21회(1.31%)였다. 모든 경로가 충돌률 5% 미만을 충족했다. 완주율까지 통과한 경로는 13개이다. 04번은 완주 93회·충돌 4회·시간초과 3회, 13번은 93회·1회·6회, 14번은 89회·1회·10회였다. 07·09·11번은 각각 100/100 완주했다. 삽입 실패·텔레포트·다른 출구 종료는 0회였다. [합류 차량 관측 모델의 경로별 결과](ic-entryprep-av-merge-rates.csv)

## 끼어들기 속도 조절과 추가 학습

`merge-22`에서 출발해 끼어들기 관련 보상·입력과 학습 대상을 조정했다. 05·13·14번의 정지 사례에서는 AV가 옆 차와 나란히 달리다가 51.07m 길이의 도로 `170059994` 끝에 도달했다. 변경할 차로에 앞뒤 공간이 생기도록 미리 속도를 맞추는 상황을 학습에 포함했다.

| 항목 | 기존 `merge-22` | 추가 학습 설정 |
|---|---|---|
| PPO 학습률 | 0.0003 | 0.00003 |
| PPO 클리핑 범위 | 0.2 | 0.1 |
| 차선 행동 엔트로피 계수 | 0.01 | 0.002 |
| 충돌 종료 보상 | −5 | −15 |
| 완주 종료 보상 | +2 | +8 |
| 필요한 차로로 실제 이동 | 경로 연결 차로까지의 차이에 비례한 감점 | 변경 전 앞뒤 간격 조건을 만족하면 +1.25, 같은 구간·도착 차로에 에피소드당 한 번 지급 |
| 위험하거나 불필요한 차선 명령 | 변경 후 옆 차로 위험도에 비례한 감점 | 변경 전 목표 차로와 경로 방향을 기준으로 스텝당 −0.18 |
| 사용할 수 있는 간격을 지나침 | 별도 항 없음 | 스텝당 −0.08 |
| 막힌 목표 차로 옆에서 과속 | 별도 항 없음 | 속도 차이에 따라 스텝당 최대 −0.11 |
| 주행 시간초과 | 별도 종료 감점 없음 | −6 |

스텝 길이는 0.2초이다. 앞 간격은 `3 + 0.35 × AV 속도 + 1.25 × 접근 속도`, 뒤 간격은 `3 + 0.35 × 뒤차 속도 + 1.25 × 뒤차 접근 속도`를 기준으로 판단한다. 거리는 m, 속도는 m/s 단위이며 접근 속도의 음수 값은 0으로 처리한다. 앞차 접근 감점과 경로 연결 차로 감점을 함께 적용한다. 차로 변경 보상은 변경 직전의 목표 차로 간격과 같은 도로 구간에서 실제로 발생한 차로 이동을 사용한다.

57개 입력 중 기존에 0이었던 네 자리에 필요한 차로 방향, 간격 조건 충족 여부, 합류 접근 목표 속도와 현재 속도의 차이, 즉시 차로 변경이 필요한지를 제공한다. 목표 속도는 현재 옆 차의 속도·간격과 도로 끝까지 남은 거리에서 계산한다. 가감속 및 차로 변경 명령은 학습된 신경망이 출력한다.

학습 교통 시드는 12001~12008, 모델 시드는 22이다. 모든 경로와 04·05·13·14번의 추가 출발 조건을 포함해 한 단계마다 40회씩 두 번 주행하며 예제를 모았다. 첫 수집에서는 목표 행동을 실행하고, 두 번째 수집에서는 학습 중인 신경망의 행동으로 방문한 상태에 목표 행동을 붙였다. 끼어들기 상황과 변경 직후 차로 유지 상황을 더 자주 표본으로 뽑아 학습했다.

1차 모델 `gap-adapter-22`는 새 입력 네 개의 첫 층 연결 가중치 1,024개와 가치평가 출력층을 학습했다. 상태 예제 53,755개로 초기화한 뒤 PPO를 8,192스텝 학습했다. 2차 모델 `gap-lane-22`는 1차 모델에서 시작해 차선 선택 출력층도 학습 대상으로 추가했다. 추가 상태 예제는 53,667개이며, 그중 끼어들기 관련 상태는 1,248개, 차로 변경 목표는 70개, 변경 직후 유지 상태는 1,024개다. 여기에 PPO를 8,192스텝 더 학습했다. 예제 학습률은 0.001이다. 두 단계의 추가 PPO 학습량은 총 16,384스텝이며 기존 모델까지 포함하면 24,576스텝이다. 변경 전후 비교에는 보상·입력·학습 대상·추가 학습량의 효과가 함께 반영된다.

보상만 조정한 후보, 차로 유지 예제를 추가한 후보, 예제를 확대한 후보도 개발 시드 20001~20020에서 확인했다. 예제 확대 후보의 100회 개발 평가는 완주 97회·충돌 0회·시간초과 3회였다. 14번의 두 정지와 05번의 한 정지에서 감속 지연이 남아, 위 네 입력을 추가했다. 이 100회는 02·05·07·11·14번을 각각 20회씩 실행한 개발 시험이다.

전체 가중치를 추가 학습한 `gap-context-22`는 같은 개발 시험에서 완주 98회·충돌 2회였다. 두 충돌은 02번의 단일 차로에서 발생했다. 이후 `gap-adapter-22`는 같은 100회에서 모두 완주했고, 팀 시드 9101에서도 16개 경로를 모두 완주했다. 다만 04·13번을 각각 20회 추가 확인했을 때 04번에서 충돌 3회가 발생했다. 세 충돌 직전에는 짧은 간격의 좌우 차로 재변경이 기록됐다. 이에 `gap-lane-22`에서 차선 선택 출력층과 변경 직후 유지 예제를 함께 학습했다.

`gap-lane-22`는 개발 시드 20001~20020에서 02·04·05·07·11·13·14번을 각각 20회 평가했다. 주행 제한 300초에서 140/140 완주, AV 충돌 0회, 시간초과 0회였다. 2초 이내 반대 방향 재변경도 0회였다. 이 결과와 시드 9101의 16경로 결과를 확인한 뒤 모델 가중치를 고정했다.

## 실행

저장소의 설치 안내대로 SUMO 1.27.1과 파이썬 의존성을 준비한다. 대량 평가는 같은 버전의 `libsumo`를 설치하면 시뮬레이션을 파이썬 프로세스 안에서 실행한다. 아래 명령은 저장소 최상위 폴더에서 실행한다.

현재 PC에 저장된 끼어들기 후속 모델로 04번과 09번을 SUMO-GUI에 한 경로씩 재생한다. 비교할 합류 관측 모델의 실행 폴더는 `merge-22`이다. `--gui`를 빼면 같은 모델과 교통 시드로 화면 없이 평가한다.

```powershell
python -X utf8 -m utils.entryprep_av eval --run results/entryprep_av/gap-lane-22 --seed 9101 --routes 4 9 --gui
```

이 브랜치를 받은 팀원은 [모델 패키지](../../results/entryprep_av/av-models-22.zip)를 프로젝트 최상위 폴더에 풀면 같은 위치에 가중치와 설정이 생긴다. 패키지에는 기준·risk·trip·merge·gap-adapter·gap-lane 모델과 후속 모델의 평가 CSV·평가 설정을 포함했다. 처음 복제한 저장소에서는 아래 명령으로 압축을 푼 뒤 위의 평가 명령을 실행한다.

```powershell
Expand-Archive -LiteralPath results/entryprep_av/av-models-22.zip -DestinationPath .
```

모델을 다시 학습할 때는 새 출력 폴더를 사용한다.

```powershell
python -X utf8 -m utils.entryprep_av train --run results/entryprep_av/retrain-baseline-22 --condition baseline --model-seed 22 --steps 8192 --pretrain
python -X utf8 -m utils.entryprep_av train --run results/entryprep_av/retrain-risk-22 --condition risk --model-seed 22 --steps 8192 --pretrain
python -X utf8 -m utils.entryprep_av train --run results/entryprep_av/retrain-trip-22 --condition trip --model-seed 22 --steps 8192 --pretrain
python -X utf8 -m utils.entryprep_av train --run results/entryprep_av/retrain-merge-22 --condition merge --model-seed 22 --steps 8192 --pretrain
python -X utf8 -m utils.entryprep_av train --run results/entryprep_av/retrain-gap-adapter-22 --condition gap_adapter --initial-run results/entryprep_av/merge-22 --gap-demonstrations --model-seed 22 --steps 8192
python -X utf8 -m utils.entryprep_av train --run results/entryprep_av/retrain-gap-lane-22 --condition gap_lane --initial-run results/entryprep_av/retrain-gap-adapter-22 --gap-demonstrations --model-seed 22 --steps 8192
```

팀 시드 9101의 재평가는 경로마다 교통을 처음부터 900초까지 진행한다. 위 GUI 명령의 삽입과 주행 제한은 각각 10,800초이며, 후속 모델의 기록된 9101 평가는 주행 제한 300초를 사용했다. 경로별 100회 평가의 시드는 risk 30001~30100, trip 31001~31100, merge 32001~32100, gap-lane 33001~33100이다. 한 시드에서 900초까지 한 번 운행한 뒤 난수 상태와 함께 저장하고, 16개 경로를 각각 초기화해 그 상태에서 출발한다. 저장·복원 과정에서 SUMO 차량 움직임이 달라질 수 있다. 100회 평가의 주행 제한은 팀 반복 평가 계획의 900초이다.

```powershell
python -X utf8 -m utils.entryprep_av eval --run results/entryprep_av/risk-22 --seed 9101
python -X utf8 -m utils.entryprep_av eval --run results/entryprep_av/risk-22 --seed 30001 --seeds 100 --cached-start --workers 3 --drive-limit 900
python -X utf8 -m utils.entryprep_score results/entryprep_av/risk-22/eval-snapshot-30001-30100-all-900s.csv --output results/entryprep_av/risk-22/rates.csv
python -X utf8 -m utils.entryprep_av eval --run results/entryprep_av/trip-22 --seed 31001 --seeds 100 --cached-start --workers 2 --drive-limit 900
python -X utf8 -m utils.entryprep_score results/entryprep_av/trip-22/eval-snapshot-31001-31100-all-900s.csv --first-seed 31001 --output results/entryprep_av/trip-22/rates.csv
python -X utf8 -m utils.entryprep_av eval --run results/entryprep_av/merge-22 --seed 32001 --seeds 100 --cached-start --workers 2 --drive-limit 900
python -X utf8 -m utils.entryprep_score results/entryprep_av/merge-22/eval-snapshot-32001-32100-all-900s.csv --first-seed 32001 --output results/entryprep_av/merge-22/rates.csv
python -X utf8 -m utils.entryprep_av eval --run results/entryprep_av/gap-lane-22 --seed 33001 --seeds 100 --cached-start --workers 2 --drive-limit 900
python -X utf8 -m utils.entryprep_score results/entryprep_av/gap-lane-22/eval-snapshot-33001-33100-all-900s.csv --first-seed 33001 --output results/entryprep_av/gap-lane-22/rates.csv
```

실행이 중단되면 같은 명령으로 완료된 시드부터 이어서 집계한다. 시간초과, 텔레포트, 삽입 실패, 목적지 외 종료도 모두 시도 횟수에 포함한다. 경로별 100회에서 완주 95회 이상이고 AV 충돌이 최대 4회여야 두 비율 목표를 통과한다. 한 모델을 평가한 수치이므로 다른 학습 시드나 다른 교통 분배에 적용하려면 해당 조건에서도 평가해야 한다.
