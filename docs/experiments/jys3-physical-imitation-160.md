# 수정 분기 환경의 BC와 DAgger 비교

기준 커밋 591bca8. 새 전문가 완주 시범 160회(57,458개 관측·행동 쌍)를 전부 BC 학습에 사용한다. 모델 선정용 전문가 시범은 같은 환경에서 별도로 경로당 2회씩 수집한다. 세 방법 모두 50개 관측, 16개 경로, 고교통 15,000대/시, 학습 시드 11이다.

- BC는 무작위 정책에 전문가 시범을 지도학습한다. 기존 절차의 30에포크와 검증 점수(좌·우 명령 F1 평균 − 0.1 × 가속 절대오차)를 사용한다.
- DAgger는 무작위 학생이 직접 운전한 64회의 상태에 전문가가 정답을 붙인다. 이 데이터만으로 학생을 12에포크 지도학습한다. BC+DAgger는 위의 BC가 같은 64개 조건에서 운전하고 학생 방문 상태와 최초 BC 시범을 합쳐 BC에서 이어 학습한다. 두 경우 모두 수집·갱신을 한 번 한다. 실패한 학생 주행에도 전문가 행동 라벨이 있다.
- DAgger 수집 시드는 기존 실험과 같은 27110000 계열이며 도로 상태는 학생에 따라 달라진다. 69280100 계열의 공통 전문가 검증 세트로 각 학습 내 체크포인트를 고른다. 재생 평가에는 기존 고교통 패널 26010000과 별도 패널 70310100을 쓴다. 각 패널 64회, 경로별 4회다.
- 초기 정책은 기존 알고리즘의 시드 11 초기화다. 단독 DAgger는 자체 무작위 체크포인트, BC+DAgger는 이 실험의 BC 체크포인트에서 시작한다. 최종 모델과 데이터는 results/jys3_physical_imitation_160에 저장한다.
