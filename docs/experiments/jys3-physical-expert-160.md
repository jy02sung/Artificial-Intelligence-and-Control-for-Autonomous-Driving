# 수정 분기 환경의 전문가 시범 160회

기존 시범의 전문가·관측을 유지하면서, 잘못된 외부 도로로 실제 진입할 수 있는 환경에서 새 BC용 주행을 수집한다. 기준 커밋은 04f5b79이며 규칙 기반 개선 전문가를 사용한다.

- 고교통 high_real_ratio, 시간당 15,000대, 16개 경로에 경로당 완료 시범 10개씩. 출발 차로는 0·1을 번갈아 쓰고 단일 차로에서는 0을 쓴다.
- 새 시드는 68172500 + 경로 번호 + 반복 번호 × 100이다. 실패는 별도 보존하고 동일 경로·출발 차로에서 시드에 10000을 더해 보충한다.
- 주행마다 매 스텝의 정책 관측 50개와 실제 전문가 명령 2개(가감속, 차로 방향)를 저장한다. 기존 전문가의 1홉 관측·분기 방향 정의와 1,000스텝 상한을 사용한다.
- 기존 시드 네 건(경로 3·13·14·16의 반복 번호 3)을 별도 재생해 기존 개선 전문가 시범과 배열 단위로 대조한다. 이 네 건은 새 데이터 160회에 포함하지 않는다.
- [수집 코드](../../utils/jys3_collect_physical_expert.py). 주행 결과와 해시는 results/jys3_physical_expert_160에 저장한다.

## 수집 결과

16개 경로별로 완주 시범 10개씩 총 160개를 저장했다. 관측과 전문가 행동 쌍은 57,458스텝이다. 새 시드 162회 중 160회 완주, 2회 일반 시간초과, 충돌·실제 이탈·끝 정지 각 0회였다. 7번(출발 1차로)과 13번(출발 0차로)의 시간초과는 별도 보존하고 동일 출발 차로에서 새 시드로 각 1회씩 보충했다. 완주 시범만 모은 160개와 전체 시도 162회를 구분한다.

기존 개선 전문가 시범과 같은 출발 조건의 별도 대조 4회는 모두 같은 스텝에 완주했다. 16번은 관측과 명령 배열도 완전히 일치했고, 3·13·14번은 적어도 일부 관측값과 행동값이 달랐다. 각 시범을 다시 열어 관측 50열·행동 2열의 행 수, 유한값, 행동 범위, 경로별 개수와 시드 중복 여부를 확인했다.
