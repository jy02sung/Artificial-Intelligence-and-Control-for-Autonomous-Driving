# 수정 환경 전문가 행동 재점검

재학습 설계 전에 성공 시범의 정답 오류, 규칙 자체의 한계, 학생 실패 상태에서 교사가 실제로 회복할 수 있는지를 분리해 검사했다. 새 정책을 학습하지 않았다.

## 저장 데이터

규칙 함수에 각 파일의 관측 50개를 다시 넣어 두 행동 값이 스텝마다 정확히 일치하는지 확인했다. BC 160회·57,458스텝, 검증 32회·11,548스텝, R1~R5 학생 640회·208,707스텝, 제외한 시간초과 2회·2,000스텝에서 불일치가 없었다. BC와 제외한 실패 파일의 저장 해시도 일치했다. 일치는 저장 과정의 점검이며 행동 적절성은 아래 별도 주행으로 확인했다.

성공 시범에서 관측된 동일 차로 앞차 간격 15m 미만이고 접근 중인 688스텝 중 가속 명령이 +0.1을 넘은 경우는 같은 13번 시범의 연속 2스텝이었다. 간격 14.04·14.48m, 접근속도 0.16·0.40m/s, 가속 명령 +0.12·+0.11이었다. 접근 중 앞차와 TTC가 2초 미만인 21스텝에서는 +0.1 초과 가속이 0건이었다. 가려짐·노이즈를 포함한 정책 입력 기준이다. 앞차 미감지 때 −0.5 미만 감속한 149스텝은 전부 제한속도 초과, 다음 도로에 적합하지 않은 차로, 또는 실제 차로변경 명령 중 하나 이상에 해당했다. 차로변경 명령 145개 중 도로 밖 방향은 0개였고, 반대 방향 명령을 5초 안에 연속으로 낸 사례도 0개였다.

## 고교통 재생

R4 최종 평가와 같은 256회에서 교사가 처음부터 끝까지 운전한 결과는 완주 250회(97.66%), 충돌 0회, 끝 정지 0회, 일반 시간초과 6회(2.34%), 실제 이탈 0회였다. 같은 도로에서 실제 변경 후 5초 안에 반대 방향으로 돌아온 사례는 없었다. 학생 R4는 같은 256회 중 완주 226회, 충돌 18회, 끝 정지 1회, 일반 시간초과 0회, 실제 이탈 11회였다. 이 패널은 R4를 보며 이미 열어본 진단용 패널이다.

시간초과는 5·7·13번 각 2회다. 5번은 170059994의 2→3차로, 7번은 169929488#0의 1→0차로, 13번은 170059994의 3→2차로가 필요했다. 마지막 150스텝 모두 교사의 목표 차로 후방 간격 조건이 충족되지 않았고 차로 유지가 150번이었다. 차량은 차로 끝 6.8~9.8m 전에서 사실상 정지했다. 분기 전 차로를 잡지 못하면 속도 목표가 0으로 내려가고 새 간격을 기다리는 규칙이다. 교사의 관측에서 확보되지 않은 간격과 실제로 합류할 수 있었는지는 구분한다. 원래 BC 수집에서 제외한 7·13번 시간초과 2건도 같은 원인이었고, 성공 데이터에도 유사한 대기가 있었다. 2번의 22.8초 저속 대기 끝에 교사가 왼쪽 변경을 지시했고 해당 에피소드는 완주했다.

학생 충돌 에피소드 77회의 마지막 최대 15스텝에는 1,141개 라벨이 있다. 그중 가속 +0.1 초과 310개, 감속 −0.1 미만 609개였다. 이 라벨은 학생 주행에 붙인 전문가 명령이다. 별도로 R4의 실패 30회를 같은 원본 결과와 스텝까지 재현하고, 종료 전 마지막 15스텝이 시작되는 동일 관측에서 교사에게 제어를 넘겨 에피소드 종료까지 운전했다. 기존 충돌 18회는 전부 완주, 기존 이탈 11회는 완주 7회·시간초과 2회·이탈 1회·끝 정지 1회, 기존 끝 정지 1회는 끝 정지였다. 30회 중 25회 회복이다.
