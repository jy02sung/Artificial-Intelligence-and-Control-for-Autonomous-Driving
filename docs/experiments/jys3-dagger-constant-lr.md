# 보강형 DAgger에서 후반 학습률을 고정한 결과

발표 모델은 R1·R2에서 Adam 0.0002, R3~R5에서 0.0001을 사용했다. 후반 감쇠의 효과를 확인하기 위해 같은 R2에서 0.0002를 유지하고 R5까지 학습했다. BC 시범 160회, 전문가, 12에포크, 취약 경로 선정 규칙, 보강 배치, 에포크 선정 점수, 초기화 시드 11을 맞췄다. R3까지 수집된 주행은 공통이다. R4·R5에서는 고정 학습률 학생이 직접 주행하고 동일한 전문가가 라벨을 달았다.

## 동일한 128회 중간 평가

| 회차 | 감쇠 완주 | 고정 완주 | 감쇠 충돌 | 고정 충돌 |
|---|---:|---:|---:|---:|
| R3 | 119 | 121 | 7 | 6 |
| R4 | 124 | 123 | 3 | 3 |
| R5 | 125 | 126 | 2 | 1 |

## R5끼리 비교한 고교통 홀드아웃

각 셀은 기존 감쇠 → 0.0002 고정 순서의 건수다. 두 정책의 경로·시드·출발 차로·초기 관측 해시를 맞췄다.

| 패널 | 완주 | 충돌 | 끝 정지 | 일반 시간초과 | 실제 이탈 |
|---|---:|---:|---:|---:|---:|
| hold64_5 | 62 → 63 | 0 → 1 | 0 → 0 | 0 → 0 | 2 → 0 |
| final256 | 247 → 254 | 4 → 1 | 2 → 0 | 0 → 0 | 3 → 1 |
| novel256 | 252 → 249 | 1 → 1 | 0 → 2 | 0 → 1 | 3 → 3 |
| **합계 576회** | 561 → 566 | 5 → 3 | 2 → 2 | 0 → 1 | 8 → 4 |

완주율 97.40% → 98.26%, 충돌률 0.87% → 0.52%. 기존 완주 556건을 유지했고, 5건을 잃고 10건을 새로 완주했다. 단일 학습 시드에서 두 일정을 비교한 결과다.

## 학습률의 출처

DAgger는 학생의 방문 상태에 전문가 행동을 붙여 누적하고 지도학습을 반복하는 알고리즘이다. 원 논문 Algorithm 3.1은 지도학습기의 Adam 학습률을 지정하지 않는다. 수업 BC 코드의 기본 Adam 학습률은 0.0003이며, 프로젝트의 0.0002는 선행 DAgger 실험에서 이어온 설정이다.
