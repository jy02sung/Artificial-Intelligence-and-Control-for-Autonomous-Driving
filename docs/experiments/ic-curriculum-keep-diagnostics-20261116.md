## 안전 시연의 한계

D_safe326표본의 가감속은 모두음수이며 중앙값-0.879. lane command는 우측95·유지220·좌측11. 원궤적에 연결해 확인하면106개 변경 요청 중 같은edge에서 그스텝에 실제변경이 확인된 것은1개,105개는 그스텝의 같은edge변경으로 확인되지 않는다. edge전환 등도 포함되므로 전부 '거부된 명령'으로 단정하지 않는다. 반대목표방향 요청은0개다.

현재 B는 감속과 함께 이 lane command에도 지도손실을 적용한다. 전체 episode의 안전완주와 이후5초 여유는 검수했지만, 이 자료를 안전한 차로변경 전문가 시연이라고 부를 근거는 부족하다. 326개 category는 모두yield이며 별도의 검수된safe_change category는 없다.

후속 C 후보는 B의 감속 감독만 유지하고 검증되지 않은 횡방향 감독을 제외하는 것. 단, A/B 대표평가와50k pilot 결과를 본 뒤 한 가지 변경으로 결정한다. 현재 실행의 데이터/손실을 도중에 바꾸지 않는다. 기준 모델을 덮어쓰지 않는다.

## 차량 ID 재생과 제한된 반사실 제동 점검

route_01/79103의 선행차는12.4초까지 flow_route_07.221이었다. 12.6초에 다른 도로에서 합류하는 bus_idm 차량 flow_route_07.222로 바뀌며 gap36.63m→11.58m가 됐다. 실제 SUMO 충돌도 ego와 이 버스의 junction collision으로 확인됐다. 단순 거리 계산 오류로 단정할 근거는 없다.

모델의 최초 강한 감속은11.4초였다. merge_risk는진단용으로11.2초부터 발생했지만 현재 기준 관측의 해당 추가 슬롯에는 입력되지 않는다. 다른 관측으로 간접 추론할 가능성까지 부정하지는 않는다.

원인 분리를 위해 같은 초기화에서만 1.6초간 accel=-1로 바꾸고 다시 기준정책에 돌려주는 제한된 교사 후보 재생을 시행했다. 차로 명령은 기준정책을 유지했다.

|---|---|---:|

이 결과는 이 장면이 더 이른 감속으로 회피 가능했음을 보여준다. 정책의 성능 개선 결과가 아니며 공식 평가/시연 데이터에 넣지 않았다. 시각을 알고 누르는 제동은 학생이 이용 가능한 관측 기반 교사가 아니므로 그대로 모방 라벨로 사용하지 않는다. 후속은 더 이른 시점의 관측 가능 위험 단서와 합류 상대 도로의 차량 정보를 확인하는 것. 현재 A/B는 원래 설정으로 계속한다.
