# PMH DAgger 10라운드 고정 정책의 실제 분기 재평가

공개 모델의 최종 평가 256회에서 기존 완주율 **245/256 (95.70%)**을 재현했다. 같은 모델과 출발 조건을 수정 환경에서 평가하자 **231/256 (90.23%)**으로 5.47%p 낮아졌다. 수정 환경에서 충돌은 1회(0.39%)였으며 경로 이탈이 24회(9.38%)였다. 이 256회에서 기존 완주 목표 95%에 미달했다.

## 비교 조건

- 대상은 PMH가 공개한 학습 시드 11의 `jys3_dagger10_fixed.pt` 한 개다. 같은 가중치로 두 환경을 결정론적으로 주행했다. 재학습과 안전 필터를 사용하지 않았다.
- 원본 고교통 시나리오 `high_real_ratio`(시간당 15,000대), 16개 경로, 출발 차로, 센서 잡음·가림, 120 m 시야, 최대 1,000스텝을 사용했다. 분기 방향과 차로 연결 표시는 원본과 같이 구성하고 정책에 원래 50개 관측만 입력했다.
- 기존 환경은 SUMO가 지정 경로를 유지한다. 수정 환경은 현재 차로가 다른 도로로만 이어지면 해당 도로로 실제 진행한다. 지정 경로가 아닌 외부 도로에 진입한 순간 경로 이탈로 집계한다. 출발 도로·차로·속도·남은 길이와 최초 50개 입력의 일치를 주행마다 검사했다.
- 세 패널의 시드는 각각 `기준값 + 100 × 반복번호 + 경로번호`다. 경로번호는 1~16, 출발 차로는 0·1을 번갈아 쓰며 단일 차로에서 0을 쓴다. 기준 64회(26010000), 라운드별 독립 평가 64회(29010000), 학습·라운드 선택에 쓰지 않은 최종 256회(30010000)를 구분한다. 95.7%는 최종 256회의 원본 성적이다. 원본에서 학습 시드 5개를 합한 96.0%는 별도 통계다. PMH는 같은 최종 세트에서 앞선 6라운드 실패를 분석하고 전문가 v3도 검증했다. 따라서 이 재평가는 이미 보고된 256개 조건에서 분기 처리 변경의 효과를 측정한다.

## 재현

```powershell
python -m utils.jys3_pmh_physical_holdout --workers 4
```

실행기는 PMH 커밋 `2bf7d863c746bf9f25369f2dc6ab0bf6a6067577`의 `models/pmh/jys3_dagger10_fixed.pt`를 읽는다. 별도로 받은 같은 모델은 `--checkpoint`로 지정할 수 있다. 가중치 SHA-256은 `502ce37d120f2c4a9dd55b6e2754e9d74ac486c698b87cf8c55b7e4fd421f2d2`다. 수정 환경은 `a4bab313da985ed614c1210219d13ea53017a7f4` 기준이며 실행 버전은 SUMO 1.27.1, PyTorch 2.14.0 CPU다. 패널별 재현 비교는 원본에 공개된 집계 및 실패 경로 단위로 수행했다.
