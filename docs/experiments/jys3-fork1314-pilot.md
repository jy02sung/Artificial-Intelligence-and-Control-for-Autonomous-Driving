# 13·14번 마지막 분기 단독 PPO

전체 경로의 앞 구간에서 종료돼 마지막 분기를 경험하지 못하는 효과를 분리한다. 이 실험은 중간 출발 자체의 학습 가능성을 보는 단독 시험이다. 전체 경로 대조와 50% 혼합 실험은 별도다.

- 기준 jys3 커밋 0bcaa9f61f01fa819b36d20d724dce13765ca8b1. 무작위 PPO, 시드 11·22·33, 시드당 50,000스텝. 0 / 16,384 / 32,768 / 50,000스텝에 고정 가중치를 저장한다.
- 고교통 high_real_ratio, 15,000대/시. 도로 1063527748 시작 지점에서 10m/s로 출발해 원래 목적지까지 달린다. 0·1차로는 169728835(13번), 2차로는 797789364(14번)로만 연결된다. 훈련 시 6개 경로·차로 조합을 블록마다 섞고 각 차로에서 두 경로의 교통 시드를 맞춘다.
- 수정 분기 환경 S1의 관측·행동·PPO 설정을 사용한다. 종료 보상은 지정 경로 도착 +5, 충돌·오진입·시간초과·잘못된 차로 끝 정지 각각 −5, 실제 정상 분기 통과는 한 번 +1이다. 전진 보상은 원 경로 전체 길이에 비례해 지나간 구간의 신규 전진 거리에만 지급한다. 부분 출발 때 이미 주행한 거리는 0점이다.
- 중간 평가에는 차로당 3개 교통 시드를 쓴다. 0·50,000스텝은 별도 차로당 8개 교통 시드(모델당 24쌍)에서도 대조한다. 시드군은 학습과 분리한다. 모델 간 공통 시나리오가 있으므로 세 학습 시드 결과와 시나리오 수를 구분한다.
- 한 쌍은 교통 시드, 출발 차로·위치·속도·시각과 배경차 위치·속도 해시가 같은 13·14번 주행이다. 실제 외부 도로 ID로 분기를 채점하고 최종 완주·충돌은 따로 집계한다.
- 실행은 python -m utils.jys3_fork1314_pilot의 check, train, screen, holdout 모드로 한다. 정책 가중치, 초기 파라미터 해시, 학습 손실·엔트로피·KL 및 평가 주행은 results/jys3_fork1314_pilot/seed{11,22,33} 아래에 저장한다. 고교통 훈련 및 평가에 앞서 별도 연결 시험에서 6개 조합의 실제 도로와 동작을 확인했다.

### 동일한 1차로 출발 상태에서 왼쪽 명령 확률

각 경로의 관측을 짝지어 확인했다. 교통과 차량 상태가 같고 서로 다른 입력값은 도로 단위 다음 분기 방향(34번 인덱스) 하나였다. 아래 수치는 주행 전반의 빈도가 아니라 출발 순간 8개 시나리오의 평균이다. 1차로에서 13번은 유지해도 통과하며 14번은 왼쪽 2차로로 옮겨야 한다.
