# 반복 seed 및 교통 전이 검증 설계

- 조건: 기존 안내/기본보상, 상세 사전 안내/기본보상, 기존 안내/차로선택·유지 보상+잘못된 차로 체류 벌점. 조합 효과와 안내 효과를 섞지 않는다.
- 새로운 학습 seed22,33 각각 동일 초기 가중치로 세 조건을 무교통에서 200,000스텝 학습한다. 기존 seed11 정책은 재학습하지 않고 재평가한다.
- 맵, 입력 차원63, PPO 파라미터, 시작조건, 16경로 순환과 예산은 기존 무교통 실험과 동일하다. 모델은 5만 스텝 경계 이후 첫 업데이트마다 저장한다.
- 모든 중간 모델에 무교통16회(seed29101), 기본 교통48회(seed29101~29103, 16경로)를 적용한다. 과거 후보평가 seed19101~19103과 분리한다.
- 기본 교통 입력은 기존 동결된 reference 파일이다(15,000대/h 시나리오). 입력 파일은 기존 실험에서 그대로 복사한다. 무교통 모델의 교통 전이 평가이며, 교통 추가 학습이 아니다.
- 3조건 × 학습seed3개 × 중간모델4개 × 평가64회 = 총2,304회 예정. 새 학습은6개, 기존seed11은 평가만3개다.
- 강제 차로 보정, 행동 교사, 추가 안전 필터를 켜지 않는다. 매 학습 업데이트와 평가에서 route override 0을 확인한다.
- 최대3개 독립 프로세스, PyTorch 각1스레드. 완료된 작업 다음에 대기 작업을 자동 실행한다. 오류 시 STOP으로 동료 작업을 중단하고 원인을 기록한다.
- 완주/충돌/시간초과를 분리하고, 시간초과 위치·원인 진단, 안내 방향 요청/실제 변경, 올바른 차로 유지, 학습 보상 성분별 횟수/크기를 저장한다.
- 상세 안내가 여러 seed에서도 개선되면 정보 표현 효과를, 체류 벌점이 개선되면 보상 신호 발생 방식의 효과를 지지한다. 이번 비교만으로 보상 계수 부족이 유일한 원인이라고 단정하지 않는다. 체류 벌점은 교통에서 필요한 양보를 억제할 수 있어 충돌·근접 실패를 따로 확인한다.
- 중간모델 최고점과 최종모델을 모두 보고한다. 이 평가로 모델을 다시 선택하면 평가 seed는 더 이상 최종 독립 검증용이 아니므로 별도 검증이 필요하다.

실행: `python -X utf8 -m utils.run_route_repeat_transfer`
