# 위험 상태의 가속 명령 벌점 단독 비교

Goal: 합류 위험을 관측한 뒤에도 가속하는 행동이 지속되는 문제를 직접 행동 비용으로 학습할 수 있는지 확인한다.
Architecture: 기존 사전 위험 관측+안전 벌점 조합을 그대로 사용하고, step 직전 관측 가능한 합류 위험에 양수 가감속 명령 비용만 추가한다. 별도 환경과 runner로 실행 중 소스 보존. Tech: PyTorch PPO, libSUMO.

대조군 safety_strength/anticipatory. 새 보상은 비종료 스텝에서 -0.4 * pre_action_merge_risk * clip(accel,0,1). 기존 속도 위험 벌점·충돌-20·차선위험계수-0.4·경로보상·학습률0.0003·표준편차·관측·초기가중치를 유지한다. 위험 없거나 감속/중립이면 추가비용0. 학습된 가감속을 수정하지 않는다. 원래 위험을 속도로 벌주는 경우 포화 속도에서 가속 명령의 차이가 바로 비용에 드러나지 않는 한계를 시험한다.

계수0.4는 실험 가정이며 최적값이라는 근거는 없다. 위험 상태에서 가속 억제를 유도하지만 충분한 감속을 보장하지 않는다. 과도한 정지·완주 퇴화도 기록한다. 새 보상은 terminal에서0, 원래 충돌 보상은 유지한다.

단계: 비용 함수 테스트 → smoke32스텝4평가 및 대조군 hp/입력/초기 텐서 확인 → 추가20만 학습 →5/10/15/20만 교통48회+무교통16회 평가. 필요 방향의 변경 확률·위험 노출부터 첫 감속 지연·실제 속도 감소·새 비용 발생량을 비교. 성공 후보만 새 seed 독립검증. 강제 보정0.

검증 완료: 단위 테스트3개,32스텝 학습 및4회평가. 대조군과 hp·초기 텐서·입력 해시·기존 소스 해시·기본 보상·행동 설정이 동일함을 확인했다. 새 비용만 추가한 조건으로 실행한다.
