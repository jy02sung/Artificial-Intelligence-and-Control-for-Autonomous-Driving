# jys3 무작위 초기화 PPO 실험 (2026-11-24)

목표는 고교통 16경로 전체 평가에서 완주율 95% 이상, 충돌률 5% 미만이다.
아직 목표를 달성한 모델이나 평가 결과는 없다. 기존 전이학습 모델의 96.25%/1.25%는 이 실험 성적이 아니다.

## 기준과 금지 조건

- 기준: `origin/jys3`의 `b5a7241925cc88757cac8592c98fdd5532830437`.
- 실험 브랜치: `codex/jys3-scratch`. 실행기: `utils/jys3_scratch.py`.
- `utils/jys3.py`의 50개 관측, 120m 센서, 거리별 잡음과 가림, 도로 안내를 유지한다.
- 보상은 충돌 -15, 정상 도착 +5, 올바른 분기 도로 실제 진입당 +0.25,
  시간초과/잘못된 차로 끝 30초 정지 -5 그대로다. 목표 차로에 있다는 이유의 보상은 없다.
- 현재 차로 번호와 목적지에 무관한 1홉 물리 연결 지도는 남는다.
  이 정보는 '몇 차로로 가라'는 목표 차로 답안과 구분한다.
- 기존 모델, BC/DAgger, 전문가 행동, 과거 경험 데이터는 사용하지 않는다.
  초기화와 전체 학습 동안 `torch.load`/`torch.jit.load`를 호출하면 즉시 실패한다.
- `navigation.query`, `navigation_context`, `_route_lane_ready`, `_lane_change_is_safe`를
  호출하면 즉시 실패한다. 정책의 행동을 위험도/차로 답안으로 덮어쓰거나 마스킹하지 않는다.
- 출발 차로는 존재하는 0/1번을 번갈아 사용한다. 경로에 유리한 `best`는 사용하지 않는다.
- 기존 jys3의 `speedMode=0`에는 교차로 내부 우선권 검사가 남는다.
  본 실험은 정책 제어 구간에서 **96**을 사용해 이것도 끄며, `laneChangeMode=0`이다.
  따라서 기존 jys3 평가와 제어 조건이 정확히 같다고 주장하지 않는다.
  [SUMO 공식 설정](https://sumo.dlr.de/docs/TraCI/Change_Vehicle_State.html#speed_mode_0xb3)
- 가감속 물리 상한, 차량 최고속도, 없는 차로/실선/교차로 내부 차로변경 제한은 유지한다.
  주변 차량 간격에 따른 행동 차단은 없다. 도로 끝에서의 시뮬레이터 동작까지
  전부 제거한 자유공간 물리실험이라고 주장하지 않는다.

## 첫 실험 조건

공통: 퇴계원 IC `high_real_ratio`, 15,000대/시 수요, 준비 주행 60초,
0.2초 간격, 에피소드 최대 1,000스텝(200초), 16경로 순환.
교통 구성은 jys3의 승용차 77%/배송차 18%/트럭 4%/버스 1%다.
차량 삽입 지연이 있으므로 수요와 실제 투입량은 구분한다.

| 항목 | baseline201 | explore201 |
|---|---:|---:|
| 초기화 | seed 201 무작위 | seed 201 무작위 |
| 예정 학습량 | 65,536 | 262,144 |
| 할인율 gamma | 0.99 | 0.999 |
| GAE lambda | 0.95 | 0.98 |
| 학습률 | 0.0001 | 0.0002 |
| 차로 엔트로피 계수 | 0.002 | 0.03 |
| 초기 차로 유지 편향 | 1 | 0 |
| 업데이트 epoch / 미니배치 | 10 / 64 | 4 / 256 |
| PPO clip / 가치손실 계수 | 0.2 / 0.5 | 0.15 / 0.1 |

둘 다 무작위 네트워크이며 초기 차로 편향 설정이 달라 초기 가중치가 완전히 같지는 않다.
관측·보상은 두 실험에서 동일하다. jys3 공개 실험에서 차로변경 탐색이 소멸하고
잘못된 차로 끝 정지가 많았으므로, explore 조건은 탐색을 유지하고 늦은 도착 보상을
앞선 행동까지 전달하는 가설을 시험한다. 효과를 미리 성공으로 간주하지 않는다.

## 평가와 기록

- 개발 평가: 16경로 × 2회 = 32회, seed `710000000 + 반복*100 + 경로번호`.
- 최종 평가: 선택 모델 고정 후 16경로 × 10회 = 160회,
  seed `810000000 + 반복*100 + 경로번호`. 최종 시드는 모델 조정에 사용하지 않는다.
- 160회 중 완주 152회 이상, 충돌 7회 이하가 관측 목표다. 시간초과도 전체 분모에 포함한다.
  단일 평가 비율은 실제 성공확률에 대한 통계적 보장이 아니다.
- 충돌·도착이 동시에 보고되면 충돌로 센다. 순간이동/잘못된 경로 이탈은 완주로 인정하지 않는다.
- 개발 평가를 통과하지 못하면 최종 평가를 열지 않는다.
- 체크포인트 SHA256, 무작위 초기 가중치 지문, 기준/실행 커밋, 소스/시나리오 해시,
  seed, 전 에피소드 결과와 실패 직전 15스텝은 `results/jys3_scratch/`에 보관한다.
- 대형 모델과 원시 로그는 로컬에 보관하고 이 문서에 결과를 추가한다.

## 실행

실행 전 감사 통과: 같은 seed 초기화 지문 재현, 다른 seed 차이,
모델 로딩/차로 정답/안전게이트 조회 차단 상태에서 16경로 실행,
정책 행동 전달 및 보상 사건 확인. 고정 가속·차로유지의 고의 위험 주행은
16회 중 13회 충돌, 2회 도착, 1회 정지 종료였다.
이는 학습 모델 성적이 아니라 충돌이 실제로 발생할 수 있다는 검사다.
초기 explore201 지문: `43d5c92817ac4d009c00194521bd1c70af8f9c7af52da20c8e9b35258dac1623`.
감사 원본: `results/jys3_scratch/audit/report.json`.

```powershell
python -m pip install --target .runtime --no-deps libsumo==1.27.1 sumo-data==1.27.1
python -m utils.jys3_scratch audit
python -m utils.jys3_scratch train --name baseline201 --seed 201 --preset baseline --steps 65536
python -m utils.jys3_scratch train --name explore201 --seed 201 --preset explore --steps 262144
python -m utils.jys3_scratch evaluate --run explore201 --step 65536
```

기본 `python -m utils.jys3 --train`은 BC 체크포인트를 요구하므로 이 실험에는 사용하지 않는다.
