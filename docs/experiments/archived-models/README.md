# 발표 성능표에서 제외한 모델과 평가

발표 모델은 [보강형 DAgger R5](../jys3-presentation-main-model.md)다. 아래 목록은 과거 가중치를 찾았을 때 **어떤 성적을 인용할 수 있는지** 확인하기 위한 기록이다. 제외 범위는 원인이 확인된 실행 조건이나 측정값에 붙였다. 동일 가중치의 수정 후 재평가에는 별도의 결과가 있다.

## 2. 기존 SUMO 고정 경로에서 얻은 성적

16번 차량이 출구 전용 0차로를 끝까지 따라가도 SUMO에 등록된 다음 도로가 본선이면 출구로 넘어가기 전에 멈췄다. 그래서 **기존 환경의 이탈 0건을 모델이 스스로 오진입을 피한 성적으로 인용하면 안 된다.** 수정 환경의 같은 장면에서는 기존 259스텝 끝 정지가 113스텝 실제 출구 진입으로 바뀌었다. 수정 후에도 물리적으로 이어지는 차로가 없는 차로 감소부에서는 끝 정지가 생길 수 있다. [지도와 동일 시드 재생](../jys3-physical-forks.md)

## 3. 고가 시야 가림 오류가 확인된 전문가 평가

| 대상 | 잘못된 부분과 확인한 범위 | 대체 기록 |
|---|---|---|
| 가림 보정 전 `queue_tail` 전문가, 11번 경로·시드 95380211 | 고가 램프의 배송차가 아래 본선의 승용차를 가린 것으로 처리됐다. 297스텝에서 전문가는 왼쪽 차량을 감지하지 못하고 차로를 바꿔 298스텝에 **본선 승용차와** 충돌했다. 이 한 건을 합류 안전 간격만의 실패로 설명하면 원인을 틀리게 된다. | 확인된 고가 교차 20쌍을 센서에 반영했다. 같은 전문가·같은 시드에서 297스텝에 유지·감속, 322스텝에 왼쪽 변경, 489스텝에 완주했다. [동일 시드 전후 기록](../jys3-overpass-visibility.md) |
| 물리적 분기는 수정됐지만 고가 가림 보정 전에 수집·평가한 전문가와 학생 | 당시 센서로 수집한 시범과 성적이다. 위 한 건에서 확인한 오류를 모든 충돌에 일괄 적용할 근거는 없다. 이전 160회 시범을 감사했을 때 저장한 행동과 당시 전문가 규칙의 출력은 일치했다. | 구형 `jys3_physical_imitation_160`와 `jys3_physical_dagger_multi`의 라운드는 당시 센서 조건의 실험으로 읽는다. 발표용 계보는 고가 보정 후 512회 검증을 마친 전문가 → 새 시범 160회 → ReLU BC → 보강형 R5다. [이전 라벨 감사](../jys3-physical-expert-audit.md) · [최종 전문가](../jys3-expert-final.md) · [최종 학습 조건](../jys3-final-relu-dagger.md) |

## 발표에 그대로 쓸 수 있는 비교

최종 환경에서 같은 128회를 주행한 **BC 107회, 기본 DAgger R5 118회, 보강형 DAgger R5 125회 완주**는 유효한 대조다. 100에포크 BC의 완주가 늘지 않은 결과도 유효하다. 최종 R5의 지정 256회에서는 8번의 차로 끝 정지 2건을 실패에 포함했고, 추가 256회에서는 끝 정지가 0건이었다. [발표 표와 최종 가중치](../jys3-presentation-main-model.md) · [BC 100에포크 대조](../jys3-final-relu-bc100.md)
