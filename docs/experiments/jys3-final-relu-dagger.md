# 최종 전문가의 ReLU Hybrid BC와 DAgger

| 항목 | 수업 기본 BC | 이번 실험과 이유 |
|---|---|---|
| 유지 | 256×256, ReLU, Adam 0.0003, 기본 배치 256, 50에포크 | BC에서 동일하게 적용했다. 가감속 지도 손실도 MSE다. |
| 관측 | 학습 데이터 평균·표준편차로 표준화 | 환경에서 척도화한 50개 관측을 HybridActorCritic에 직접 전달했다. |
| 출력 및 손실 | 연속 행동 두 개를 MSE로 회귀 | 가감속은 tanh 평균, 차로는 좌·유지·우 3클래스 교차엔트로피다. 연속값 양자화가 차로변경 명령을 유지로 바꾸는 문제를 피한다. |
| 학습 배치 | 균일 배치 | BC는 차로변경 정답 32개를 추가했다. DAgger는 현재 오답 32개와 학생 실패 직전 15스텝에서 32개도 보강했다. 후자에는 가감속 손실도 적용했다. |
| 검증·시드 | 에피소드 20% 검증, 검증 MSE 최소, 시드 0 | 별도 전문가 32회로 좌·우 평균 F1 − 0.1 × 가감속 MAE가 최대인 에포크를 선택했다. 초기화 시드 11, 그래디언트 노름 상한 1.0을 사용했다. |
| 후속 학습 | 단일 BC | 학생이 방문한 상태에 전문가 정답을 붙였다. 각 라운드 144회씩 누적해 12에포크씩 업데이트했다. 값 함수·보상·PPO 업데이트는 사용하지 않았다. |

## 최종 전문가와 시범

저속 도로 12m 전문가를 확정했다. 기존과 후보의 512회 결과와 문제 시드별 대기는 [전문가 보고서](jys3-expert-final.md)에 기록했다.
모든 주행은 고교통 15,000대/시, 물리적 분기, 고가 교차 20쌍 보정, 안전게이트 OFF에서 실행했다.

| 용도 | 주행 시도 | 채택 | 제외 및 시드 보충 | 채택 스텝 |
|---|---:|---:|---:|---:|
| 학습 시범 | 168 | 160 | 8 | 57,158 |
| 오프라인 검증 | 33 | 32 | 1 | 11,737 |

학습 시범은 지정 경로 완주와 10초 미만 저속 대기를 모두 요구했다. 검증 시범은 완주를 요구했다. 제외한 주행까지 시드 검증에 포함했다. 저속 대기는 같은 도로·차로·합류 방향에서 전문가가 간격 부족으로 기다리며 실제 속도가 1m/s 미만인 상태가 50스텝 이상 연속된 주행 수다. 학생 평가의 속도와 주행은 학생 정책의 출력으로 결정했다.

선정 모델은 **DAgger R5**이다. 128회에서 완주 수 최대, 충돌 수 최소, 실제 이탈 최소, 이른 라운드 순으로 선정했다. 취약 경로 실패 수가 같은 경우 경로 번호가 작은 순서로 보강했다.

| 지정 256회 · DAgger R5 | 247 | 4 | 2 | 0 | 3 | 8 |

- 지정 91M 패널은 완주 96.48%, 충돌 1.56%, 끝 정지·시간초과 2건으로 목표 **미달**이다.
- 추가 신규 패널은 완주 98.44%, 충돌 0.39%, 끝 정지·시간초과 0건으로 목표 **충족**이다.

서로 다른 실제 사용 시드는 1,625개다. 같은 평가 패널은 모델 간 비교에 재사용했다. 지정 91M 대역은 이전 프로젝트 실험에서 평가한 기록이 있어 104320000 대역 256회를 추가했다. 두 패널 모두 이번 모델의 학습과 선정에서 분리했다.
