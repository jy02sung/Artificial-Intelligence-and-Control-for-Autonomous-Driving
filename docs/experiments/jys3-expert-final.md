# 최종 시범 전문가 선정

같은 고교통 512회에서 저속 도로의 후단 여유 거리만 24m에서 12m로 줄였다. 시드·경로·출발 차로를 짝지었고 재시도 없이 평가했다.

| 조건 | 완주 | 충돌 | 끝 정지 | 시간초과 | 실제 이탈 | 10초 이상 대기 |
|---|---:|---:|---:|---:|---:|---:|
| 기존 24m | 512 | 0 | 0 | 0 | 0 | 19 |
| 저속 12m | 512 | 0 | 0 | 0 | 0 | 15 |

| 문제 연결로 시드 | 기존 대기(초) | 후보 대기(초) |
|---|---:|---:|
| 68173405 | 27.6 | 27.6 |
| 94600413 | 96.2 | 0.0 |
| 94601313 | 60.6 | 0.0 |
| 94600014 | 14.4 | 0.0 |
| 94600214 | 45.4 | 0.0 |

최종 전문가로 저속 12m 후보를 선정했다. 두 조건 모두 50개 관측과 같은 차로변경 안전 간격을 사용했다.
완주 512건을 전제로 10초 이상 대기 건수가 줄거나, 문제 5건 모두 악화 없이 3건 이상에서 10초 이상 줄면 후보를 선택하도록 실행 전에 정했다.
