# 수정 환경에서 S1·S2 무작위 초기화 비교

고정 경로 환경에서 학습한 모델을 차로 기반 분기 환경에 옮겼을 때 발생한 오진입을, 처음부터 실제 오진입을 경험하게 학습하면 줄일 수 있는지 비교한다. 16개 경로 고교통 검증을 마친 뒤 시작하도록 대기 중이다.

|설정|S1|S2|
|---|---:|---:|
|충돌|−5|−7|
|올바른 분기 통과 / 지정 경로 완주|+1 / +5|+1 / +5|
|경로 전진 누적 상한|+2|+2|
|실제 경로 이탈 / 차로 끝 정지 / 일반 시간초과|각 −5|각 −5|
|학습 시드|11·22·33|11·22·33|
|학습량|0 → 60만 스텝|0 → 60만 스텝|

1. 기존 정책의 수정 환경 검증 1,536회를 완료하고 기존 환경 기록과 출발 상태를 대조한 뒤 새 실험을 시작한다.
2. 세 시드 각각에서 무작위 PPO 가중치를 생성하고 0스텝 가중치를 저장한다. 같은 시드의 S1·S2가 같은 초기 가중치 해시로 학습을 시작했는지 대조한다. 고교통 15,000대/시, 16개 경로, 기존 관측·행동과 PPO 설정을 적용한다.
3. 5만 스텝마다 조건·시드별 64회 평가한다. 대표 시점은 세 학습 시드 합산 완주 최다, 충돌 최소, 이른 시점 순서로 정한다. 학습 중 정책 손실·가치 손실·엔트로피·근사 KL을 기록한다.
4. 대표 모델과 60만 모델은 학습·선정에서 분리한 기존 세 교통 시드군에서 각 조건당 576회 평가한다. 대표가 60만이면 같은 가중치의 평가는 한 번만 수행한다. 완주·충돌·끝 정지·일반 시간초과·경로 이탈, 13번 진출과 16번 본선 복귀를 집계한다.

재개 가능한 실행 명령은 `python -m utils.jys3_physical_scratch`다. 가중치와 업데이트별 원자료는 로컬 `results/jys3_ppo_comparison/pure_f/physical_forks/from_scratch_600k`에 저장한다. [고정 가중치 검증](jys3-physical-validation.md) · [실행 코드](../../utils/jys3_physical_scratch.py)
