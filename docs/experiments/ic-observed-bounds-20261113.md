# 실측 교통량 재조사와 HV 수요 불확실성 검증

## 결론과 자료 범위

현재 확보한 자료만으로 **퇴계원IC의 실제 16개 경로별 OD를 복원했다고 말할 수 없다.** 본선 구간 관측량은 확보했지만 램프 회전량, 일반도로 유입량, 방향·시간 기준의 정합성이 미확정이다. 기존 15,000대/시간 분배는 실측 분배가 아니며, 이번 시험에서도 그대로 정답으로 사용하지 않는다.

상행/하행 일반 정의는 있으나 순환고속도로의 해당 관측 방향과 맵 경계 대응을 확정하지 않았다. 10010은 시간0~23, 10031은1~24로 표시되므로 이번 값은 **동시 관측 재현이 아닌 시간표기17·18, 양방향에 걸친 범위**다. 본선 측정값은 통과 교통량이지 혼잡으로 못 들어간 잠재 수요까지 포함한 수요가 아니다.

## 결과를 보기 전에 고정한 시험

- 맵/HV: `scenarios/hv_high15000_entryprep`의 파일을 복사. 네트워크·차량 제어·버스5%·승용차 위반자2%·출발차로best는 변경하지 않는다. 이 차종 비율은 실측값이 아니며 화물차는 재현하지 않는다.
- 본선 하한: 남쪽5,639 + 북쪽3,510. 상한: 남쪽6,861 + 북쪽4,677.
- 일반도로 01/02/07/08/09/10/11/12는 기존 가정 300/300/900/900/1200/400/400/400, 합계4,800대/시간 유지. 실측으로 보정됐다는 의미가 아니다.
- 각 본선의 진출 비율을 독립 가정 **10%,25%,40%**로 고정. 남쪽03/04/05 및 북쪽13/14/15에 각각 균등 분할, 나머지는06/16 직진. 비율의 확률이나 현실성을 주장하지 않는다.
- 총 입력 하한13,949대, 상한16,338대. 1시간 동안 투입하고 최대10,800초까지 배출 관찰. 6조건 × seed9101/9102/9103 = 18회, 최대6개 병렬.
- 10,800초는 이전 시험의 7,400초 안팎 배출 사례까지 관찰하기 위한 공통 상한이다. 시간 연장이 용량·지연 문제 해결을 뜻하지 않는다.
- 실패해도 입력 비율을 조정하지 않는다. 통과율, 미투입, 도로 잔류, 충돌 차량 이벤트, 텔레포트, 출발 지연, 도로 내 이동시간을 구분한다. 충돌 이벤트는 사고 건수와 다르다.
- 전체 통과는 `계획=투입=도착` 및 충돌/텔레포트/잔류/미투입0인 경우만 인정한다. 도착자 평균 지연은 실패 조건에서 미완료 차량을 제외하는 한계가 있다.

수치 입력은 [경로별 입력 CSV](ic-observed-bounds-inputs-20261113.csv), 원자료 검증과 seed는 [설계 JSON](ic-observed-bounds-design-20261113.json). 실행: `python -X utf8 -m utils.hv_observed_bounds run`. 기존 AV 학습은 재개하지 않는다.

## 실제 분배 확정에 더 필요한 자료

같은 시간대·방향의 본선 양끝 교통량, 램프별 진입/진출량과 금강로 경계 교통량이 필요하다. 본선 관측량의 차이만으로는 ‘진입−진출’의 순변화만 제약할 수 있으며 개별 진출입량이나 16개 OD는 유일하게 정해지지 않는다. 조사 위치가 맵 외부 다른 IC를 포함하면 단순 차감도 불가능하다. 이번 실험은 그 공백을 통과하기 쉬운 분배로 채우지 않고 명시적 가정의 민감도로 남긴다.
