# 보상 변경 전후의 같은 주행 비교

기존 완주와 충돌이 같은 출발·교통 조건에서 어떤 결과로 바뀌었는지 비교했다. 각 표의 행은 기존 결과, 열은 변경 후 결과이며 단위는 주행 건수다. 정지는 잘못된 차로 끝에서의 30초 정지 종료, 일반 시간초과는 1,000스텝 상한 도달이다. 서로 다른 평가 패널은 합산하지 않았다.
