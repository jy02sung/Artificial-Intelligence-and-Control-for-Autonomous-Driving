**결론**: 목표(완주 ≥ 95 %, 충돌 < 5 %)에 도달하지 못했다. 가장 좋은 seed 11 후보가 미사용 시험 256회에서 완주 187(73.0 %)·충돌 58(22.7 %)였다. 이전 순수 PPO(29~58 %)보다는 높지만, 고교통에서 충돌이 많이 남았고 seed 12·13은 정지·시간초과로 무너졌다.

## 조건

- 시작: 무작위 초기화(학습 seed로 생성, SHA-256은 `seed<S>/protocol.json`)
- 보상: 완주 +1, 충돌 −1만 사용(시간초과·차로 끝 정지는 0으로 종료)
- 커리큘럼: 차 없음 → 저교통(기본 교통량 20 %) → 중교통(50 %, 실제 차종 비율) → 고교통(15,000대/시)
  - 전환 기준: 학습 주행 최근 100회 완주율 90 % / 85 % / 80 % 이상, 단계당 최소 5만 스텝
  - 고교통 진입 후에는 끝까지 고교통
- 신경망·PPO: jys3 기본(256×256 tanh 공유 actor-critic, 학습률 1e-4 고정, n_steps 2048, 10에포크, 미니배치 64, γ .99, λ .95, clip .2, 차로 엔트로피 .002, 차로 유지 편향 1)
- 주행 순서: 16경로를 섞은 블록, 교통 시드 = seed×1e6 + n, 출발 차로는 블록마다 0/1 교대
- 학습: seed 11·12·13 각 3,000,320스텝(3개 동시 실행, 약 7시간)
- 선정: 고교통 단계의 체크포인트(102,400스텝 간격)를 26010000 + 29010000 128회로 평가하고, 완주 최다 → 충돌 최소 → 이른 스텝으로 seed마다 1개 선택
- 시험: 선택한 3개를 48010000(미사용) 256회, 30010000 256회에서 1회 평가

## 해석

- 커리큘럼으로 차 없음·저교통·중교통은 세 seed 모두 통과했다. 어려운 부분은 고교통이다.
- 고교통에서 보상이 +1/−1뿐이면 충돌을 줄이는 가장 쉬운 길이 멈추기다. seed 12·13은 그쪽으로 수렴해 시간초과가 대부분이 됐다.
- seed 11은 멈추지 않았지만 충돌률이 20 %대에서 내려가지 않았다. 고교통 210만 스텝 동안 학습 주행 완주가 약 40~50 %에서 정체했다.
- 따라서 이 설정(보상 2개, 3M 스텝)으로는 PPO만으로 목표에 닿지 않는다. 남은 선택지는 더 긴 학습, 보상 추가(목표 차로·진행), 또는 모방학습 시작점이다.
