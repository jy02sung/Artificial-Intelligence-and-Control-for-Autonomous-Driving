## 충돌 원인 근거

**음수 간격은 ‘존재하지 않는 차’가 아니다.** SUMO의 인접차 gap은최소간격을포함한값이므로음수만으로차체끼리이미충돌했다고단정하지않는다. 그러나위험할정도로가까운실제차량을None처리하는것은명확히확인됐다. 예를들어기본03번0.2초에는옆차가ego와거의나란히있고raw후방gap−6.70m였지만관측후방채널은없음값−1/−1이었다. 그상태에서왼쪽명령이적용되어다음스텝충돌했다.

음수간격누락이확인된충돌: 기본02·03·07·13·14, 저교통량13·14. 이7개충돌직전입력에음수간격을0으로표시하고상대속도를복구하는 **오프라인1회추론**도실시했다.7개모두가속명령이양수였고차선명령방향도그대로였다. 따라서관측버그수정만으로저장된무교통정책이안전해진다는주장을하지않는다. 이는재학습또는수정관측주행결과가아니다.

### 수정된 우선순위

1. 공통 관측기의 음수간격 처리부터 수정하고 존재/중첩/옆뒤접근/연결edge 사례를 회귀검증한다. 모델 입력 의미가 달라지므로기존모델결과와새기준을구별한다.
2. 동일한 교통 환경에서 기준 관측+기본 보상으로 학습한 기준을 마련한 뒤, 관측A/B와 보상A/B/C를 각각 독립 비교한다. 무교통 학습 모델의 교통 평가를 새 학습 조건의 대조 학습 모델로 대신하지 않는다. 제동 반응 검사도 함께 기록한다.
3. 현재HV지퍼는유지하는쪽이이번증거에맞다. AV지퍼교대판정은현맵에맞게정의·검증한후에만보상조건으로포함한다.
4. 300/500m 안내, 전방 제한속도, 합류 상대 접근 정보, 합류/분기 보상은 서로 별도 조건으로 남긴다. 차선 변경 주기는 행동 설계 문제로 별도 검토하며, 관측/보상 실험의 공통 행동 조건을 임의로 바꾸지 않는다. 도로를 더 연장하거나 수요를 줄여 현재 충돌을 숨기지 않는다.

**진단 종료 후 후속 학습은 보류한다.** 관측 오류가 확인되었으므로 승인한 계획의0단계통과조건을먼저충족해야한다.
