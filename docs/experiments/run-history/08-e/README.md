# 실험 E 설계와 실행

같은 물리 상태에서 13번은 출구, 16번은 본선으로 가는 정책을 학습하는지 검사한다. 네 조건 모두 D1의 왕복 지급 방지, 시간초과 실패 처리, 고교통 배경 수요, 가감속 및 단발 차로 명령을 사용한다. 이 기록에는 설계와 실행 코드가 들어 있다. 결과 판정은 별도 평가가 필요하다.

| 조건 | 추가 도로 의도 | 추가 통과 보상 |
|---|---|---|
| E0 | 없음 | 없음 |
| E1 | 본선·진출·기타 | 없음 |
| E2 | 없음 | 조기 확보 후 통과 |
| E3 | 본선·진출·기타 | 조기 확보 후 통과 |

41차원 정책에서 추가 세 칸은 E0·E2에서 0이다. 활성 분기가 보이면 도로 종류로 의도를 인코딩한다. E2·E3은 기존 통과 지급 시 마지막으로 적합 차로를 확보한 거리 d에 따라 0.25 × min(1, d/300)을 더한다. 실제 지급 조건과 적합 차로 이력은 [실행 코드](../../../../utils/experiment_e.py)와 [기반 환경](../../../../utils/experiment_a.py)을 함께 참조한다.

1·4·5·6·8·9·10·11·12·13·16번에 13·16번을 한 번씩 더 넣어 13회 단위로 섞는다. 블록별 출발 차로 0·1을 교대한다. 시드 11·22·33, 조건당 20만 스텝, 0부터 5만 스텝마다 저장한다. 저장소 루트에서 다음 명령으로 학습과 평가를 차례로 실행한다.

```sh
python -m utils.experiment_e
```

전체 16경로·두 출발 차로·세 교통 수준에서 평가한다. 고교통 선정에는 같은 출발 차로에서 13번과 16번 모두 올바른 다음 도로로 넘어가고 잘못된 차로 끝 정지가 없는 쌍을 센다. 동률은 충돌·완주·이른 스텝 순으로 결정한다. 선정과 별도 시드로 대표 및 최종 모델을 검증한다. D의 두 변경 과제 동시 성공은 13번·1차로와 16번·0차로를 묶었으므로 직접 비교할 때 같은 정의로 재집계해야 한다.
