# 공통 관측 오류 수정과 재검증

실제 차량의 음수 간격을 `None`으로 버리던 처리를 수정했다. 차량 ID가 있으면 거리 채널에0을 표시하고 상대속도를 유지한다. 차량 없음(빈 ID/None)과 감지거리 밖은 기존처럼 없음으로 남긴다. 현재·인접·두 칸 옆 차로에 동일한 누락 방지 규칙을 적용했다.

- 보상 계수, 도로, 차선 변경 주기, 안전 필터, 경로 안내, 저장된 정책은 변경하지 않았다.
- 차량 간격의 기존 계산 관례는 유지했다. TraCI 이웃 gap은 해당 차량의 minGap을 제외한 값이고, 두 칸 옆 직접 스캔은 차체 간 종방향 거리다. 이번 수정은 음수값의 존재 정보 누락을 고친 것이며 모든 좌표·거리 표현을 새로 통일한 변경은 아니다.
- 내부 junction의 다른 접근도로 차량은 별도 관측 추가 후보로 남는다. 가까운 모든 XY 차량을 정책에 넣지 않았다.

## 검증

수정 전 회귀검사는6개 테스트 중4개 테스트(하위 사례 포함7개 실패)가 음수gap 누락으로 실패했다. 수정 후6개 모두 통과했다. 좌우/앞뒤, 현재·인접·두 칸 옆 차로, 빈 ID, 감지 범위, 양수간격 보존, 실제 정책 입력 채널을 검사했다.

같은 정책(seed22,600064스텝), 같은 평가seed9101, 동일 입력 파일로 기존24사례를 재현하고, 무교통 나머지8경로를 추가했다. 독립4프로세스로 실행했다.

| 조건 | 수정 전 | 수정 후 |
|---|---|---|
| 무교통 대표8경로 | 8완주/0충돌 | 8완주/0충돌 |
| 저교통량 대표8경로 | 4완주/4충돌 | 4완주/4충돌 |
| 기본교통량 대표8경로 | 1완주/7충돌 | 1완주/7충돌 |
| 무교통 전체16경로 | 이번 비교의 추가 회귀검사 | **16완주/0충돌** |

기존24사례의 종료유형과 종료시간은 모두 같았다. 수정 후 저장된 추적의 음수gap 관측채널45건은 모두 거리0으로 정책에 전달되었다.32회 모두 강제경로보정0,텔레포트0이었다.

**관측 오류는 수정됐지만 기존 정책의 교통 성능은 개선되지 않았다.** 무교통 학습 정책의 감속·양보 판단을 정보 처리 수정만으로 대체할 수 없다는 진단과 일치한다. 다음 비교는 이 검출기를 공통 사용하면서 동일 교통 학습을 수행한다.
