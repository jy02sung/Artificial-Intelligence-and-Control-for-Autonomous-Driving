# MCW2 시야 가림 PPO의 차로 분기 재평가

고정한 MCW2 모델은 같은 80개 출발 조건에서 기존 분기로 77회(96.25%), 차로 연결을 따르는 분기로 72회(90.0%) 완주했다. 완주율 차이는 −6.25%p다. 수정 환경의 실제 이탈 7회는 모두 13·14번 경로의 같은 램프 분기에서 발생했다.

|환경|완주|충돌|실제 이탈|600초 시간초과|삽입 실패·기타|
|---|---:|---:|---:|---:|---:|
|기존 지정 경로|77|3|0|0|0|
|차로 연결 분기|72|1|7|0|0|

## 어느 주행이 달라졌나

|경로|기존|차로 연결 분기|
|---|---|---|
|5|완주 4, 충돌 1|완주 5|
|13|완주 3, 충돌 2|충돌 1, 이탈 4|
|14|완주 5|완주 2, 이탈 3|
|그 밖의 13개 경로|각 5회 완주|각 5회 완주|

기존 완주 77건 중 71건이 다시 완주했고, 5건은 이탈, 1건은 충돌로 바뀌었다. 기존 충돌 3건 중 2건은 이탈, 1건은 완주로 바뀌었다. 수정 환경의 충돌은 13번 시드 40113에서 발생했다.

이탈 당시 차량은 4개 차로가 있는 도로 `170059994`에서 가장 왼쪽인 SUMO 차로 번호 3을 점유했다. 이 차로는 램프 `844484876`에만 이어지며, 임무가 요구한 램프 `1063527748`로 들어가려면 차로 번호 0~2 중 하나를 점유해야 했다. 13번에서는 시드 40013·40213·40313·40413, 14번에서는 40014·40114·40314에서 이탈했다. 80회 중 23회에서 SUMO 실행 경로가 한 번 이상 바뀌었다.

원래 평가의 80/80건에서 저장된 종료 사유와 종료 스텝을 재현했다. 원래 기록은 CUDA에서 생성했고 이번 재생은 CPU(PyTorch 2.14.0, libsumo 1.27.1)에서 수행했다. 주행별 평균속도의 최대 차이는 0.00000045m/s 미만이었다. 두 환경의 출발 시각·도로·차로·속도·위치, 최초 47개 관측의 바이트 해시, 첫 정책 행동이 80쌍 모두 같았다.

## 평가 조건

- `origin/mcw2`의 `3dee85f1e3f8e857158d0b8edd69e0e8d0000c39`에서 원본 환경과 `results/mcw_runs/mcw2_occlusion_ppo/best_model.pt`를 가져왔다. 11번 학습 시드에서 시야 가림을 적용해 PPO로 추가 학습한 12,288스텝 선정본이다. SHA-256은 `4dab15658aa3f85880df9165d655f932be3e092c4997758e515b9cb6092e4f7e`다. 이번 평가에서 가중치 업데이트는 0회다.
- 기존 공개 평가에 사용한 경로 16개와 경로별 교통 시드 5개를 각각 재생했다. 경로 번호를 1~16, 반복 번호를 0~4로 두면 시드는 `40000 + 100 × 반복 번호 + 경로 번호`다. 동일 시드가 교통과 센서 잡음을 결정한다. 이 표본은 원래 성적에 분기 수정이 미친 영향을 비교하기 위한 것이다.
- 두 환경 모두 `high_real_ratio`에서 시간당 15,000대 유입을 설정했다. 승용·소형화물·트럭·버스의 추출 비율은 77·18·4·1%다. 배경 차량을 60초간 먼저 주행시킨 뒤 SUMO가 고른 출발 차로(`best`)와 허용 최고 출발 속도(`max`)로 자차를 투입했다. 시간 간격은 0.2초, 제한은 3,000스텝(600초)이다.
- 원본의 47개 입력과 결정론적 가감속·차로변경 출력을 사용했다. 120m 이내 차로 연결성을 지정 임무 기준으로 조회하는 `route_conn`과 `agenda2`가 켜져 있다. 원래 잡음, 트럭·버스 100% 및 소형화물 50%의 시야 가림, 실선 차로변경 제약을 유지했다. 별도 차로변경 안전 필터는 꺼져 있고 자차의 SUMO 속도·차로변경 모드는 모두 0이다. 시연용 출발 차로, 시나리오, 차로변경 대기시간은 적용하지 않았다. 원래 평가 모드에서는 학습용 30초 정지 종료가 비활성화된다.
- 수정 환경은 매 스텝 시작 시 점유 차로의 실제 연결을 확인한다. 지정 도로로 갈 수 없고 다른 도로로 이어지면 SUMO 실행 경로를 변경한다. 아직 분기 앞에서 적합한 차로로 옮기면 지정 경로를 복원한다. 양쪽으로 이어지는 차로는 지정 경로를 유지한다. 정책의 내비게이션은 계속 원래 임무 경로와 그 경로상의 현재 위치를 읽는다. 충돌을 우선 판정하고, 잘못된 외부 도로에 실제 들어가면 이탈로 종료한다. 한 스텝 사이에 짧은 도로를 통과한 경우 SUMO가 실행한 도로 순서를 확인한다.
