# Rolling Merge 전문가의 고교통 1:1 비교

기준 커밋 69611a2. 학습 가중치 없이 수정 분기·안전게이트 해제·시간당 15,000대 환경에서 16개 경로 × 8개 시드(95380000 + rep × 100 + route)를 대조한다. 기존 전문가가 바꾸려는 차로에 지금 진입할 수 없는 경우에만 50차원 관측으로 종방향 목표를 조절한다. 원래 안전 판단을 유지한 strict를 먼저 평가한다. 기존 14m와 새 10m는 목표속도 상한이 0이 되는 위치이며 실제 차량이 정지하는 위치와는 다를 수 있다.

목표속도는 원래 막힘 상태의 목표에서 출발한다. 옆·앞이 막히면 옆 앞차 속도 −3.5m/s(아래 한계 5m/s), 뒤만 막히고 여유가 있으면 뒤차 속도 +3m/s 방향으로 조절한다. 현재 차로 앞차 IDM과 10m 여유 감속 상한을 적용한다. 속도 정렬의 응답시간은 기존 1.3초, 정렬 단독 감속은 2.5m/s²까지다. 1~2초 내 양보나 10~18m/s 합류는 관측할 성능이다.

일반 시간초과 직전 5초 이상 연속 정지(속도 0.001m/s 미만)한 strict 주행이 2회 이상이면 같은 128회에서 relaxed를 추가한다. remaining <25m, speed <4m/s에서만 후방 필요 간격의 뒤차 속도 계수를 0.50→0.45로 바꾼다. 접근 속도 항, 앞 간격, 겹침 기준은 유지한다. relaxed가 strict보다 10초 대기 주행을 줄이고 충돌·이탈 증가 및 완주 감소가 없을 때만 비교 대표로 삼는다. 최종 채택은 사용자 목표로 별도 판정한다.

대기는 차로변경이 필요하고 실선이 아니며 안전 기준에 막힌 연속 시간이다. 도로·차로·필요 방향이 달라지면 시간을 새로 센다. 저속 대기는 그중 실제 속도 1m/s 미만인 연속 구간이다. 전체 128회에서 대기가 없으면 0초로 계산한다. 차로변경 속도는 같은 도로에서 실제 차로 번호가 바뀐 스텝 직전의 속도를 사건별로 합산한다. 완주 시간은 완주 주행만 집계한다.

## 판정

원래 합류 허용 기준을 쓰는 1단계 Rolling Merge(strict)가 이 패널의 채택 목표를 달성했다. 완주가 121→125회, 충돌 1→1회, 실제 이탈 0→0회였다. 저속 합류 대기 10초 이상인 주행은 8→2회로 75% 줄었다. 기존 완주 121회를 전부 유지했고 기존 시간초과 4회를 완주로 바꿨다. strict에서 남은 일반 시간초과 2회는 모두 종료 직전까지 정지해 있어 2단계도 실행했다. 후방 마진을 완화해 **새롭게 허용된 명령이 0개**로, 두 후보의 주행별 기록까지 일치했다. `rolling_expert(obs, env)`와 GUI의 `--mode new`는 strict를 사용한다.

주된 효과는 일부 주행의 장시간 정지 감소였다. 전체 차로변경 평균 속도는 비슷했고, 복구된 주행 중에도 저속 합류가 있었다. 7번 시드 95380107은 177.6초의 저속 대기가 없어졌지만 실제 차로변경 당시 속도는 3.8m/s였다. 아래 두 잔여 시간초과는 새 전문가도 해당 주행 전체에서 실제 차로변경 0회였다.

128개 출발 도로·차로·속도·차로 끝까지 거리·초기 관측 해시가 세 조건에서 일치했다. 기준 전문가의 종료 사유와 스텝 수도 이전 128개 주행과 모두 일치했다. 별도로 기존 저장 관측 59,221개에서 고정 단위 변환 상수만 전달했을 때 1단계의 차로 명령은 기존 행동과 전부 일치했고 가감속 출력은 3,151개에서 바뀌었다. 다른 시드의 독립 검증과 새 시범 수집은 이번 범위에 포함되지 않았다.

## GUI에서 비교 재생

jys3 작업 폴더에서 한 줄씩 실행한다. 분홍색 AV를 화면이 따라가고 주행 종료 시 집계 기록과 재생 기록이 동일한지 검사한다. 기존 전문가의 최장 저속 대기가 긴 순서다. 7번은 기존 및 새 전문가 GUI를 실제 구동해 각각 1,000스텝 시간초과, 196스텝 완주를 재현했다.

```powershell
python -m utils.jys3_rolling_expert --gui --mode old --route 7 --seed 95380107
python -m utils.jys3_rolling_expert --gui --mode new --route 7 --seed 95380107
python -m utils.jys3_rolling_expert --gui --mode old --route 5 --seed 95380105
python -m utils.jys3_rolling_expert --gui --mode new --route 5 --seed 95380105
python -m utils.jys3_rolling_expert --gui --mode old --route 5 --seed 95380405
python -m utils.jys3_rolling_expert --gui --mode new --route 5 --seed 95380405
```
