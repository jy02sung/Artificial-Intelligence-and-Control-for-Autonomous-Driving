# Rolling Merge 전문가의 고교통 1:1 비교

기준 커밋 69611a2. 학습 가중치 없이 수정 분기·안전게이트 해제·시간당 15,000대 환경에서 16개 경로 × 8개 시드(95380000 + rep × 100 + route)를 대조한다. 기존 전문가가 바꾸려는 차로에 지금 진입할 수 없는 경우에만 50차원 관측으로 종방향 목표를 조절한다. 원래 안전 판단을 유지한 strict를 먼저 평가한다. 기존 14m와 새 10m는 목표속도 상한이 0이 되는 위치이며 실제 차량이 정지하는 위치와는 다를 수 있다.

목표속도는 원래 막힘 상태의 목표에서 출발한다. 옆·앞이 막히면 옆 앞차 속도 −3.5m/s(아래 한계 5m/s), 뒤만 막히고 여유가 있으면 뒤차 속도 +3m/s 방향으로 조절한다. 현재 차로 앞차 IDM과 10m 여유 감속 상한을 적용한다. 속도 정렬의 응답시간은 기존 1.3초, 정렬 단독 감속은 2.5m/s²까지다. 1~2초 내 양보나 10~18m/s 합류는 관측할 성능이다.

일반 시간초과 직전 5초 이상 연속 정지(속도 0.001m/s 미만)한 strict 주행이 2회 이상이면 같은 128회에서 relaxed를 추가한다. remaining <25m, speed <4m/s에서만 후방 필요 간격의 뒤차 속도 계수를 0.50→0.45로 바꾼다. 접근 속도 항, 앞 간격, 겹침 기준은 유지한다. relaxed가 strict보다 10초 대기 주행을 줄이고 충돌·이탈 증가 및 완주 감소가 없을 때만 비교 대표로 삼는다. 최종 채택은 사용자 목표로 별도 판정한다.

대기는 차로변경이 필요하고 실선이 아니며 안전 기준에 막힌 연속 시간이다. 도로·차로·필요 방향이 달라지면 시간을 새로 센다. 저속 대기는 그중 실제 속도 1m/s 미만인 연속 구간이다. 전체 128회에서 대기가 없으면 0초로 계산한다. 차로변경 속도는 같은 도로에서 실제 차로 번호가 바뀐 스텝 직전의 속도를 사건별로 합산한다. 완주 시간은 완주 주행만 집계한다.
