# 전원 종료 후 복구와 자동 후속 실험

기존 실험은 약25000스텝에서 중단됐고 policy-0만 남아 있어, 기존 출력은 보존하고 같은 기준점부터 새 출력 디렉터리에서 재실행한다. 완전한 이어학습이라고 표현하지 않는다.

자동 순서: 세 조건 병렬 학습 → 저장 모델 전체 평가 → 안전 목표 충족 후보 우선, 그 안에서 완주가 높은 모델 선택 → 실패 지표에 따라 후속 배치. 충돌5% 이상이면 위험 차로 변경 벌점 계수만2배, 충돌5% 미만이나 기타 실패가 남으면 경로 보상 계수만2배. 각 배치는20만 추가 스텝이며 같은 seed의 개발 비교다. 결과를 반복해서 참고하므로 최종 성능 검증은 새 seed로 별도 실시해야 한다.

최대3배치 후에도 목표 미달이면 자동으로 계수만 계속 올리지 않고 trace 재분석 상태로 남긴다. 목표 달성은 전체 오류 없는 평가에서 완주+충돌100%, 충돌5% 미만을 함께 만족하는지로 판정하되, 개발 목표 달성만으로 최종 검증 완료라고 하지 않는다.

매 PPO 업데이트에 policy와 optimizer 및 스텝을 recovery.pt로 원자 저장한다. SUMO 상태나 난수상태까지 저장하는 완전 동일 재현 체크포인트는 아니며, 전원 종료 복구 시 에피소드 재시작 사실을 기록해야 한다.

사용자 알림: 배치 완료·선택 근거·새 실험 시작·오류 등 의미 있는 변화 때 전달한다. 출력: results/traffic_recovery_auto_20261116, 코드 utils/run_traffic_recovery_auto.py. 기존 맵/모델/원시 결과는 변경하지 않는다.
