# 양보 감속과 본선 제동 여유 조정 후 전문가 검증

기존 전문가가 51m 연결로에서 오래 기다리고 본선 차로 끝에서 3회 정지해, 양보 중 목표 속도와 가속 허용 거리를 조정했다. 후보는 고교통 512회 모두 지정 경로를 완주했다. 본선 끝 정지 3건은 해소됐으나 연결로 장시간 대기 6건 중 5건은 그대로여서 최종 시범 생성기 채택은 보류했다.

기준 커밋 `1a16fad`, 실행 커밋 `839e2d5`. 각 주행의 시드, 경로, 출발 차로를 직전 평가 기록과 대조했다. 규칙 기반 전문가, 물리적 분기, 고교통 15,000대/시, 안전게이트 OFF, 50개 관측, 기존 안전 간격, 0.2초 스텝, 재시도 없이 512회다. 지정된 두 수정은 `_decision`에 적용했다. 최종 가감속을 추가 제한하는 기존 `queue_tail`은 양쪽에서 똑같이 사용했다.

| 평가 조건 | 완주 전 → 후 | 10초 이상 연속 저속 대기 전 → 후 |
|---|---:|---:|
| 기존 평가 128 | 128 → 128 | 0 → 0 |
| 신규 패널 64 | 64 → 64 | 3 → 2 |
| 일반 시범 조건 160 | 160 → 160 | 4 → 4 |
| 혼잡 보강 시범 조건 160 | 157 → 160 | 13 → 13 |
| 전체 | 509 → 512 | 20 → 19 |

충돌, 실제 이탈, 일반 시간초과는 전후 모두 0건이다. 차로 끝 정지는 3→0건이었다. 차로변경이 막혀 1m/s 미만으로 연속 10초 이상 대기한 주행은 기존 20건 중 3건이 해소되고 8번에서 2건이 새로 발생했다(94600008, 24.4초와 94601408, 10.8초). 간격이 열린 240건 모두 첫 허용 스텝에 실제 차로가 바뀌었다.

본선 3건은 차로 끝까지 약 5.7~5.8m를 남긴 위치에서 정지 상태로 0→1차로 변경 후 완주했다. 연결로의 변화 없는 5건은 후보의 동일 관측에서 기존·수정 제어 출력을 대조했다. 차로변경이 막힌 총 1,394스텝 중 기본 가감속이 달라진 스텝은 53개, 후단 `queue_tail` 적용 뒤 가감속 차이가 0.000001을 넘은 스텝은 0개였다. 이 후단 제어는 끝에서 24m를 남기는 목표와 옆 차로 앞차의 속도·간격에 따른 목표 중 낮은 값을 사용한다. 개선된 연결로 5번에서는 선행 도로 `52873356`의 28스텝부터 가감속이 달라졌고, 연결로에 진입한 뒤 8.9m/s로 변경했다.
