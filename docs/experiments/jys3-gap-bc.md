# 혼잡 시범이 BC 학생의 합류에 미치는 영향

동일 전문가의 이전 완주 160회(57,458스텝)와 혼잡 선별 160회(59,221스텝)를 비교한다. 서로 다른 교통 시드로 수집한 두 데이터셋 전체의 비교다. 기준 코드 891cc45. 초기 모델은 시드 11로 생성한다. 조기 양보 전문가나 보강 시범 11회는 이번 학습에 넣지 않는다.

| 설정 | 수업 실습 기본 | 이번 BC 두 조건 |
|---|---|---|
| 최적화·학습률 | Adam 0.0003 | Adam 0.0004 |
| 에포크 | 50, 예시 명령 100 | 30 |
| 배치 | 256 | 기본 512에 차로변경 64개 추가, 마지막 기본 배치는 잔여 개수 |
| 입력 | 31차원 예시, 학습 세트 평균·표준편차 사용 | 환경이 정규화한 50차원 |
| 정책 | 256×256 ReLU, 연속 출력 2개 | 256×256 Tanh, 연속 가감속과 차로 명령 3종 |
| 손실 | 두 행동의 평균제곱오차 | 기본 배치의 가감속 Smooth L1(β=0.15) + 전체 배치의 차로 교차엔트로피, 기울기 노름 상한 1 |
| 시드·검증 | 0, 에피소드 단위 20% 분할 | 11, 공통 독립 전문가 주행 32회(11,555스텝) |
| 선정 | 검증 MSE 최저 | 좌·우 F1 평균 − 0.1 × 가감속 MAE 최고 |

기존 jys3의 BC 학습 함수를 그대로 사용한다. 희소한 차로 명령을 학습하는 비중을 두 조건에 동등하게 적용하기 위해 기존 추가 샘플 수를 유지했다. 수정 분기 환경, 고교통 15,000대/시, 안전게이트 해제, 16경로 × 8회, 새로운 교통 시드 95380000 + 반복 × 100 + 경로 번호에서 결정론적으로 평가한다. 합류 틈은 전문가의 관측과 차로변경 허용 기준으로 판정한다. 첫 허용 시점부터 올바른 방향 명령까지 지연과 끝까지 유지해 놓친 합류를 기록한다.

## 학습과 실제 주행 결과

두 모델의 초기 가중치 텐서 SHA-256은 `bc539bc4560a504decbf408d5f384e5d276cb26cce78d2ef6bcfa94978aefbf5`로 같았다. 각 조건 30에포크를 학습하면서 기존 시범은 총 3,390회, 혼잡 시범은 총 3,480회 업데이트했다. 시범 길이와 교통 시드가 다르므로 여기서 얻은 차이는 두 데이터셋 전체를 사용한 결과다. 학습 시드는 11 한 개다.

| 조건 | 선정 에포크 | 좌·우 평균 F1 | 가감속 MAE | 완주 | 충돌 | 실제 이탈 | 끝 정지 | 일반 시간초과 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|

| 기존 규칙 전문가, 같은 교통 시드 | 해당 없음 | — | — | 121/128 (94.5%) | 1 (0.8%) | 0 | 0 | 6 (4.7%) |

실제 도로·차로·출발 속도·잔여거리 및 첫 관측 해시가 총 128쌍에서 일치했다. 기존 충돌 43회 중 혼잡 시범 BC에서는 27회가 완주, 12회가 충돌, 4회가 이탈이었다. 기존 완주 81회 중 75회는 완주를 유지했고 6회는 충돌했다.

## 합류에 관한 두 기준

필요한 방향은 현재의 도로 안내와 차로 연결로 정하고, 차로변경 가능 여부는 기존 전문가가 관측한 앞뒤 간격·접근 속도·겹침·차선 조건으로 판정한다. 같은 도로·차로에서 필요한 방향의 첫 허용 시점을 기준으로 0.2초 간격으로 센다. 지연은 허용 중 올바른 명령을 한 경우에만 계산한다. 끝까지 놓친 사례는 첫 기회 이후 차로 명령이 계속 유지이고 실제로 차로를 바꾸지 않은 채 해당 도로에서 이탈·끝 정지·차로 끝 12m 이내 시간초과가 발생한 경우다.

| 판정 | 기존 시범 BC | 혼잡 시범 BC |
|---|---:|---:|
| 자기 주행에서 합류 기회를 만난 구간 | 56 | 63 |
| 올바른 명령을 낸 구간 / 전체 (그중 즉시) | 53/56 (53) | 58/63 (56) |
| 명령을 낸 구간의 평균 / 중앙 지연 | 0.00 / 0초 | 0.02 / 0초 |
| 기회를 보고 끝까지 유지해 합류 실패 | 1회, 16번 | 2회, 7·16번 |
| 자기 주행에서 옆 차 때문에 기다린 뒤 틈이 열린 구간 | 1 | 6 |
| 그중 올바른 명령 | 0/1 | 2/6, 각각 0초·1.0초 |
| 그중 끝까지 유지해 합류 실패 | 0 | 1 |
| **동일한 전문가 관측에서**, 대기 후 첫 기회에 즉시 정방향 명령 | **34/49 (69.4%)** | **32/49 (65.3%)** |

실제 학생 주행의 56·63개 기회에는 처음부터 틈이 있던 구간이 포함된다. 대기 후 틈이 열린 구간만 보면 자기 주행에서 분모는 1·6이다. 같은 장면의 판단은 전문가와 함께 별도 측정했다. 전문가는 동일한 128개 시드를 운전하고 두 BC 모델은 각 첫 허용 관측에 독립적으로 응답했다. 대기 후 첫 기회 49개 중 두 모델 모두 맞힌 사례 31개, 기존만 3개, 혼잡만 1개, 둘 다 놓친 사례 14개였다. 이번 개선의 가장 큰 결과는 충돌하던 주행의 완주 전환이며, 기다린 뒤 첫 합류 기회에서 명령을 더 잘 고르는 효과는 나타나지 않았다.
