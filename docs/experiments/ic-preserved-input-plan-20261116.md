# 새 관측 입력의 행동 보존 초기화 비교

## 확인한 문제와 한계

미사용 입력에도 신경망 가중치가 남아 있어 관측 추가 직후 정책이 달라질 수 있다. 저장 상태에 출발 모델을 적용한 오프라인 비교에서 다음 분기 안내의 활성 입력239개 중30개 상태에서 차선 명령이 바뀌었다. 교차 관측은 활성31개 상태 중 차선 명령 변화0개였다. 이는 상관된 저장 상태의 즉시 행동 비교이며 완주율이나 실패의 인과적 설명은 아니다.

## 독립 비교

- 기준: lane_followup/future의 기존 초기화.
- 후속: 같은 출발 정책에서 첫 층47:50 입력 열만0으로 설정. 다른 가중치와 보상·관측·학습 설정은 동일.
- 새 입력은 학습 가능하며 차선 명령을 덮어쓰지 않는다. 학습 전 기존 관측을 넣은 모델과 행동분포·가치가 같아야 한다.
- 추가20만 스텝, seed11, 평가79101~79103(교통48회, 무교통16회), 0/51200/100352/151552/200000 중간 모델.
- 후기 퇴보뿐 아니라 초기 성능도 확인하도록 원자적으로 저장된 recovery.pt에서24576스텝 정책을 추가 보존했다. 추출 원본 및 정책 해시는 로컬 snapshot.json에 기록했다. 해당 스텝의 동일 학습량 대조군은 없으므로 다른 조건의5만스텝과 동등 비교로 취급하지 않는다.
- 기존 기준 모델, 기존 미래 안내 모델과 비교하고 후보가 개선되면 별도 신규 seed 검증. 초기 가중치 해시는 의도적으로 달라지므로 동일하다고 보고하지 않는다.

## 구현·검증 순서

1. 새 입력 연결만 바꾸고 다른 가중치를 보존하는 단위 검사를 먼저 작성한다.
2. 행동분포·가치 보존 및 새 입력 연결의 역전파 기울기를 검사한다.
3. 전용 실행기에서 출발 모델을 읽을 때만 초기화한다. 저장된 학습 모델을 평가할 때 초기화하면 안 된다.
4. 짧은 학습·평가와 입력/소스 해시 확인 후 기존 평가가 끝나 비워지는 CPU 작업 슬롯에서 실행한다.
5. 중간 평가를 완료 표에 추가하고 기존 조건 대비 결과로 다음 조건을 결정한다.
