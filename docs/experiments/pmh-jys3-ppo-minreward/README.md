# jys3 DAgger 모델에 보상 2개로 PPO 추가 학습 (pmh, 2026-11-24~25)

상태: **완료**. 안전 게이트·행동 필터 없음(정책 단독 주행). 실행 코드 `utils/pmh_jys3_ppo_minreward.py`, 실행 커밋 `f009762`(pmh).

## 조건

- **시작 가중치**: `models/pmh/jys3_dagger10_fixed.pt` (BC v2 → DAgger 1~10라운드, fixed 체인). 최종 256회에서 완주 245, 충돌 2, 정지 9였다.
- **보상 (2개)**: 완주 +1, 충돌 −1. 환경 원래 보상(분기 통과 +0.25, 시간초과 −5 등)은 쓰지 않는다.
  - 시간초과·차로 끝 정지는 보상 0으로 끝나므로 이미 +1을 잃는다. 따로 벌점을 두지 않았다.
  - 시작 정책이 이미 경로를 따라가므로 분기 통과 보상도 뺐다.
- **jys3 PPO가 나빠진 원인에 대한 대응** (두 조건 공통)
  - 가치망이 학습된 적이 없었다(BC·DAgger는 행동만 학습). 그래서 PPO 전에 가치망만 2048스텝 × 10회 학습했다. 이 스텝은 학습량에 넣지 않았다.
  - 가감속 탐험 폭이 초기값 σ=0.61 그대로였다. 시작 σ를 0.22(log_std −1.5)로 두었고, 이후에는 학습된다.
- **비교 조건**

| 조건 | 내용 |
|---|---|
| `plain` | 위 PPO 그대로 |
| `kl` | 손실에 시작 정책과의 KL(차로 범주 KL + 가감속 가우시안 KL) × 1.0을 더해, 모방학습 해에서 크게 벗어나지 않게 한다 |

- **PPO 설정**: jys3와 같다(학습률 1e-4 그대로, 2048스텝 롤아웃, 10 에폭, 미니배치 64, γ .99, λ .95, clip .2, 차로 엔트로피 .002).
- **학습량·seed**: 조건마다 204,800스텝, 학습 seed 11·12. 고교통량 `high_real_ratio`.
- **에피소드**: `ScheduledEpisodes`(16경로 섞은 블록, 교통 seed = seed×10⁶ + n).
- **평가**
  - 20,480스텝마다 독립 64회(29010000대)로 평가했다.
  - 최종 256회(30010000대)는 미리 정한 마지막 체크포인트(204,800스텝)로 평가했다.

## 해석

- **보상만 쓴 PPO(`plain`)는 붕괴했다.**
  - 첫 20k스텝부터 충돌이 늘었고, 최종 256회 충돌이 65~106건이 됐다.
  - 가치망 사전 학습과 탐험 폭 축소만으로는 jys3에서 본 악화를 막지 못했다.
  - 원인으로 추정하는 것: 성공률이 96%라 실패 신호가 드물고(±1 보상, 에피소드 평균 약 350스텝), advantage 정규화가 잡음을 키운다. 또 가치 손실이 공유 몸통을 바꿔 모방학습으로 얻은 특징을 흔든다. 이 추정은 따로 검증하지 않았다.
- **KL 고정(`kl`)은 붕괴를 막았지만 개선도 없었다.**
  - 최종 256회는 243·245회 완주로 시작 모델(245)과 같은 수준이다.
  - 남은 실패도 그대로 14·13번 경로의 차로 끝 정지다.
- **결론**: 이 설정에서 보상 PPO는 DAgger 모델을 넘지 못했다. 현재 최선 모델은 그대로 `models/pmh/jys3_dagger10_fixed.pt`다.
  - 학습 seed는 조건마다 2개다.
  - 이 실험에서 바꾸지 않은 것: KL 계수(1.0) 한 값만 썼고, 학습량은 204,800스텝, 학습률은 1e-4로 고정했다.
