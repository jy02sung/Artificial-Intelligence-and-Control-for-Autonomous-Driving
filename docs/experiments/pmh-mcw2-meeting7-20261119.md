# mcw2 모델 이어 학습 + 7차 회의 답변 반영 (pmh, 2026-11-19)

## 1. 원본: mcw2

- `origin/mcw2`(`8a3d073`)를 pmh에 병합했다(`850e6d5`). mcw2 브랜치는 수정하지 않았다.
- 모델: `results/mcw_runs/mcw2_nosafety_final/best_model.pt`. 학습 코드: `utils/mcw_train.py`(수정 없음).
- 원본 모델 구성
  - 47차원 관측: ClarityEnv + RouteNavigation(400m), 감지 범위 50m.
  - 하이브리드 PPO: 학습률 1e-4 고정, 은닉층 [256, 256].
  - 안전 게이트: 끔(`--no-safety`).
  - 보상: TTC·목표 차로 간격 감점, 차로 변경 벌점 0.01, 정지·시간 초과 벌점, 차로 준비 +0.3.
  - 학습 이력: 커리큘럼 학습 → 증류(DAgger) → 가중치 0.8:0.2 보간으로 완성.
- 이 컴퓨터에서 재평가한 결과(15,000대/시간 + 실측 차종 비율, 16개 경로 × 5 seed = 80회): 완주 78/80(97.5%), 충돌 1, 시간 초과 1. 보고서와 80회 모두 결과가 같다.

## 2. 추가한 내용: 회의 답변 반영

코드: `utils/pmh_mcw_variants.py`. `mcw_train.py`를 감싸서 환경만 바꾸고, 나머지 설정은 모두 mcw2와 같다.

| 안건 | 답변 | 반영 |
|---|---|---|
| 1-(1) 감지 범위 | 150m | `--visibility 150`: 주변 차량 감지·거리 정규화·연결성·밀도 기준 50m → 150m |
| 1-(2) 노이즈 | 가우시안, 고정 → 거리 비례 단계 적용 | `--noise fixed`: 거리 σ 1.0m, 상대속도 σ 0.5m/s<br>`--noise distance`: 거리 σ 0.5+0.02×거리(150m에서 3.5m), 상대속도 σ 0.25+0.005×거리(150m에서 1.0m/s) |
| 2 내비게이션 | SUMO 제공 | `--sumo-nav`: 경로 안내 칸(obs 31~33)을 SUMO `getBestLanes()`의 최적 차로 오프셋과 현재 차로를 계속 따라갈 수 있는 거리로 대체. 팀 내비게이션 칸(obs 37~46)은 0 |
| 3 안전 게이트 금지 | 보상·관측으로 보완 | 게이트는 계속 끔. ① TTC·간격 벌점과 ③ 차로 변경 벌점은 mcw2에 이미 있음. ② 옆 차로 앞뒤 거리·상대속도는 obs 1~20에 이미 있음(mcw2에서 사라지는 문제를 고침) |
| 4 집중 구간 | 엇갈림 구간 | `--weave-weight 2`: 51m 엇갈림 구간 170059994를 지나는 route_03/04/05/13/14/15를 학습 경로 출제에서 2배 |

노이즈 적용 방식

- 감지된 차량의 관측값(거리, 상대속도)에만 더하고, 학습과 평가 모두에 적용한다.
- 보상과 충돌 판정은 실제 값을 쓴다.
- 에피소드 seed로 난수를 정하므로 평가는 재현된다.

## 3. 학습 조건

- 6개 조건 모두 mcw2 최종 모델에서 시작했다.
- `high_real_ratio`에서 PPO로 20만 스텝 학습했고, 학습률 1e-4(고정)·seed 11 등 나머지 하이퍼파라미터는 mcw2와 같다.
- 증류(DAgger)는 쓰지 않았다. 안전 게이트를 교사로 쓰기 때문이다.
- 평가: 학습이 끝난 최종 모델과, 2.5만 스텝마다 16회 평가해서 고른 최고 모델을 각각 80회 평가했다.

## 5. 해석

- **mcw2 원본을 PPO로 더 학습하면 나빠진다.** A는 원본 97.5%에서 86~94%로 떨어졌다. 원본은 증류와 가중치 보간으로 만든 모델이라 PPO 이어 학습으로는 유지되지 않는다. 회의 변경의 효과는 A를 기준으로 봐야 한다.
- **감지 150m**(B)는 최고 모델 기준 96.3%로 A보다 높다. 다만 최종 모델은 73.8%로, 학습 중 흔들림이 크다.
- **노이즈는 성능을 크게 낮춘다.** 고정 노이즈(C)는 71~81%다. 거리 비례 노이즈(D)는 71~80%이고, 엇갈림 경로 route_13·14에서 시간 초과가 10건이다. 회의 답변대로 고정 노이즈부터 단계적으로 넣는 것이 맞다.
- **SUMO 내비게이션**(E)을 쓰면 같은 거리 비례 노이즈에서도 89~91%로 회복하고, 시간 초과는 0이다. SUMO의 최적 차로 정보는 노이즈가 섞이지 않은 경로 정보라서 끼어들 틈을 판단하는 데 덜 흔들리는 것으로 본다(검증 안 함).
- **엇갈림 구간 2배**(F)는 E와 완주율이 같다(91.3%). 엇갈림 경로 완주는 25→26, 시간 초과는 0이다.
- **회의 답변을 전부 반영한 F**: 완주 91.3%, 충돌 8.8%다. 목표(완주 ≥95%, 충돌 <5%)에는 못 미친다. 감지 범위가 넓어지고 노이즈가 들어간 더 어려운 조건이므로, 노이즈가 없는 원본 97.5%와 직접 비교할 수는 없다.
- **한계**
  - seed 1개, 20만 스텝 결과다.
  - 16회 평가로 고른 최고 모델과 최종 모델의 차이가 크다. 결론의 차이 중 일부는 학습 흔들림일 수 있다.

## 6. 다음 후보

- F 조건에서 seed를 늘리고, 학습을 원본 mcw2처럼 커리큘럼(none→low→high→high_real_ratio)부터 다시 한다.
- 노이즈 커리큘럼: 고정 노이즈로 수렴시킨 뒤 거리 비례 노이즈로 넘어간다. 회의 답변의 단계 적용을 학습 일정에 반영하는 것이다.
- 남은 충돌(route_13·02)을 `utils/pmh_collision_replay.py` 방식으로 재생해 원인을 분석한다.

## 7. 재현

```bash
# 원본 평가
python -X utf8 -m utils.mcw_train --stage high_real_ratio --eval-only --eval-episodes 5 --no-safety \
  --lc-penalty 0.01 --lane-keep-bias 0.5 --timeout-penalty 15.0 --stall-penalty 0.08 \
  --resume results/mcw_runs/mcw2_nosafety_final/best_model.pt --name pmh_eval_mcw2_final_80ep
# F 학습 (회의 답변 전부)
python -X utf8 -m utils.pmh_mcw_variants --visibility 150 --noise distance --sumo-nav --weave-weight 2 \
  --stage high_real_ratio --steps 200000 --seed 11 --no-safety --lr 1e-4 --lane-entropy 0.002 \
  --lane-keep-bias 0.5 --lc-penalty 0.01 --timeout-penalty 15.0 --stall-penalty 0.08 \
  --eval-interval 25 --eval-episodes 1 --resume results/mcw_runs/mcw2_nosafety_final/best_model.pt \
  --name pmh_F_all_weave2
```
