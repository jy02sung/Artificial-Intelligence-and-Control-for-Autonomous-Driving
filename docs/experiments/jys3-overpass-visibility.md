# 고가 램프 차량의 시야 가림 수정

11번 경로의 기존 충돌 1건에서, 원본 지도에 교량으로 표시된 `170059996`의 배송차가 아래 본선 `206426298`을 달리는 승용차를 가렸다. 센서는 차량의 평면 위치만으로 가림을 계산했다.

수정한 센서는 원본 지도에서 교량과 층을 확인하고, SUMO 지도에서 차로가 평면상 교차하면서 접속점은 공유하지 않는 도로 쌍 20개를 사용한다. 관측 차량과 대상 차량이 같은 도로 구간에 있고, 가림 후보 차량이 다른 층의 도로를 달리며 그 차체가 해당 교차 구역과 겹칠 때 가림에서 제외한다. 정책 입력은 50개이며 차량별 높이 이력은 저장하지 않는다.

## 동일 시드 재생

수정 분기 환경, 고교통 15,000대/시, 11번 경로, 출발 0차로, 시드 95380211. 같은 규칙 기반 전문가 `queue_tail`로 각각 1회 주행했다.

| 항목 | 기존 센서 | 수정 센서 |
|---|---|---|
| 297스텝 왼쪽 승용차 | 가려짐 | 감지 |
| 왼쪽 차량과 나란히 있다는 관측 | 0 | 1 |
| 297스텝 전문가 명령 | 왼쪽 변경 | 차로 유지 및 감속 |
| 이후 주행 | 298스텝 본선 1차로 측면 충돌 | 322스텝 왼쪽 명령, 489스텝 완주 |
| 완주 / 충돌 / 끝 정지 / 시간초과 / 실제 이탈 | 0 / 1 / 0 / 0 / 0 | 1 / 0 / 0 / 0 / 0 |

기존 128회 평가 중 충돌이 발생한 시드 한 건을 대상으로 한 재현 결과다. 같은 높이의 차량, 등록되지 않은 다른 도로, 등록된 교차 구역 밖의 가림은 별도 센서 테스트로 확인했다.
