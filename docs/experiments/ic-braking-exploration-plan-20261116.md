# 감속 탐험 폭 단독 비교

Goal: 사전 위험 관측과 안전 보상 조합에서 희소한 감속 탐험이 학습을 제한하는지 검증한다.
Architecture: 기존 anticipatory 환경·보상·네트워크를 재사용한다. 출발 정책을 읽을 때 연속 가감속 분포의log_std 하나만-0.5(std≈0.60653)로 재설정하고 이후에는 기존 PPO가 그대로 학습한다. 모델의 평균 가감속, 차선 확률, 가치 출력은 바꾸지 않는다.
Tech stack: PyTorch hybrid PPO, libSUMO, unittest.

## 가설과 독립 비교

기존 정책에서 위험 상태별 감속 샘플 확률이0.33~0.42%,150m 관측51,200모델에서는0.040~0.055%였다. 이는 한 재생 사례의 조건부 확률이며 전체 학습의 원인으로 확정하지 않는다.

대조군: safety_strength_trials/anticipatory(lr0.0003). 새 조건: 같은 모든 설정, 시작할 때 가감속 std만 원래 새 정책의 초기값exp(-0.5)로 복원. 학습률을 낮춘 실험과는 별개다. 학습 후 저장 모델을 평가할 때 std를 다시 초기화하지 않는다. 결정적 평가는 기존처럼평균 가감속+차선argmax. 강제 감속·안전장치·경로 보정0.

초기에 위험한 탐험이 늘 수 있으므로 훈련 중 충돌을 성능 개선으로 보지 않는다. 같은5/10/15/20만 체크포인트, 동일 seed79101~79103 및 무교통16경로로 비교한다. 성공 후보만 신규seed 검증. 출발 모델과 기존 결과는 보존한다.

## 구현·검증

- [x] 순수 초기화 함수 테스트: log_std만 변경, mu/logits/value 불변, 잘못된 std 거절.
- [x] 새 wrapper: 원본 출발 모델 경로에만 재설정, 학습 체크포인트 로드는 보존.
- [x] smoke32스텝+4회평가, 대조군과 모든 초기 텐서(log_std 제외)·입력 해시·hp 동일성 확인.
- [ ] 완료된 학습 슬롯에서20만스텝 학습. 중간 모델 평가 및 희소 감속 상태의 출력 변화 분석.

검증 기록: 32스텝 smoke 및4회평가 완료. 초기 텐서는log_std만 달랐으며 입력 해시·다른 학습 설정 동일. 표준편차0.287626→0.606531. 저장 모델 재로딩 시 학습된 표준편차를 유지함을 확인했다.
