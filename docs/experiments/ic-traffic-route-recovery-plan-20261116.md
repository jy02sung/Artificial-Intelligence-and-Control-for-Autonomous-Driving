# 안전 기준점 이후 길찾기 개선 실험

기준: lane/policy-151552.pt (신규320회 완주267, 충돌14, 시간초과39). 원본은 보존한다.
2·13·14번 대표 시간초과 trace는 앞차 없는 비연결 차로 끝 정지였다. 이것만으로 진입 당시 교통 영향까지 배제하지 않는다.

|조건|변경|
|---|---|
|control|동일 안전 보상으로 추가 학습만 수행|
|route|기존 목적지 차로 선택·유지 보상을 추가|
|opportunity|route + 안전한 목표 방향 차로 변경 기회를 놓친 스텝에 벌점|

세 조건은 같은 기준 가중치에서 시작한다. 관측63차원, 맵, HV, PPO 파라미터 고정. optimizer는 동일하게 초기화한다. 강제 보정 없음.
route: 다음 도로 연결 차로까지 거리 감소에 +0.1/차로, 이탈 -0.1, 올바른 차로로 전진 시 +0.005/m(해당 구간 누적0.5 상한). 기존 검증된 selection_reward 재사용.
opportunity: 300m 이내 잘못된 차로이고 목표 방향 인접 차로의 기존 안전위험값<0.2, 속도>0.5m/s인 경우에만 -0.008/스텝. 정지 대기에는 적용하지 않는다. 계수는 검증할 가설이다.

각 조건 seed11, 추가20만 스텝; 0/약5만/10만/15만/20만 모델을 무교통16회+교통48회 평가한다. 평가 seed59101~59103, 세 조건 동일. 총960회. 3개 프로세스로 병렬 실행하고 완료 모델을 자동 평가한다. 최종 모델이 최고라고 가정하지 않는다.

선택 기준: control 대비 시간초과 감소와 완주 증가, 충돌 증가 여부를 함께 평가. 완주+충돌만으로 채택하지 않는다. 보상 발생 횟수·총량, 안내 방향 요청/실제 변경, 올바른 차로 유지와 위험 시 감속을 기록한다. 개선 후보만 신규20seed 평가와 학습seed22/33 재현으로 넘어간다. 이 후속 대규모 검증은 결과 판정 후 진행한다.

실행 전 실제 SUMO 소규모 학습/평가로 세 조건의 초기 가중치 동일성과 코드해시·강제보정0을 확인한다. 원시 결과는 results/traffic_route_recovery_20261116에 보관하고 요약만 Git에 올린다.

진단 확인: lane 시간초과 중 2번11건·13번12건·14번12건 모두 route_lane_blocked. 종료 직전 상태에 대한 분류이며 당시 차선변경 실패 원인 전체를 확정한 것은 아니다. opportunity는 목표 방향 명령을 내린 스텝에는 벌점을 부여하지 않는다.
