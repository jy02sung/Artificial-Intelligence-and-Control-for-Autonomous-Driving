# 합류 확인 거리와 물리 감지 거리 분리

## 원인 진단

1·2번 경로의 진입 edge169728849는 zipper 노드1808903166으로 연결된다. 기존 교차위험 관측은 getJunctionFoes의 경로상 합류 지점 검색 거리에도 물리 감지거리50m를 사용했다. 따라서 바로 옆에 있어 감지 가능한 차량이라도 합류 지점이50m보다 멀면 후보에서 빠진다.

기존 정책 route_01, seed69101/69103의13.4초 충돌을 그대로 재현했다. 상대차flow_route_07.224는 경로상 합류 지점까지 약148/150m 남았을 때 물리적으로 약40/49m 거리에 있었다. 검색 범위50m에서는 위험 정보가 각각 합류선47.7/49.7m 전에야 들어왔다. 당시 속도27.78m/s, 최대 감속5.4m/s²로 이상적 정지거리71.46m,1스텝 반응거리5.56m다. 이 비교는 합류선 이전 정지 가능성에 관한 것이며 모든 대체 행동의 불가능성을 의미하지 않는다.

100m 검색은 합류선97.7/99.7m 전에 위험을 확인했고 당시 상대차 물리 거리는28.4/35.1m로 여전히50m 안이었다.150m 검색에서는 위험 함수가 양수가 되는 시점이 합류선136.6/138.6m 전이었다.

## 독립 비교

- near50: 경로상 합류 검색50m, 물리 감지50m.
- ahead150: 경로상 합류 검색150m, 물리 감지50m.
- 두 조건 모두 기존 교차위험3개 관측(60:63), 동일 위험 함수·보상·행동·도로·교통·학습 설정을 사용한다. 입력60:63의 연결 가중치만0으로 초기화하여 기존 정책의 시작 행동을 보존한다.
- 현재 실제50m 안의 차량 위치·속도와 지도 연결만 사용한다. 우선권 응답 플래그, 미래 실제 궤적,50m 밖 차량은 정책에 제공하지 않는다.
- 출발 정책 round-02/route/policy-200000.pt, seed11, 추가20만스텝. 개발평가79101~79103, 교통48회·무교통16회,0/51200/100352/151552/200000.
- 기존 관측50m 조건과의 비교에는 초기화 차이가 있으므로 near50/ahead150의 동일 초기화 비교로 검색 거리 효과를 분리한다. 개선 후보만 신규seed 검증하고, 확인된 보상 개선과의 조합은 이후 별도 조건으로 둔다.

## 검증 순서

1. 물리50m 안·경로50m 밖인 차량의 후보 포함 여부, 물리50m 밖 차량 제외를 단위 검사한다.
2. 두 조건의 짧은 학습·평가, 동일 초기 가중치 및 설정을 검증한다.
3. 실행 자원에 맞춰 조건을 시작하고 기존 진행 실험을 보존한다. 완주·충돌·기타 및 위험 인지 시점을 비교한다.

검증 완료: 두 조건의 짧은 학습·평가 통과 및 초기 가중치 동일. seed69101 재현67스텝에서 near50 관측은 기존50m 구현과 매번 정확히 같았다. ahead150은7.8초부터 위험을 표현했고 기존50m는 그 시점0이었다. 새 입력 연결을0으로 둔 정책은 기존13.4초 충돌을 그대로 재현하여, 이 검사가 행동 변경 없이 관측만 비교했음을 확인했다. 학습 후 개선 효과는 아직 검증 전이다.

## 첫 중간 모델의 재생 진단

150m 관측51,200모델은 무교통16/16완주. 교통 부분평가9회는 완주5/충돌4여서 남은 개발 평가를 보류했다. 전체48회 완주율로 환산하지 않는다. 학습은 계속한다.

route_01/79103을 기존 출발 정책과 학습 모델로 재생해, 각각 저장된 평가와 동일한13.2초 충돌을 확인했다. 강제 보정0, 모델 및 소스 해시를 보존했다.

|항목|기존 출발 정책|150m 관측51,200모델|
|---|---:|---:|
|물리 감지 범위 안에서 합류 위험 양수 최초 시각|9.8초|9.6초|
|위험 발생 이후 감속 명령 최초 시각|11.4초|11.4초|
|그때 속도|27.78m/s|27.78m/s|
|충돌 시각|13.2초|13.2초|

기존 정책의 위험 시각은 분석용 계산이며 정책 입력에 추가하지 않았다(해당 입력 가중치는0). 두 정책의 앞선 행동이 달라 위험 최초 시각0.2초 차이를 관측 기능 자체의 효과로 해석하지 않는다.

학습 모델의 감속 전 위험 상태9개에서 합류 입력60:63을0으로 가정한 정책 출력을 별도로 계산했다. 실제 실행 행동은 바꾸지 않았다. 가감속 출력 최대 차이는0.0254였고, 가속/감속 부호가 바뀐 상태는0개였다. 입력이 완전히 무시됐다고 단정할 수는 없지만 이 장면에서는 조기 감속 결정에 충분히 활용되지 않았다. 진행 중인 위험·속도 보상 조합이 이를 바꾸는지 후속 평가한다.
