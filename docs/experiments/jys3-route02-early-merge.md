# 2번 경로 전문가의 조기 합류 가능성

기준 커밋 3188524. 학습 가중치 없이 기존 전문가와 같은 초기 상태·교통 시드 94601802를 재생한다. 전문가가 유지한 5개 시점에서 각각 왼쪽 명령 한 번만 대체하고 이후 상태에 맞춰 원래 전문가를 실행한다. 시점은 접근·감속·정지 구간별로 전문가의 앞뒤 간격 기준에 가장 근접한 관측에서 골랐다. 완주와 충돌, 실제 다음 차로, 명령 직전 옆 차로 후속 차량의 이후 3초 최소 가속도를 원래 주행과 비교한다.

## 재생 결과

원래 전문가는 124.6초에 처음 이 구간에서 왼쪽을 명령해 총 658스텝에 완주했다. 각 재생은 개입 직전까지 저장된 50개 관측과 전문가 행동의 완전 일치를 검사했다. 다섯 시점 모두 개입 직후 0→1차로로 바뀌고 완주했다. 아래 가속도는 명령 직전 옆 차로의 가장 가까운 후속 차량을 같은 차량 ID로 추적한 3초간 최솟값이다. 총교통량이 아닌 이 차량에 미친 국소 영향을 나타낸다.

| 명령 시각 | 관측 뒤 간격 / 전문가 요구(m) | 원래 후속차 최소 가속도(m/s²) | 조기 합류 시(m/s²) | 완주 스텝 |
|---|---:|---:|---:|---:|
| 71.2초 | 7.83 / 18.47 | −0.09 | −9.00 | 383 |
| 74.2초 | 15.13 / 25.17 | +0.50 | −9.00 | 397 |
| 85.4초 | 27.70 / 32.63 | +0.51 | −7.00 | 463 |
| **88.2초** | **33.59 / 35.01** | **+0.41** | **+0.47** | **477** |
| 111.6초 | 37.35 / 37.91 | −3.50 | −9.00 | 594 |

88.2초에는 앞 간격도 4.43m로 요구 3.0m를 만족했다. 실제 진입을 36.4초 앞당겼고 지정 경로 완주도 181스텝(36.2초) 빨라졌다. 후속 차량은 관측한 3초 동안 계속 가속했다. 반면 다른 네 개입에서는 −7~−9m/s² 급감속이 발생했다. 한 시드의 반사실 비교이므로 조건을 일괄 완화할 근거로 쓰기보다, 주변차 반응을 포함한 전문가 회귀검증 사례로 사용한다.
