# 2번 경로 전문가의 조기 합류 가능성

기준 커밋 3188524. 학습 가중치 없이 기존 전문가와 같은 초기 상태·교통 시드 94601802를 재생한다. 전문가가 유지한 5개 시점에서 각각 왼쪽 명령 한 번만 대체하고 이후 상태에 맞춰 원래 전문가를 실행한다. 시점은 접근·감속·정지 구간별로 전문가의 앞뒤 간격 기준에 가장 근접한 관측에서 골랐다. 완주와 충돌, 실제 다음 차로, 명령 직전 옆 차로 후속 차량의 이후 3초 최소 가속도를 원래 주행과 비교한다.
