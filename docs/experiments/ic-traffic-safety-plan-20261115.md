# 교통 정책 기반 안전 보상 및 조합 탐색 (2026-11-15)

## 기준과 목적
기존 교통학습 `route_following_trials_20261114/runs/baseline/policy-200000.pt`에서 시작한다. 원본은 변경하지 않는다. `.pt`에는 신경망 가중치만 있으므로 정책/가치망은 이어받고 Adam 상태는 새로 시작한다. 모든 대조군에 동일하게 적용하며 완전한 학습상태 재개라고 부르지 않는다.

1차: 길찾기 실패를 줄여 완주+충돌을100%에 접근시키되, 충돌로 일찍 종료한 모델을 성공 후보로 간주하지 않는다. 후보선정은 기타실패·충돌·실제완주를 함께 보며 기존 정책에 비해 무엇이 나빠졌는지 표시한다. 조합 후보를 찾고 그 후보부터 이후 한 요인씩 제거/조정한다.

## 네 조건
- baseline: 기존 관측/보상 그대로 교통에서 추가20만스텝. 학습을 더 한 효과의 대조군.
- gap: baseline에 현재 차로 앞차 안전거리 부족 벌점만 추가. 물리간격=SUMO gap+ego minGap, 목표간격=minGap+1.5×ego속도, 부족비율=max(0,1−물리간격/목표간격). 매스텝−0.1×부족비율.
- lane: baseline에 요청한 인접차로의 앞/뒤 안전거리 부족 및3초 이내 접근 위험 벌점만 추가. −0.1×max(앞/뒤 간격부족, 앞/뒤 접근위험). 실제 존재하는 인접차로로 변경 요청할 때만 적용. 명령은 차단하지 않는다.
- combo: 상세 사전안내+위 두 안전보상+차로선택/유지 보상(+0.1 접근, 전진1m당+.005 최대+.5, 이탈−.1). 기존 느린앞차 막힘 벌점은0으로 하여 안전한 양보와의 충돌을 줄인다. 여유 관측60~62에 좌/현재/우차로의 앞뒤 접근위험(max)을 추가한다. 체류 벌점은 이번 조합에 넣지 않는다. 이 조건은 여러 요소를 동시에 바꾼 후보탐색이며 개별 인과효과를 주장하지 않는다.

고정: 16경로, 기존 reference교통 입력(15,000대/h), 맵·가감속/차로변경 적용·PPO 기본 파라미터 그대로. seed11. 자동제동/차로안전게이트/강제경로수정 없음. 경로안내300m.

## 검증과 기록
1. 보상 함수·조건격리 테스트. 무교통 앞차 없음은 안전거리추가벌점0. 모델입력 차원63 유지.
2. 실제 SUMO 짧은 학습/평가, 같은 원본 가중치 및 소스/입력hash 검증.
3. 최대3작업 병렬, 우선 baseline/combo/gap 이후 lane. 추가학습0/약5만/10만/15만/20만 정책 평가. 추가학습 스텝과 원본20만을 명확히 구분.
4. 각 checkpoint 무교통16회+교통48회, 평가seed39101~39103. 매 사례 직후 partial 결과 저장. 완주/충돌/시간초과, 안내반응, TTC3초 미만 감속 요청/실제감속, 위험차로변경 요청, 보상 성분 기록. 충돌 직전5초와 첫상태 보존.
5. 단일seed 탐색이므로 최종 채택 전 seed반복과 별도 검증 필요. 지도나출발조건을 쉽게 바꾸지 않는다. 원시정책/자료 로컬, 요약 GitHub.

구현: `env/traffic_safety_trials.py`, `utils/run_traffic_safety_trials.py`, `tests/test_traffic_safety_trials.py`.

## 구현 및 사전 검증
12개 단위검증 통과. 실제 SUMO 4조건 짧은 학습과0/32스텝 무교통·교통 평가 총16회 통과. 모든 조건의 초기 신경망 텐서가 원본 교통 정책과 일치하고 action_safety=False·강제보정0 확인. 짧은 검증의 완주율은 성능 결과로 사용하지 않는다. 중간 평가 사례별 partial파일 저장으로 미완료 체크포인트도 끝난 사례를 확인할 수 있게 했다.
