# 남쪽 합류 보조차로의 단발 왼쪽 명령 재생

고정 경로에서 학습한 S1 60만 모델(학습 시드 22)을 수정 환경에서 재생했다. 도로 844484877의 0차로에서 끝 정지한 8회 중 중복을 합친 6개 출발 조건이 대상이다. 원래 명령을 유지한 6회 모두 기존과 같은 스텝에 끝 정지했고 보조차로에서 왼쪽 명령은 0회였다.

각 주행은 동일한 가중치·교통 시드·출발 차로에서 다시 시작한다. 처음으로 잔여 거리가 150, 115, 100, 80, 60, 40, 20, 0m 이하가 된 스텝에 좌우 명령 하나만 왼쪽으로 바꿨다. 해당 스텝 가감속과 이후 전 행동은 원래 정책이 결정한다. 공통 거리 시험 48회에서 완주 26회, 충돌 22회. 시드 45110108은 중간 거리의 성공 시점을 찾기 위해 10개 거리를 추가했고 6회 완주했다.

## 실제 완주한 대표 시점

실측 간격은 가림과 센서 노이즈 적용 전 환경 이웃 조회값, 정책 간격은 모델이 실제 받은 정규화 관측을 m로 환산한 값이다. 앞·뒤 모두 목표인 왼쪽 1차로 기준이다. 행동 확률은 정책의 범주별 출력이다. 결정론 평가에서는 가장 큰 확률의 행동을 실행했다.

6개 대표 시점 모두 현재 차로의 물리적 연결 플래그는 0·0, 왼쪽 차로는 1·1이었다. 현재 차로의 잔여거리 기반 연결성도 1보다 작았다. 왼쪽 차로의 앞뒤 이웃·겹침·밀도 입력만 빈 차로 값으로 바꿔 정책의 출력을 다시 계산해도 6개 전부 왼쪽이 최댓값이 되지 않았다. 이 입력 변경은 모델 반응을 확인하는 별도 계산이며 주행 결과는 원래 교통으로 측정했다.
