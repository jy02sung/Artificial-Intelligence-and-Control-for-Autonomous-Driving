# 다음 실험: 관측 활용 / 보상 크기 / 보상 발생 기회 분리

이번 문서는 다음 비교 설계다. 자동으로 추가 학습을 시작하지 않는다. 기존 결과와 정책은 보존한다.

## 먼저 바로잡을 기준

현재3조건은 과거 성공한 무교통 정책의 이어학습이 아니라 seed11·랜덤 초기화·교통15,000대/h·20만스텝 비교다. 따라서 이전 성공 정책의 길찾기 능력이 유지된다는 전제는 성립하지 않는다. 다음에는 무교통16경로를 먼저 검증한 뒤 교통으로 확장한다. 무교통 평가의 높은 완주율은 안전성 증명이 아니며 충돌 회피는 별도 교통 평가가 필요하다.

모든 신규 비교는 동일한63차원 입력/초기 가중치/PPO 파라미터/경로 스케줄/seed/예산을 고정한다. 무교통이라는 환경 변경 자체를 관측·보상 개선 효과로 주장하지 않는다. 별도의 무교통 기준을 함께 학습한다. 범위를 줄인 경로만 잘 되는 결과를16경로 성능으로 보고하지 않는다.

## 1차: 무교통에서 원인 분리 (아직 미실행)

공통:16경로 균등 순환, seed11,200,000스텝, 기존 시작조건·맵·행동 그대로, 강제보정 없음. 각 비교는 기준에서 한 요인만 변경한다. 기존중간10만/20만 정책을 유지하고, 새 실험은5만 단위 중간모델도 평가한다.

| 조건 | 변경 하나 | 구분할 가설 |
|---|---|---|
| 무교통 기준 | 기존 경로안내·기본보상 | 교통을 배우기 전 경로선택 자체를 학습할 수 있는가 |
| 간결한 사전안내 | 동일 준비 계산의 유효성·합류후 상대방향만 추가, mask·비용 채널은0 | 많은 미래mask보다 행동에 바로 연결되는 표현이 도움이 되는가 |
| 기존 선택보상 | 현재 선택·유지 보상 그대로 | 무교통에서 차로변경 경험이 늘면 보상이 실제로 자주 발생하는가 |
| 보상 크기5배 | 위 선택·유지·이탈 성분 전체×5, 발생조건 동일 | 발생 기회는 충분한데 크기만 약했던 것인가 |
| 잘못된 차로 지속 벌점 | 기존 선택·유지 보상에 비연결차로 체류 벌점만 추가 | 실제 변경 전에는 신호가 거의 없는 문제가 원인인가 |

마지막 조건의 초기 제안은 현재edge에 유효 목표차로가 있고300m 이내일 때 `-0.02 × dt/0.5 × min(목표까지 차로수,1)`이다. 정지 중에도 적용한다. 목표정보가 없거나 내부junction이면 적용하지 않는다. 교통에서는 안전한 양보에도 불이익을 줄 수 있으므로 우선 무교통으로 제한하고 안전거리 보상과 동시에 튜닝하지 않는다. 이 수치는 검증된 최적값이 아니다.

관측 표현의 효과를 확정하려면 기존 풍부한 사전안내도 동일 무교통 조건으로 대조한다. 비용이 부담되면 무교통 기준+간결안내+기존선택보상을 먼저 실행하고, 선택보상 대비 크기5배/지속벌점을 두번째 묶음으로 실행한다. 묶음 간 기준을 바꾸지 않는다.

## 반드시 저장할 것

- 학습 중 선택보상 횟수/합계, 유지보상 스텝/합계, 이탈벌점 횟수/합계, 기타보상 합계. rollout 업데이트 단위로 저장한다. 이전 실험은 학습 성분별 기록이 없어 정확한 학습 중 발생 횟수를 복원할 수 없다.
- 안내가 유효하고 변경이 필요한 주행 중 상태 수, 올바른 방향의 확률과 argmax 요청, 요청 전달, 실제 차로변경, 맞는 차로 이탈.
- 무교통 정지: 올바른차로 감속 정지 / 비연결차로 끝 정지 / 기타를 분리한다.
- 상태별 입력 가림 검사는 입력 활용 민감도 진단일 뿐이다. 학습 분포 밖 입력이므로 가린 평가의 성능을 정식 대조군으로 취급하지 않는다.

## 판정

크기5배만 개선되면 크기 부족 가설을 지지한다. 크기5배는 개선되지 않고 지속벌점이 개선되면 신호 발생 방식/밀도 문제를 지지한다. 간결안내가 개선되면 표현의 학습 난이도 문제를 지지한다. 한seed로 확정하지 않고 후보와 기준을 seed22/33으로 반복한다. 후보선정용 평가와 최종검증seed는 분리한다.

무교통16경로 완주 및 실패 유형 확인을 통과한 후보만 동일 모델에서 교통 조건으로 확장한다. 교통을 넣은 뒤 완주 저하를 경로선택과 충돌회피로 다시 나누며, 충돌을 완주로 집계하지 않는다.
