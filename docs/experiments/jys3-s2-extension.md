# S2 충돌 −7 연장 학습과 S1 시간초과 진단

30만 스텝의 같은 128회에서 S2는 완주 83건, 충돌 6건, S1은 완주 64건, 충돌 14건이었다. 당시 승격 기준은 20만·25만·30만 합산 완주였고 S1이 194 대 189로 앞섰다. 이번에는 S2의 30만 성적이 더 긴 학습과 세 학습 시드에서도 유지되는지 확인한다. S2는 30만에 16번 0차로 본선 복귀 4/4, 13번 목표 진출 1/8이었다.

## 진행 조건

S2 학습 시드 11·22는 30만 가중치, Adam, 난수 상태와 진행 중인 주행을 복원했다. 시드 33은 S1과 같은 초기화 방식으로 0에서 시작한다. 고교통 15,000대/시에서 세 모델 모두 60만까지 학습한다. S1과의 설정 차이는 충돌 보상 −5→−7이다. 정책 손실·가치 손실·엔트로피·근사 KL을 업데이트마다 기록한다.

5만마다 64회/학습 시드로 평가하고, 대표 모델과 60만 모델을 기존 세 교통 시드군에서 각각 192회씩 검증한다. 대표와 최종이 같으면 같은 가중치는 한 번 평가한다. 모든 시드군은 S2 학습과 체크포인트 선택에서 분리하며, S1 성적은 이번 연장 결정 전에 공개됐다.

실행 명령은 `python -m utils.jys3_reward_simple_v3 --s2-extension`이다. 로컬 기준 폴더는 `results/jys3_ppo_comparison/pure_f/reward_simple_v3`, S2 추가 결과는 하위 `s2_extension`에 저장한다. [원래 실험과 최종 비교](jys3-reward-simple-v3.md)

## S1 시간초과 106회 전수 재생

60만 S1 세 모델의 고교통 최종 검증 576회에서 90회는 차로 끝 정지, 16회는 1,000스텝(200초) 시간초과로 끝났다. 같은 가중치·교통 시드·출발 차로로 재생하고 원본 종료 종류·종료 스텝·분기 통과 횟수·누적 전진 보상을 대조했다. 모든 시간초과에 −5가 적용됐다. 개별 주행별 원자료는 기준 폴더의 `S1_600k_timeout_cases.csv`에 보관한다.

### 차로 끝 정지 90회

모두 종료 시 차로 끝까지 0m였다. 90회 모두 마지막 도로에서 목표 도로와 연결되지 않은 차로에 있을 때 연결 차로 쪽 명령이 한 번도 없었다. 마지막 150스텝 내내 차로 유지 63회, 내내 오른쪽 17회, 유지와 방향 명령 혼합 10회였다. 71회는 150스텝 모두 가속을 명령했다.
