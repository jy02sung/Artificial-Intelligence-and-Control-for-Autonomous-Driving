# 퇴계원 단독 맵 기본 차량 검증

- 전체 맵 `maps/toegyewon_osm`은 그대로 보존한다.
- 별도 `maps/toegyewon_only`에 사용자 화면 범위를 자른다. 동쪽은 사노IC 앞, 서쪽/남쪽은 표시한 경계까지이며 접속부 내부 차로 형상은 재생성하지 않는다.
- 모든 경우: 경계 진입 도로→경계 진출 도로의 반복 도로 없는 모든 연결 경로. 무한 순환은 제외하고 경로 목록을 저장한다.
- H0: 각 경로 × 시작 차로 × Krauss/IDM/EIDM/ACC, 한 대씩 무교통 통과. 출발 거부, 충돌, 시간초과, 텔레포트를 구분한다.
- A0: 저장된 기본 R0(seed11/22/33,20만 스텝), best/max 출발, 무교통,900초. 새 맵에 대한 전이 기능 검증이며 새 학습 또는 95% 통계 보장이 아니다.
- 실패 시 B: 같은 AV 행동 제약에서 경로를 아는 진단 제어와 비교한다. 실패 마지막60초의 실제 차로, 다음 도로, 연결 가능한 차로, 정지 위치를 남긴다.
- H0/A0 검토 후 시작 조건 강건성→최소 재학습→낮은 교통량 순서로 진행. 도로/보상을 성공하도록 몰래 변경하지 않는다.
- 목표는 경로별 완주95% 이상/충돌5% 이하. H0는 교통량/지퍼 성능 검증이 아니며 이번 단계에서 혼잡 교통은 넣지 않는다.
- 기존 IC 관측 구조를 유지하고 OSM의 램프 유형을 기존 램프 플래그에 연결한다. 사노 지퍼 관측은 해당 도로가 없어0이다. 변경된 도로 분포에서 기존 정책이 실패할 수 있으므로 옛 맵 성적과 직접 개선율 비교하지 않는다.
