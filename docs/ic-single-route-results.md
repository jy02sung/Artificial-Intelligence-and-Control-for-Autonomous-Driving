# south_to_east 단일 경로 관측 실험 결과

## 1. 최초 시작 조건 검증

진단 제어로 20개 후보를 검증했다. 17개는 완주했고, 차로3/4/5에서 25m/s로 출발하는 3개는 SUMO가 차로 변경 거리 부족으로 삽입을 거부했다. 이는 학습 정책의 시간초과/충돌과 별도인 **유효하지 않은 시작 조건**이다. 도로·제약을 바꾸지 않았다.

원본: results/ic_single_route_v1/start-validation-initial.json. 이 실패 기록을 보존하고, 학습 전에 평가 조건의 해당3개만 같은 차로의 정지출발(0m/s)로 교체하여 재검증한다. 결과는 제한된 시작 조건 범위에서만 해석한다. 평가 조건은 학습 결과를 본 뒤 선택하지 않았다.

학습 조건도 독립 검증한다: 차로0~2는7/17/23m/s, 차로3~5는3/7/13m/s. 총18개, 위치0m 유지. 평가와 학습의 숫자 속도는 겹치지 않지만 best/max 실제속도 중복 여부는 별도 기록한다.

## 2. 유효한 시작 조건 및 관측 변경 검증 완료

최초 실패3개를 기록한 뒤 해당차로의 정지출발로 바꾼 평가20개는 진단 제어 **20/20 완주, 충돌0**. 별도 학습 시작18개도 **18/18 완주, 충돌0**. 이는 PPO 성능이 아니라 환경의 통과 가능성 검증이다.

평가20개의 동일 초기 상태에서 기존/수정 관측37개 중 의도한 분기거리·목표차로방향2개 외에는 모두 정확히 동일함을 확인했다. 기존 분기거리는 -1, 수정 분기거리는 유효값이었다. 수정 거리값은 현재 차로 끝까지 거리와 이후 외부edge 길이를 합하며 내부 연결edge 길이는 제외한 근사값이다. 이후 분기에서 차로번호 체계가 달라질 수 있으므로 현재edge가 아닐 때 방향은 현재 best-lane 방향을 사용한다. 보상 계산용 context는 바꾸지 않았다.

다음 실행은 seed11 각200,000스텝의 처음부터 학습이다. 두 조건은 별도 프로세스로 실행하며 총학습량은 동일하다. 시간 성능 비교는 하지 않는다. 모델선정 없이 마지막 체크포인트를 평가한다.
