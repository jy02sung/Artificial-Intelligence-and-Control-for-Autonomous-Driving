# south_to_east 단일 경로 관측 실험 결과

## 1. 최초 시작 조건 검증

진단 제어로 20개 후보를 검증했다. 17개는 완주했고, 차로3/4/5에서 25m/s로 출발하는 3개는 SUMO가 차로 변경 거리 부족으로 삽입을 거부했다. 이는 학습 정책의 시간초과/충돌과 별도인 **유효하지 않은 시작 조건**이다. 도로·제약을 바꾸지 않았다.

원본: results/ic_single_route_v1/start-validation-initial.json. 이 실패 기록을 보존하고, 학습 전에 평가 조건의 해당3개만 같은 차로의 정지출발(0m/s)로 교체하여 재검증한다. 결과는 제한된 시작 조건 범위에서만 해석한다. 평가 조건은 학습 결과를 본 뒤 선택하지 않았다.

학습 조건도 독립 검증한다: 차로0~2는7/17/23m/s, 차로3~5는3/7/13m/s. 총18개, 위치0m 유지. 평가와 학습의 숫자 속도는 겹치지 않지만 best/max 실제속도 중복 여부는 별도 기록한다.

## 2. 유효한 시작 조건 및 관측 변경 검증 완료

최초 실패3개를 기록한 뒤 해당차로의 정지출발로 바꾼 평가20개는 진단 제어 **20/20 완주, 충돌0**. 별도 학습 시작18개도 **18/18 완주, 충돌0**. 이는 PPO 성능이 아니라 환경의 통과 가능성 검증이다.

평가20개의 동일 초기 상태에서 기존/수정 관측37개 중 의도한 분기거리·목표차로방향2개 외에는 모두 정확히 동일함을 확인했다. 기존 분기거리는 -1, 수정 분기거리는 유효값이었다. 수정 거리값은 현재 차로 끝까지 거리와 이후 외부edge 길이를 합하며 내부 연결edge 길이는 제외한 근사값이다. 이후 분기에서 차로번호 체계가 달라질 수 있으므로 현재edge가 아닐 때 방향은 현재 best-lane 방향을 사용한다. 보상 계산용 context는 바꾸지 않았다.

다음 실행은 seed11 각200,000스텝의 처음부터 학습이다. 두 조건은 별도 프로세스로 실행하며 총학습량은 동일하다. 시간 성능 비교는 하지 않는다. 모델선정 없이 마지막 체크포인트를 평가한다.

## 3. 학습 실행 중 독립 검증

학습 커밋 `0afa18c46a849861263dc7728f95cb950ab16206`, seed11, 조건당200,000스텝. 두 manifest는 mode 이외 모든 항목이 동일하다. 각각의 TensorBoard/체크포인트는 results/ic_single_route_v1/original 및 corrected에 저장한다.

best/max 시작에서 같은 진단 행동으로 전체 경로624스텝을 두 환경에서 재생했다. 매스텝 보상·차로 결과·종료 여부·도로 문맥이 모두 같고, 관측도 의도한2개 좌표 밖에서는 완전히 같았다. 459스텝에서 관측이 달랐다. sb_in의 정규화 거리 입력은 -1→0.41985, weave에서는 -1→0.15594, weave 목표차로 방향은0→-0.33333으로 바뀌었다. 이는 새 보상이나 행동 보조를 추가한 것이 아닌 관측 비교임을 확인한다.

원시 검증: results/ic_single_route_v1/full-route-invariance.json. 학습과 별도 프로세스에서 수행하여 학습 RNG/환경을 변경하지 않았다.

## 차로 변경 처리의 한계 (추가 진단)

동일 환경에서 차로5·15m/s 출발 후 best-lane 방향 명령을 연속 입력하자 0.2초에5→4, 0.4초에4→3, 0.6초에3→2, 0.8초에2→1로 이동했다. 따라서 현재 환경에는 변경 후 대기시간으로 연속 변경을 막는 로직이 없다. lane_change_duration=1초는 명령 유지값이며 코드의 cooldown이 아니다. 이 빠른 차로 이동은 현실적인 횡방향 기동을 검증한 결과가 아니다. SUMO 삽입 검사의 거리 제약과 출발 후 제어 방식이 다르므로, 삽입 거부를 AV의 변경 빈도 제한으로 설명하지 않는다. 관측 비교 중 이 동작은 변경하지 않았다.

## 5. 수정 관측 학습 및 대응 비교 완료

seed11 각200,000스텝의 최종정책을 같은20개 시작조건에서 평가했다. 목표(완주95% 이상, 충돌5% 이하)는 **이번 무교통 평가 표본에서 두 모델 모두 충족**했다. 단일seed·단일경로의 기능 검증이며 성공확률의 통계적 보장이나 실제 교통 안전 검증이 아니다.

과속 지표는 에피소드 비율이 아닌 스텝 합계 비율이다. 차로변경은 실제 lane_before와 lane_after의 번호 변화를 센 것이므로 edge 경계에서 번호가 달라진 경우도 포함할 수 있다. 이를 모두 불필요한 횡방향 기동으로 단정하지 않는다. 두 모델의 주행을 점검할 필요성을 나타내는 지표다.

### 해석

- 앞선 A0의 south_to_east는 22개경로·교통 혼합 학습 정책3개 모두 실패했다. 이번에는 기존 관측도 단일경로·무교통·검증된 출발조건에서 완주를 학습했다. 기존 관측으로 원천적으로 학습이 불가능했던 것은 아니다.
- 이전 캠페인과는 경로수·교통량·시작분포가 함께 다르다. 개선을 특정 한 요인에 귀속할 수 없다. 이번 두 조건 사이의 통제된 차이는 관측뿐이다.
- 현재 평가에서는 관측 수정의 완주율/시간 이득이 없다. 단일 경로에서는 경로가 고정되어 목표차로/주변기하를 외우는 정책도 가능하므로, 다른경로 일반화나 교통 대응까지 입증되지 않는다.
- 두 정책은 best/max 재생의1초 샘플에서 가속명령이 모두 양수였다. 기본보상이 속도·완주를 장려하고 과속벌점은 없는 상태라 높은 속도 유지 결과와 부합한다. 수정관측이 속도규칙을 자동으로 가르쳐주지는 않는다.
- 현재 빠른 연속 차로변경 처리도 그대로다. 현실적인 차로변경 시간, 과속, 교통상호작용 검증을 거치기 전 최종정책/수집정책으로 채택하지 않는다.
