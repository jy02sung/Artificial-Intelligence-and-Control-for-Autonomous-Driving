# 위성사진 대조 및 차로·표선 보정 (2026-11-07)

대상은 현재 선택한 퇴계원IC·사노IC 및 연결도로 82개 구간이다. 도로 형상은 첨부 OSM을 보존하고 네이버 위성사진과 대조했다. 위성사진 촬영일을 확인할 수 없고, 교량 아래·그림자·짧은 표선 전환은 판독 한계가 있다. **전체 구간의 실제 차로·실선/점선을 확정한 검증은 아니다.**

## 발견 사항과 반영

| 위치 | 문제 | 수정/판단 |
|---|---|---|
| 사노 서향 교량 뒤 544295537 | 원본 차로 태그 없음 → 1차로 기본값 | 위성사진의 3차로 적용 |
| 사노 동향 교량 뒤 169929482 | 원본 차로 태그 없음 → 1차로 기본값 | 위성사진의 2차로 적용 |
| 동구릉로 북쪽 및 연결부 | 1차로 기본값이 연속 도로 폭을 끊음 | 596640907, 597119334, 841607184#2/#3를 2차로 보정 |
| 동구릉로 교량 아래 짧은 연결부 | 그림자로 직접 판독 제한 | 597119333, 841607184#0/#1은 앞뒤 2차로 연속성에 근거한 **추정 보정**, 거리뷰 확인 필요 |

| 사노 두 교량, 퇴계원 본선 교량 일부 | 점선으로 표시되던 실선 | 아래 4개 구간에 양방향 차로 변경 제한 적용 |

## 표선 적용 범위

- 실선 확인: `1413342573`, `169929478`, `86198725`, `86198722`. SUMO 내부 차로 경계에 `changeLeft/changeRight` 제한을 양쪽으로 적용한다. 승용차·버스는 해당 경계를 변경하지 못하며 GUI에서도 실선으로 표시된다.
- 점선 확인: `169929493`, `169728835`. 기본 차로 변경 허용을 유지한다.
- 혼합/미확정: `170059994`(엇갈림·안전지대), `86198728`(진출 준비+교량), `86198709`(4→3차로 전이). 전체를 실선으로 막지 않았다. 정확한 전환 거리와 차로별 경계는 추가 거리뷰 판독 후 구간을 분할해야 한다.
- 그 외 다차로 구간은 미확정이다. **화면에 점선이 보인다고 실제 점선으로 검증됐다는 뜻이 아니다.** 단일 차로 구간에는 내부 차로 경계가 없으며 도로 외곽선과 구분해야 한다.
- 예외 차종 `custom1`은 이전 프로젝트 방식과 맞춰 예약했다. 이번 변경에 위반차·긴급회피 AV를 투입하거나 그 제어기를 구현하지는 않았다.
- 방향을 나타내던 반복 화살표를 꺼 표선을 읽기 쉽게 했다.

## 근거와 재현

[네이버 사노IC 위성지도](https://map.naver.com/p/search/사노IC?c=18.00,0,0,1,dh)를 사노 동·서 교량, 남북 접근부, 퇴계원 본선 교량·남측 루프·엇갈림 구간으로 이동해 확인했다. 화면 캡처는 로컬 docs/assets/osm-audit에 보관한다(네이버/국토지리정보원 표시 포함). 공개 저장소에는 재배포하지 않는다.

[차로 보정 목록](../maps/toegyewon_osm/lane-overrides.json)에 관찰과 연속성 추정을 구분했고, [표선 목록](../maps/toegyewon_osm/markings.json)에 확인된 경계와 미확정 구간을 기록했다. [도로별 감사 결과](../maps/toegyewon_osm/import-audit.json)의 marking_status로 적용 여부를 확인할 수 있다. 원본 OSM은 수정하지 않았다.

[SUMO 공식 문서](https://sumo.dlr.de/docs/Networks/PlainXML.html)에 따라 도로 수정 파일과 연결 reset 파일로 재생성한다. 네트워크 결과 파일의 차로 좌표를 직접 고치지 않는다. 학습·데이터 수집은 중단 상태이며 정적 연결 검사 통과는 실선 제약하의 AV 완주 보장이 아니다.

## 아직 남은 항목

- OSM 차로 태그도 사진 확정값도 없는 32개 구간은 기본값이며, 거리뷰/추가 증거 필요.
- 혼합 실선/점선의 정확한 시작·끝 위치와 교량 아래 표선.
- OSM 본선 합류부 일부의 큰 교차부 형상 경고, 외곽 램프 분기부의 차로 배분.
- 최종 차로별 경로 가능성, 실제 차량 주행 검증. 지도 점검 완료 전 학습 재개 금지.
