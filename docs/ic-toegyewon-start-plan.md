# 퇴계원 실패 경로 시작 조건·관측 진단

대상: 기본 정책3개 모두 실패한 route_04, route_14. 기존 맵·정책·보상·행동 제약은 고정한다.

1. S 단계: 각 경계 진입 차로 × 출발속도0/10/max와 기존 best/max를 비교한다. R0(seed11/22/33)와 경로 안내 진단 제어를 같은 조건으로 각각 실행한다. 출발 위치0m, SUMO seed1001, 최대900초. 삽입 거부는 주행 시간초과와 별도 기록한다.
2. O 단계: 실제 네트워크에서 다음 도로로 연결되는 차로 집합과 기존 관측의 best-lane offset·분기거리·방향을 비교한다. 각 스텝의 잘못된 차로 여부, 정책이 올바른 방향을 요청했는지, 명령이 적용됐는지와 차로 변화 횟수를 구간별 집계한다. 원시 관측/명령은1초마다 저장한다.
3. 해석: 진단 제어 통과는 해당 출발 조건/행동 제약의 통과 가능성 근거다. 입력에 올바른 방향이 있어도 정책이 반대로 명령하면 판단 실패로 기록한다. 명시적 분기 안내 누락은 코드와 실제 관측 모두 확인한다. 관측 누락이 유일한 학습 실패 원인이라는 주장은 관측 수정 재학습 전에는 하지 않는다.

실행 `python -m utils.diagnose_toegyewon_start`. 기존 결과와 분리해 `results/toegyewon_start_v1`에 저장. 무교통 진단이며 학습·보상 수정은 하지 않는다.

4. X 단계: best/max 기준의 두 경로·정책3개에서 차로 명령만 진단값으로 교체하거나 가감속만 제한속도 추종으로 교체한다. 12회 추가, 기존 무개입6회와 비교한다. 개입 결과는 PPO 성능이 아니라 실패 축을 분리하는 근거다.
